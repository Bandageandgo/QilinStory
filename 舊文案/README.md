# 舊文案／盤點清單（不含 `舊Json檔/`）

> **本資料夾是最早期（DialogueGenerator 時代）的對話 JSON，全部是歷史版本：不編輯、不引用為現行文案、不刪。**
> `舊Json檔/` 是另一批「舊扁平檔」，對照關係見 `劇情/索引.md`〈舊扁平檔 → 現行對話〉，不在本清單內。
> **盤點方法（2026-08-27）：** 把每檔所有 `text`（去掉引擎標記與標點）逐句拿去比對現行 `Json/`、`劇情/`（含舊創作稿）、`@角色設定`／`@地點`／`@結局`／`@事件圖`，看有多少句原樣還活著、活在哪。數字＝「原樣命中句數／可比對句數」。**命中低不代表點子沒用過**——序章、山賊窩、破廟都是整段重寫過的，只是不再逐句對得上。

## 怎麼用這份清單

- **想找日後可挖的素材 → 看第三類。** 那些是現行任何檔案都沒有的東西。
- 第一、二類是「已經被現行稿吸收」的，要看就看它指的現行檔，**不要回頭引用舊句**。
- ⚠ **再利用通則（每一檔都適用）：**
  1. 設定順位 `世界觀.md` ＞ 角色／地點檔 ＞ 舊稿。舊稿裡的張角、九黎、饕餮、董卓、十年之期、麒麟試煉等，**大半已被改寫或廢案**，先查 `給AI看的指南/世界觀.md` 第八節禁詞與 `@角色設定/饕餮.md` 第十節廢案，再談用。
  2. 舊稿滿是**括號內心話**（「（……這也算是一種為生活努力的方式……？）」），現行規則不寫內心話（文本創作指南 2.1a）——只能取事件與台詞骨架，演出要重寫。
  3. 舊稿的 `role` 編號、`MC` 編號與現行**不保證相同**（例：舊 `MC21` 是饕餮、`role35` 是斯蒂娜；現行絲蒂娜另有 ID），轉用前查 `給AI看的指南/立繪指令轉換規則.md`。
  4. 舊稿的引擎寫法（`BeginDiceRoll(Insight,Auto,10)`、`PlayOrPauseNodePlayer`、旗標）全部過時，一律照 `劇情/轉成json指南.md` 重寫；**不得有 `SetFlag`／自創變數**。
  5. 文風先過 `給AI看的指南/武俠文風創作指南.md`（舊稿有「傳銷」「色板」「學術用途」這類現代詞，是可換不可留）。
