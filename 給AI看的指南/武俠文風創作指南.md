# 武俠文風創作指南

**文件目的：** 這是**動筆前讀的檔**。`給AI看的指南/武俠文風審校清單.md` 是事後查表工具（逐詞禁詞表＋逐檔待修清單）；本檔是創作當下的準則——教你把段落一次寫對，而不是寫完再換詞。

**適用範圍：** `劇情/` 資料夾所有 .md 的**玩家看得到的文字**（對白、旁白、選項、物品描述）。`Json檔/` 是轉譯產物，不在此列。引擎標記（`[panel]`、`[em7]`、`Sequence`、`ModifyData`）與 `>` 引用區塊內的開發註記不受文風約束。

**位階：**
- 內容與設定的牴觸，依 `給AI看的指南/世界觀.md` 第十一節順位：世界觀 ＞ 各角色／地點檔 ＞ 既有腳本。
- **文風問題以本檔為準**；逐詞查表用 `給AI看的指南/武俠文風審校清單.md` 第一部分；引擎與敘事結構依 `給AI看的指南/文本創作指南.md`。
- 本檔標記慣例與全案相同：**已定**／**暫定**／**未定**。標「暫定」的規矩照做，但作者可能改。

**建檔：** 2026-08-25。

## 一、總則：本作是什麼腔

一句話定位：**金庸的詞彙語域，本作的白描敘事。**

寫每一段之前先分清楚你在哪一層：**選詞**這一層學金庸，**敘事**這一層學本作自己的新檔。兩層搞混，就會寫出「用金庸的全知口吻替角色下判語」或「用網文的詞寫白描」這兩種都錯的東西。

### 1.1 詞彙層：承金庸的（已定）

- **半文半白**。基準是金庸的白話武俠文：「多謝」不是「謝謝」，「得罪了」不是「抱歉」，「霎時、登時、倏地」不是「瞬間」。
- **角色語域分層**。文人講文人的話，粗人講粗人的話，一個角色一場戲裡不換語域（本作已做得極好，見第四節聲口卡——也最容易在「講解型對白」裡崩掉）。
- **寫神色只用動作詞**。微微一笑、臉色一沉、目光一凝；不用「嘴角勾起一抹」「眼中閃過一絲」「寫滿了」。
- **寶器、武功、來歷用文言短賦**。四六交錯、音節要穩：「色如霜雪，透著日月白光」（`劇情/雙世冥劍.md`）。
- **熱鬧場有說書人聲口**。報場、看客、喝采是另一套嗓門，允許誇張對仗：「是龍是蟲，全看這一遭！」（`劇情/天下第一武道大會.md`）。

### 1.2 敘事層：本作自己的（已定，不得寫成金庸）

| 金庸會這樣 | 本作不這樣 |
| :--- | :--- |
| 全知第三人稱說書人 | **第二人稱**。旁白對玩家說「你」，新內容主角說話者標籤一律 `你` |
| 敘述者下判語（「這一下當真兇險已極」） | **旁白不下判語、不加註解**。事實擺出來，讓玩家自己撞（各新檔 ⚠ 註記一再重申「不得由任何人加註解」） |
| 白描之後補一句人物心事 | **白描到底，不補心事**。「他笑了一下，笑完就低頭繼續絞水」之後不許加「他心中一酸」 |
| 道德是清楚的，俠就是俠 | **不給答案**。「這一支不准有答案」（`劇情/戴天.md` 檔頭紅線）；兩套說詞都不揭穿 |
| 內心獨白（心道：……） | **不寫內心話**。CRPG 寫法，見 `給AI看的指南/文本創作指南.md` 2.1a——內心狀態靠旁白動作、`[em7]`、立繪表情三樣傳達 |

### 1.3 節奏基準（已定）

本作新檔的敘述節奏是**極短句、句號斷得兇、靠重複造迴響**：

> ＊（重刀。全場只有一把。）＊ ——`劇情/雙世冥劍.md`

> ＊（不是暖。是燙。燙得你差點以為它要把你的衣角燒穿。）＊ ——`劇情/雙世冥劍.md`

長句不是禁的——文言賦體、說書報場、賈詡的駢句都是長的。**禁的是副詞形容詞堆疊的長句**（「迫不及待地」「深深地」「緊緊地」連用即是警訊）。情緒不夠重就不要斷短句；斷短句是重錘，一場戲掄兩三下就夠。

## 二、動筆前五條鐵律

1. **旁白是說書人，寫完唸出聲。** 全案的教訓：旁白比對白更容易破功——網文句、翻譯腔、遊戲詞八成漏在旁白。唸出來像論文、像產品說明、像字幕翻譯的，整句重寫，不要修詞。
2. **寫情不點破。** 金庸寫情只用動作：「她沒有再說甚麼，只緊緊握住了你的手」。禁止情緒羅列（「喜悅、感動、釋然…種種情緒交織」）、禁止「眼中情緒複雜」。情緒放在物件和動作上：擦了兩遍的刀、絞水的舊繩子、坐得很淺的椅子。
3. **機制詞不進敘事。** 任務、解鎖、等級、經驗、觸發、檢定——引擎行無罪，旁白與對白裡是硬傷。教學一律走提示框；檢定標記不混進旁白星號文本；演出指示（「畫面淡出淡入」「＊噴血特效＊」）寫在 Sequence 或註記行，不寫成旁白內文。**選項文字與對白同級**——選項是玩家必讀的第一人稱文字，同樣過本檔全部規矩。
4. **半文半白，沒把握不硬寫文言。** 寫壞的文言（「想作漁翁，也得有本事否」）比白話更出戲。拿不準文法就退回半文半白，讓句子乾淨。
5. **時代是東漢光和二年（179 年）。** 動用任何名物、制度、典故前過一遍第三節辛類判斷法。西曆年份系統面可留，**角色口中必是「臘月下旬」或元號紀年**。

## 三、詞彙紅綠燈（類別判斷法）

不用背詞表——記住每一類的**判斷法**，動筆時自問。拿不準的個別詞，查 `給AI看的指南/武俠文風審校清單.md` 第一部分逐詞表。

### 甲、財經公文詞

**判斷法：這個詞會不會出現在現代公司的會議紀錄裡？會，就換成買賣人的話。**

投資→出資、入夥、押注；赤字→虧空；財務危機→庫房見底、度支不繼；方案→條陳、法子；風險→干係、兇險。原則：講錢就講得像市集與帳房，不像簡報。「利益向來伴隨風險」→「天下沒有穩賺不賠的買賣」。

⚠ 這一類最集中在**賈詡、郭嘉、甄筠**這幾個最該講究措辭的角色嘴裡——他們越聰明，越不該講公文。

### 乙、現代抽象名詞

**判斷法：這個名詞摸得到嗎？摸不到的抽象名詞（情報、實力、狀態、壓力、責任、記憶、時間），十有八九有更具體的古語。**

情報→消息、風聲、底細；實力→本事、身手；責任→擔子、本分、該當的；壓力→逼迫、催逼；目標→要辦的事、所求。單看每處都小，合起來是全案最高頻失分點。

### 丙、遊戲／系統術語

**判斷法：這個詞是不是在講遊戲機制？是，就不該出現在旁白與對白。**

任務→差事、委託；單挑→比武；決賽→壓軸之戰；黑馬→無名小子一鳴驚人。機制教學移入提示框；非移不可時包進說書人口吻（「討生活的營生……日積月累，於武藝見識皆有裨益」）。

### 丁、稱謂與客套

**判斷法：金庸有現成正確答案的，直接用。**

謝謝→多謝；抱歉／對不起→對不住、恕罪、得罪了（臨殺致歉必是「得罪了」）；你好→見過某某、打擾了；沒問題→好，這便出發；加油→好自為之。老師→師父。

### 戊、網文腔簽名句

**判斷法：這個句式是不是起點中文網出來的？「瞬間」「嘴角勾起一抹Ｘ」「眼中閃過一絲Ｘ」「一道黑影如鬼魅般」「Ｘ感」——全是。**

寫神色回到金庸的動作詞（目光一凝、臉上變色）；寫出招回到具體（「白光遞到，直取咽喉」）；瞬間→霎時、登時、剎那間、倏地。

### 己、翻譯腔句式

**判斷法：唸出聲。像英文直譯的都是——「作為一個Ｘ」「…的存在」「意味著」「一種／一份＋抽象名詞」「讓她感到」「因為…所以…」對舉、雙重否定。**

「你早就知道它的存在？」→「你早知道有這東西？」；「生者本就是一種責任」→「活著的人，原就背著死去的人的分量」。中文用主動與具體：「她心下一沉」不是「這讓她感到失望」。

### 庚、網路流行語與 ACG 梗

**判斷法（喜劇腔判準，已定）：「用古人的詞講現代思維的笑話」成立；「直接搬運現代網路流行語」不成立。**

吐槽可以現代思維、古代語彙：「基操」→「雕蟲小技」，笑點不減；「有病要治」→「癲症宜早延醫」，更好笑。禁：基操、好耶、格局小了、躺平、靠譜、戲精、下次一定、說人話……（完整名單見審校清單庚類）。梗的來源年代晚於東漢的（天王蓋地虎、征途是星辰大海），一律不搬。

### 辛、時代錯置（東漢 179 年）

**五個判斷法，動用名物前自問：**

1. **幣制**——明清幣制（銀兩、幾兩銀、文）不入對白。東漢通貨是五銖錢。
2. **器物**——宋以後的東西不出鏡：算盤（用算籌）、羅盤（用司南）、瓷花瓶、玻璃（稱琉璃）。
3. **物產**——明代才進中國的不存在：菸草、辣椒、以及一切美洲作物。
4. **外來語**——日語詞（武道、素體、大本營）、近代軍語（部隊、據點、根據地）、清末行話（掮客、銅板、包漿）不入文。
5. **典故**——晚於東漢的詩文佛語不引：唐詩、禪宗語、「我不入地獄誰入地獄」、日本幕末詩。角色念的詩句拿不準出處就自撰韻語。

### 類型讓步清單（已定，與硬性錯置區隔）

以下是**拍板保留**的武俠類型慣例或世界觀設定，不算錯置，不必修：

| 項目 | 判定 |
| :--- | :--- |
| **「銀子」「銀兩」** | **保留**（作者拍板 2026-08-25）。武俠類型慣例，金庸宋代背景也照用。與菸草、算盤等硬性錯置不同級——那些仍必改 |
| 狗頭人、蜥蜴人等西式奇幻生物 | 逆流河世界觀設定（音譯名仍禁：哥布林→依全案意譯體例） |
| 「情報網」作系統名 | 可留；**角色口中一律換**「消息、風聲」 |

### 語尾詞規矩（已定，2026-08-25 拍板）

少女腔語尾詞（喔／哦／耶／啦／嘛）**僅限蕭靈犀、赫連娜娜、蔡文姬**三人，一場戲每人以三次為度，多了就膩。其他任何角色——包括路人、阿婆、狗頭人，**張仲景也不豁免**——**一律不用**：他的油滑寫在內容裡（「是不是覺得脫胎換骨，想去跟牛打一架了？」），不靠「哦」撐。**判準看聲口不看字**：雍仔「先謝過啦」那種市井滑頭腔、主持人「開——場——啦」的報場腔，不算少女腔；裝乖賣巧的「不保哦」才算。波浪號「～」全案不用。

## 四、角色聲口卡

寫對白前對一次卡。原則：**一個角色一場戲一種語域**；讓他破功的永遠不是腔，是具體名詞——把「通路商」換成「行商」，人設一分不損。角色設定本體以 `@角色設定/` 各檔為準，本節只管「怎麼說話」。

### 旁白（說書人）

白描、短句、不下判語、不進角色內心。只寫看得見的：動作、物件、環境。判語型句子（「這一下當真兇險」「他心中一酸」）一律刪。標竿：

> ＊（他說得很平常，像在講今天要挑幾桶水。）＊ ——`劇情/五原障.md`

### 黑幕旁白（過場／回憶）

與旁白同一副嗓子，但管時間流逝與收尾。收尾句允許把分量壓在玩家身上，仍然不評論：

> ＊（你們在那座塢裡待了半天。你不知道自己是慶幸沒找到，還是怕自己其實找得到。）＊ ——`劇情/陽曲塢.md`

### 你（主角）

少年心熱、嘴直，武人本色不文縐縐。會衝口而出（「那不公平。」），會在選項裡撂狠話也會平實應戰。**選項就是他說出口的話**，同樣過文風。不寫內心話（2.1a）。

### 子羽

自稱**「羽」**（「……羽記得。」）。句短，近文言，常以「…………」代答——他的沉默是台詞，不要幫他填。講怪物、講武學用書面語（「吞食劍中怨念滋生……」）。標竿：

> 「書上說，父之讎，不共戴天。」「……那被殺的那個，他兒子呢？」 ——`劇情/戴天.md`

### 呂信

粗豪直腸，口頭有「嘖」「嘿」，句子帶勁：「滾開──！」「還真是皮糙肉厚啊。」豪語成套（「想當年西楚霸王，一桿長戟橫掃八千里」）。⚠ 別把他寫笨——他的粗話裡有真話：

> 「了不了得了，看他們自己。刀能砍的就那麼一截，剩下的路是他們的。」 ——`劇情/仗義疏財.md`

### 賈詡 ⚠ 高危

自稱「賈某」「為師」。正式場合四六駢句，是全案語域天花板：

> 「戰國之世，九黎橫生，百家伐異，各闢門道。」「可嘆，秦帝毀書，古學斷絕，殘存不過奇文異錄。」 ——`劇情/第二章劇本.md`

日常陰陽怪氣帶喜感（「唉，張寧誤我……」）。**高危：財務線。** 他一講錢就滑進「投資、赤字、方案」——這個人講駢文，講錢也必須講得漂亮：出資、虧空、條陳。

### 郭嘉 ⚠ 高危

話少，句冷，收尾利：「鬧劇不奉陪了。」「無所謂，反正我用不上。」字斟句酌型——正因如此，一句「正常處理」就把人設打穿。**高危：講解與財務。** 他的冷要用古語的冷：「大有可為」不是「不會是沒有空間」。

### 赫連娜娜 ⚠ 高危

自稱「本姑娘」，稱主角「大俠」，活潑，是講解擔當。語尾詞限額內可用。**高危三連：講解型對白＋現代詞＋語尾詞失控。** 她話多，每一句都是漏詞的機會——她可以興奮，但興奮要用她的詞（「劍出鞘不見血不回鞘」是她的味道；「絕對是絕世珍寶」不是）。

### 蕭靈犀

自稱「小犀」，稱主角「表哥」，白話帶語尾助詞（限額內）。帳房少女——她撥的是**算籌**不是算盤。⚠ 她的活潑是人設，她用的名詞照樣要過紅綠燈（「大本營」「報告一聲」都不是她該有的詞——「落腳處」「捎個信」才是）。

### 張寧

毒舌醫者，罵人快而準：「就那四個蠢貨，肯定只有全部出局。」「你這笨蛋是嫌自己命太長了嗎？」對小犀會軟（「小犀乖」）。她的刀子口不需要翻譯腔幫忙——「作為一個醫者」這種句式一出現她就死了，她會說「行醫的看不慣」。

### 雍仔

自稱「道爺」「胖爺」「本道長」，說書滑頭腔，順口溜張口就來：「道法自然——贏也自然，輸也自然！」喜劇擔當，**現代思維古代語彙**的示範角色——他可以講歪理，不能講網路梗。

### 主持人（報場口白）

純說書人聲口，四六對仗、誇張、敲龜殼：「是龍是蟲，全看這一遭！」「無鋒劍法，快如流星；草原女兒，劍出鞘不見血不回鞘！」熱鬧場專用嗓門，與白描旁白形成層次——**兩副嗓子不許互串**。

### 路人與配角通則

話從**行當**裡長出來：老兵講水講路（「井只有這一口，路只有我認得」），莊稼人講田講天。不用語尾詞、不賣萌、不講解劇情。一個好配角一場戲只需要一句有分量的話。

## 五、正面範例庫（本作標竿句）

模仿的對象。每句附出處與它好在哪。**風格拿不準時，回來重讀這一節，比讀任何規則有用。**

### A. 敘述白描

> ＊（正堂上沒有擺架子。案是常家的案，可是案後那個人坐得很淺，像隨時會站起來。）＊ ——`劇情/陽曲塢.md`

不寫心理，只寫姿勢，權力的不安全感全在裡頭。且在同場收尾扣回：「＊（他說完就坐回去了。坐得還是很淺。）＊」——細節要能前後扣。

> ＊（他的手還握在刀柄上。沒有拔。指節白了。）＊ ——`劇情/雙世冥劍.md`

三個短句遞進，零形容詞，零心理描寫。全案動作白描的最高水準。

> ＊（不是暖。是燙。燙得你差點以為它要把你的衣角燒穿。）＊ ——`劇情/雙世冥劍.md`

自我糾正式斷句，把超自然感受寫成身體感受。

> ＊（他還在那裡。場上沒點燈，只有月色。他在擦刀——白天已經擦過一遍的那把。）＊ ——`劇情/戴天.md`

夜戲建場。「白天已經擦過一遍的那把」是全段的眼——情緒放在物件的冗餘動作上。

> ＊（他說完就繼續絞他的水。繩子很舊了，絞起來吱吱響。）＊
> ＊（他笑了一下，笑完就低頭繼續絞水，好像這件事不值得再多說一句。）＊ ——`劇情/五原障.md`

同一個動作貫穿整場，三次重複、三種情緒。老兵的重量全靠這口井撐起來。

> ＊（他轉過頭來看你。那是他這一路上第一次真正看你。）＊
> ＊（子羽看見了。他也看見你看見了。）＊ ——`劇情/雙世冥劍.md`

三層視線疊在一句裡。寫「被看見」不寫「被感動」。

> ＊（毒煙不等人。你身後有兩個護衛沒能退開，倒下去的時候連聲音都沒發出來。）＊ ——`劇情/雙世冥劍.md`

死人寫法：不哀悼、不特寫，只報事實。旁白不補刀、不評論。

### B. 對白

> 釣魚叟：「餌是給魚吃的。我釣的，不是魚。」 ——`劇情/翠影潭.md`

全案標竿句。十二個字，兩層意思，零解釋。

> 老兵：「刻字的是留下來的人。留下來的人手裡有刀。」 ——`劇情/五原障.md`

頂真句法。江湖的真相（誰活著、誰有刀，誰就算數）一個字的評論都沒有。

> 子羽：「書上說，父之讎，不共戴天。」「……那被殺的那個，他兒子呢？」 ——`劇情/戴天.md`

九個字的追問掀開整個武俠底層設定。問題比答案重——本作不給答案。

> 老兵：「不是。我是這座障的。」「他們來了以後，我還是這座障的。」 ——`劇情/五原障.md`

同構重複句。立場、處境、尊嚴一次到位，收尾是「就這樣。」

> 少年：「四十七張。」「我數過。所以現在跟著我的有二十幾個——還有二十幾家沒來。」 ——`劇情/陽曲塢.md`

報數，不是招募。冷得很準——數字比形容詞狠。

> 呂信：「想當年西楚霸王，一桿長戟橫掃八千里。大丈夫在世，就該這般轟轟烈烈，打出個名震天下——這才不枉來人間走一遭！」
> 子羽：「……殺得越多，才越明白這話有多輕。」 ——`Json檔/天下第一武道大會_酒館夜話.json`

一豪一冷、一長一短，兩句對砍。對白的節奏是角色之間的，不是單句的。

### C. 動作與場面

> ＊（全場轟然炸開，喝采如雷、震得梁上塵灰簌簌而落——你人還沒動手，聲勢已先壓了對手三分。）＊ ——`劇情/天下第一武道大會.md`

動詞選得狠（炸、震），破折號承轉。標準舊派武俠場面句。

> ＊（你咬牙硬撐，終究技不如人——對手一記重手當胸搗來，你來不及閃避，眼前一黑，便不省人事。）＊ ——`劇情/天下第一武道大會.md`

敗仗四拍：撐、來、避不及、黑。「搗」字見功夫。

> ＊（重刀。全場只有一把。）＊
> ＊（然你們所寄予的那個人，只是閃避，遲遲不肯出刀。）＊ ——`劇情/雙世冥劍.md`

戰場困境六個字交代完。斷短句是重錘，掄在最重的地方。

### D. 文言賦體與說書口白

> ＊（此劍乃金鐵所鑄，色如霜雪，透著日月白光，然光華之下，更有森森寒氣……）＊ ——`劇情/雙世冥劍.md`

寶器寫法：四六交錯，音節穩。最接近金庸寫兵器的一句。

> 賈詡：「戰國之世，九黎橫生，百家伐異，各闢門道。」「可嘆，秦帝毀書，古學斷絕，殘存不過奇文異錄。」 ——`劇情/第二章劇本.md`

角色語域的天花板。四字排比＋文言虛詞（可嘆、不過、唯），跟全場所有人都不一樣——這才叫毒士。

> 主持人：「塞外赫連部劍術奇才——娜娜姑娘！無鋒劍法，快如流星；草原女兒，劍出鞘不見血不回鞘！」 ——`劇情/天下第一武道大會.md`

報場口白：對仗、誇張、聲口響亮。熱鬧場的另一副嗓子。

## 六、壞→好改寫十課

每課：原文（全部出自現有文本）→ 改法 → 病名。改法多數取自審校清單的既有建議。

**第一課．財經公文詞**
原文（甄筠）：「項目的核心價值、未來展望、資金規劃、退場機制」（`劇情/第二章劇本.md`，全檔最重一句）
改：「筠只問四件事：你英豪府憑什麼本事立足？日後打算怎麼走？銀錢從何而來？若賠了，又拿什麼還？」
病名：甲類。四個簡報名詞變四個問句——內容一字沒少，人活了。

**第二課．同一張嘴兩種語域**
原文（賈詡，同一檔內）：前文「戰國之世，九黎橫生，百家伐異，各闢門道」；後文「你們跟我各自提出才藝方案，這是命令。至於(玩家名)跟郭嘉，負責評選。」（`劇情/第二章劇本.md`）
改：「你們各自獻技，為師擇優——至於(玩家名)與郭嘉，替為師掌掌眼。」
病名：語域崩壞。一個講駢文的人不會講「提出方案、負責評選」。**寫長對白時每隔幾句抬頭看一眼聲口卡。**

**第三課．遊戲 UI 詞入旁白**
原文：＊（……偶爾體驗一下尋常百姓的「工作」，如釣魚、採藥等，不僅能賺取些許資源，還能獲得寶貴的「生活經驗」。累積足夠的「生活經驗」，便有機會參悟命盤中的各種「天賦」……）＊（`劇情/舊創作稿/初出茅廬之一.md`）
改：機制數值移入提示框；旁白只留「＊（在江湖上討生活，釣魚採藥都是營生。日積月累，於武藝見識皆有裨益。）＊」
病名：丙類。旁白是說書人，不是新手教學。（「命盤」另屬 `@角色設定/饕餮.md` 第十節停用術語，雙重違規。）

**第四課．翻譯腔「作為一個Ｘ」**
原文（張寧）：「作為一個醫者，我並不討厭你這種笨蛋。」（`劇情/英豪府遴選.md`）
改：「行醫的看不慣見死不救。你這種笨蛋……不討厭。」
病名：己類。英文 "As a..." 直譯。張寧的毒舌自己會說話，不需要句式墊。

**第五課．公文句式複製四遍**
原文（黑幕旁白，同句式連用四次）：＊（於是你們提交方案……一段時間過後，朝廷寄回了反饋……）＊（`劇情/第二章劇本.md`）
改：＊（於是你們呈上所擬條陳……過了些時日，朝廷批文發還——）＊
病名：甲類＋句式偷懶。「反饋」還是大陸用語。公文轉批文，時代與文風一起修好。

**第六課．「絕對」——新檔也會漏**
原文（赫連娜娜）：「哇！這劍好漂亮！大俠，這絕對是絕世珍寶啊！」（`劇情/雙世冥劍.md`，2026-08-25 定稿檔）
改：「哇！這劍好漂亮！大俠，這定是絕世珍寶啊！」
病名：現代副詞。絕對→定是、準是、必。**這句漏在最新定稿檔裡——證明鐵律不分新舊稿，每段都要過。**

**第七課．近代軍語＋職場語**
原文（蕭靈犀）：「我就在這守著咱們的『大本營』。你若是在外面混不下去了……記得回來報告一聲。」（`劇情/舊創作稿/開啟大地圖.md`；該場戲的現行版是 `Json檔/主線事件_179年_6月.json`，這兩個詞在現行版已整句改掉）
改：「我就在這守著咱們的落腳處。你若是在外面混不下去了……記得回來捎個信。」
病名：辛類（大本營＝明治日語軍語）＋現代職場語。她的俏皮完全不靠這兩個詞。

**第八課．網文神色句**
原文：`[身形一頓，眼中閃過一絲驚駭]`（`劇情/竹林小徑.md`，同檔五見）
改：`[身形一頓，臉上變色]`
病名：戊類。神色用動作詞：目光一凝、臉上變色、臉色一沉。「閃過一絲」是網文簽名句。

**第九課．旁白播報數值**
原文：＊（在童淵的壓力下，你感覺自己的力量有了增長。武力經驗提升。）＊（`劇情/舊創作稿/大地圖的小溪村.md`）
改：數值播報走提示框；旁白改「＊（童淵招招進逼，你硬接了幾記，虎口發麻——但這幾下，筋骨是實實在在吃進去了。）＊」
病名：丙類＋乙類。「壓力」是現代心理詞（古語：進逼、催逼、相激）；「經驗提升」是系統話。

**第十課．情緒羅列**
原文：＊（她凝視著藥草，又抬頭深深地看著你，眼中情緒複雜，似有千言萬語。）＊（`劇情/舊創作稿/初出茅廬之二.md`）
改：＊（她接過藥草，攥得很緊。看了藥草一眼，又看你，到底沒說什麼。）＊
病名：鐵律二。「情緒複雜」「千言萬語」是替讀者把情緒講完。動作擺出來，讓玩家自己讀。

## 七、本作獨有技法（金庸沒有的題目）

### 7.1 第二人稱旁白

旁白對玩家說「你」，但**「你」不透明**——旁白看得見你做了什麼，看不見你想什麼（內心規則見 `給AI看的指南/文本創作指南.md` 2.1a）。內心狀態的三樣工具：旁白寫動作環境、`[em7]` 補立繪演不出來的那一下、立繪表情特效。第二人稱的獨門力量是**把道德分量直接壓在玩家身上**，而且照樣不評論：

> ＊（你不知道自己是慶幸沒找到，還是怕自己其實找得到。）＊ ——`劇情/陽曲塢.md`

這句合法，因為它寫的是「不知道」——擺出兩個可能，不替你選。「你心中湧起一股愧疚」就不合法，那是替玩家決定他的感受。

### 7.2 同一句話的三種語氣（分支寫作）

金庸一場戲只寫一遍；本作同一個節點常要寫三個分支。規矩：

- **選項只寫他在做什麼，不寫標籤**。範例（`劇情/雙世冥劍.md` §9）：`[信義]`「她給你這把刀，是要你止殺。」／`[機略]`「那東西殺了多少人，你數過嗎？」／`[通達]`（什麼都不說，自己頂上去）——三條都是行動，沒有一條暗示正解。
- **分支之間變的是語氣與代價，不變的是聲口**。三條分支裡子羽還是子羽，短句還是短句。
- 旗標回收的舊句（「他那天說『那我自己去』」）引用時**一字不改**——前後扣得準，靠的是原句原字。

### 7.3 選項文字

選項是玩家必讀的第一人稱文字，出過全案最重的現代語（「洩洪壓力」「信仰之躍」）。選項過稿標準與對白完全相同：讀出來要像**這個少年會說出口的話**。撂狠話的選項用武人的狠話（「今日這座台子，就陪并州父老看個痛快!」），不用心理學。

### 7.4 喜劇腔

判準一句（已定）：**現代思維可以，現代語彙不行。** 銀魂式吐槽是本作的腔，保；梗的載體必須是古人的詞。實作三條：

1. 換詞不換梗：「基操」→「雕蟲小技」、「有病要治」→「癲症宜早延醫」——笑點在思維，不在流行語。
2. 喜劇角色（雍仔、呂信的自誇、賈詡的怪癖）可以荒唐，不可以出戲——「我！就是才藝！」成立，因為每個字都是古語。
3. 喜劇段的旁白仍是說書人。吐槽交給角色，旁白最多冷冷擺事實（「＊（…………………………）＊」就是好吐槽）。

### 7.5 紅線註記寫在引用區塊

寫作紅線（「不得由任何人加註解」「這句話不得改字」「不得讓子羽在此接話」）是本作重要的創作紀律，一律寫在 `>` 引用區塊帶 ⚠ 標記，**不寫進旁白行**——「依指南 0.2.3」這類字樣漏進旁白格是全案已發生過的事故。新寫段落裡最重的那一句，值得當場立一條 ⚠ 告訴未來的自己：這裡不許解釋。

## 八、寫完自檢清單

每寫完一段（或一場戲），照順序過一遍：

1. **唸出聲**——旁白逐句唸。像論文、產品說明、字幕翻譯的：整句重寫。
2. **八類快掃**——會議紀錄詞？摸不到的抽象名詞？遊戲機制詞？謝謝抱歉你好？「瞬間／一抹／一絲」？「作為／的存在／一種Ｘ」？網路流行語？宋以後的東西？
3. **聲口對卡**——每個開口的角色對一次第四節：自稱對嗎？語域穩嗎？高危角色（賈詡、郭嘉、娜娜）的講解段再讀一遍。語尾詞數一下（限兩人、每場三次內）。
4. **情緒檢查**——有沒有句子在替玩家或角色講感受？（「情緒複雜」「心中湧起」「感到一絲」）改成動作與物件。
5. **機制與演出**——旁白裡有沒有數值播報、檢定標記、「畫面淡出淡入」？移走。
6. **字面掃描**——簡體字、非中文字符（拉丁字母、殘留外文）、波浪號。
7. **時代三問**——錢怎麼算（五銖錢；銀子可留）？器物是宋以前嗎？引的詩文是東漢前嗎？
8. **設定紅線**——`給AI看的指南/世界觀.md` 第八節永久禁詞（五胡亂華、司馬、篡魏、三國歸晉、輪迴、重來、前世）一個都不能出現；饕餮相關段落過 `@角色設定/饕餮.md` 第十節停用術語。

拿不準的詞：查 `給AI看的指南/武俠文風審校清單.md` 第一部分。拿不準的設定：查 `給AI看的指南/世界觀.md`，**沒寫的就是還沒決定，留白或詢問，不得發明**。
