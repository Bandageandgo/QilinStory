# 武俠文風審校清單（金庸標準）

**文件目的：** 本清單是對 `劇情/` 資料夾全部 43 個劇本檔（不含 json 指南、改動追蹤、更新紀錄等內部文件）逐行審校的結果。以金庸的白話武俠文風（半文半白、說書人腔）為標準，找出不像武俠的**用詞、名詞、句式與敘事口吻**。

**兩種用法：**
1. **回頭修稿**——按「第五部分：逐檔待修清單」逐條核對替換。
2. **逐詞查表**——個別詞拿不準時查「第一部分」高頻替換詞表。

> **⚠ 今後創作標準已由 `給AI看的指南/武俠文風創作指南.md` 接手**（2026-08-25）：新寫任何段落前讀該檔（第一～四部分的守則已升級收進該檔，並補上正面範例庫與聲口卡）；本檔專職事後審稿與逐詞查表。

**審校範圍說明：** 只審玩家看得到的文字（對白、旁白、選項、物品描述）。引擎標記（`[panel]`、`[em7]`、`ModifyData` 等）與開發註記不算問題。逆流河的西式奇幻生物（狗頭人、蜥蜴人）是世界觀設定，不算問題；「銀魂式」喜劇吐槽是刻意風格——但**「用古人的詞講現代思維的笑話」成立，「直接搬運現代網路流行語」不成立**，後者一律列出，由作者定奪。
