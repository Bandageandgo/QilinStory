# 音樂指令轉換規則（BGM／音效對照表）

**這份檔是拿來「查曲」的。** 要配樂時先來這裡找情境，找到就照抄 ID。

> ⚠ **情境欄由作者填，AI 不得自行判定或發明。** 空白＝還沒定；需要配樂又找不到對應情境時**問作者**，不要挑一首聽起來像的填進去。
> 「現行用在哪」欄是從 `Json/` 掃出來的**事實**，可以當線索；標〔JSON 原註〕的是節點 `Description` 裡作者自己寫的字。

> ⚠ **曲子不專屬於任何場景或角色**（2026-09-02 作者澄清）。同一個場景可以先後放好幾首，同一首也可以橫跨好幾個場景——例如竹林小徑既可以是 `BGM_37` 也可以是 `BGM_25`。所以**「情境」欄是用途說明，不是排他綁定**；看到某場景已經有別首曲子，**不代表哪一邊寫錯了**，不要拿這張表去「糾正」既有 JSON。

## 1. 指令寫法

```
AudioControl(PlayMusic,BGM_19);        換 BGM
AudioControl(PauseLowerMusic);         把現行音樂壓低（不是停掉）
AudioControl(StopMusic);               停掉音樂
AudioControl(PlaySFX,音效ID);          放音效（持續／循環）
AudioControl(PlaySFXOneShot,音效ID);   放一次性音效
AudioControl(StopSFX);                 關閉音效。⚠ 不帶參數、不帶逗號
```

現行搭配習慣（**掃出來的現況，不是規則**）：

| 組合 | 次數 |
| :--- | :-: |
| `PauseLowerMusic` ＋ `PlayMusic` | 44 |
| `StopMusic` ＋ `PlayMusic` | 23 |
| 只有 `PlayMusic` | 21 |
| 只有 `StopMusic` | 13 |
| 只有 `PauseLowerMusic` | 8 |

- 進箱庭對話要蓋掉地圖音樂時，既有稿多寫 `關閉地圖音樂、放主題曲`（`StopMusic` ＋ `PlayMusic`）。
- 養成事件插一段戲多寫 `PauseLowerMusic` ＋ `PlayMusic`。

> **⚠ 鐵則（2026-09-04 作者裁示）：已有音樂在播時，`PlayMusic` 前必須先 `AudioControl(StopMusic);`（或依情境 `PauseLowerMusic`），否則兩首會疊著放。** 對話中途換曲、轉場帶時間標記時也一樣——`Stop` 與 `Play` 掛同一個 `@秒數`，寫在 `Play` 前面。抓到的實例：`呂信線/02第三百四十九次.json` `#1999`／`#2999`／`#3999` 轉場「日頭下去了」原本只寫 `PlayMusic,BGM_23@1`，前面 `#2` 的 `BGM_19` 沒停（已於當日補 `AudioControl(StopMusic)@1;`）。

**「同格只有 `PlayMusic`」全案清查（2026-09-04 掃描，33 處）：**

- **✅ 沒問題（前一格已 `StopMusic`／`PauseLowerMusic`，8 處）**：`主線事件/179年/4月` `#2`、`179年/6月` `#2052`、`179年/7月` `#2373`、`180年/9月`＆`11月` `#282`（空一拍再進 `BGM_32`，本檔 §2 已載）、`天下第一武道大會` `#841`、`小溪村後山/赫連娜娜、張寧` `#739`、`賈詡線/01兩卷` `#31`、`趙王洞/遺跡` `#60`。
- **✅ 疊播嫌疑 7 處已沿 `links` 反向逐條追完（2026-09-04）**：確定疊播的只有 `主線事件/180年/9月`＆`11月` 的 `#8`——上游 `#3`（赤龍幫未出資分流）在播 `BGM_23`，到 `#8` 直接疊 `BGM_19`，**已補 `AudioControl(StopMusic);`**（作者「確定就補」裁示；另一條無音樂的上游路徑補了也只是空停，無副作用）。其餘 5 處（兩檔 `#4351`、`雲中/街道` `#4146`、`探索事件/180年/3月` `#4157`、`趙王洞/遺跡` `#87`）反向追到入口都沒有音樂帶進來，**是初掃的誤報，不必動**。
- **✅ 檔頭／入口直接 `PlayMusic` 的 18 處全數不用管（2026-09-04 作者說明）**：**進入這類事件對話時，系統會自動暫停箱庭（地圖）音樂；離開事件時自動恢復播放**。所以入口不必寫 `StopMusic`／`PauseLowerMusic`——上面的鐵則只管**對話中途**換曲（前面已有本對話自己 `PlayMusic` 過的情況）。
- **BGM 與音效可以並存**：人聲嘈雜、馬車聲這類環境音走 `PlaySFXOneShot`，配樂另外走 `PlayMusic`，同一格兩句並列（例 `大地圖/天下第一武道大會` #669、`探索事件/179年/3月` #83）。

- `PlaySFXOneShot`＝**一次性的動作**：收到錢、落水、鳥叫、肚子叫、打鐵、爆一下。
