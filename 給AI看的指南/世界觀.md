## 零、兩條軸（已定）

這個世界的超自然只有兩個來源。**別的東西都掛在這兩條下面，沒有第三條。**

| 軸 | 是什麼 | 本部會碰到的 |
| :--- | :--- | :--- |
| **本土** | 這個世界自己長出來的。道 → 三皇 → 四獸 → 仙 | 麒麟骰（饕餮）、混沌骰、白虎道妖、黑血屍、屍丹、神像紅眼一類的凶戾 |
| **外來** | 從「逆流河」這道兩界之隙漏進來的 | 狗頭人、蜥人、龍、河伯的異舟與星淚石、「更高維度生命」 |

**波斯祆教那一套不是第三條軸**，是外邦對同一件事的另一種說法（第五節）。
**「九黎」也不是第三條軸**，它是**這兩條軸的怪物全部一起出來**時，世人給那場浩劫取的名字（第六節）。

## 一、本土：層級（已定）

道在最上。天皇、人皇、地皇平級（三才三個位子，不是天子）。四獸在人皇下面。仙再下面。

| 層 | 誰 | 本作品 |
| :--- | :--- | :--- |
| **道** | 宇宙的規則（取《道德經》的道）。源頭／最上。不必再拆成「生命」還是「法則」 | 不出場、不講課 |
| **三皇** | **天皇＝人皇＝地皇**。人皇是「人」這一格的皇，與天皇職等平行，**不是天子** | 只出**人皇**。天皇、地皇留著，不出場 |
| **四獸** | 貪惡長出來的獸。四凶：饕餮、渾敦（混沌）、窮奇、檮杌 | 在人皇**下面**。本部只出饕餮、混沌 |
| **仙** | 人皇下面能辦事的人：追隨者、信徒、傳人 | 南華在這一層 |

主角、張角都不進這張表。主角是血脈後人；張角是拿了骰子的人。

**不要：** 人皇＝商紂。封骰的是人皇，不要寫成商王、周武。商紂、周武王不入場。

典籍裡「天、地、人」是三個並排的**位子**，不是戰力榜。遊戲借用：人皇與天皇平坐；四獸低一等，所以封得進骰子。

## 二、人皇與極西之族（已定／本劇不揭）

### 人皇

- 不是龍椅上的皇帝。血脈在主角母系。封得住獸的是這家的血，骰子跟著走。
- **骰子是人皇封的。** 哪一任（末代還是更早）**未定**，不擋現寫。
- 人皇還在，但**困住**，只剩意志，動不了，跟死了沒兩樣。**現在沒功能。** 困在哪、意識細節——不管。
- 交棒、流放、天王老子、逍遙子、主角跟人皇見面：放最後，甚至不在這款遊戲。

### 極西之族＝崑崙＝西王母＝主角母系（已定）

`劇情/宗緯家.md` 女神像石刻那一族，就是主角母系，就是人皇血脈這一支。那尊身披戰甲、手持長矛、「與中原女子的溫婉截然不同」的女神像即**西王母**（《山海經》的凶悍原貌）。

石刻原文（`劇情/宗緯家.md` L293–297，**不改字**）：

> 吾族本居極西之地，受神諭指引，跨越「逆流之河」來到中土。
> 時值戰國亂世，吾族助秦王掃六合，統天下。
> 然秦王欲求長生，窺視吾族血脈之力。
> 吾族不願為奴，遂隱於深山，封印逆流河口，以此神像鎮之。
> 後世有緣人，若得吾族傳承，當以此力守護蒼生，勿蹈秦王覆轍。

**「跨越逆流之河」是地理上的渡河，不是穿越世界（已定）。**
他們**是這個世界的人**，只是原本住在極西、住在河口那一側；東遷之後回頭把河口封起來。

- **⚠ 嚴禁**寫成「人皇一族來自裂隙另一側」「人皇之血封得住四凶是因為它不屬於這個世界」。人皇仍舊是「人」這一格的皇，與第一節的層級表完全相容。
- 秦王要的，正是能封住那頭東西、也曾被拿去換力量的那種血。
- **核心諷刺（表裡真實）：** 廢掉人祭的英雄，做出來的封印卻要靠獻祭維持。這一族既是終結人祭的人，也是至今仍在獻祭的人。
- **由此 `劇情/宗緯家.md` 那場戲翻倍地諷刺：** 他讀到的是自己家的族譜，卻只想著「肯定留下了不少好寶貝吧」。
- **未定：** 逆流河口有幾處；極西那一處與宗緯家石像鎮的那一處是不是同一道。**AI 不得自行決定數量。**

舊稿「廢人祭、臨終封骰」見 `@角色設定/天王老子.md`、`@角色設定/饕餮.md` 備查。**尚未與本檔對齊。** 新寫不得當前提。
**⚠「十年一獻」＝廢案，全案刪除**：封印不需要餵、沒有週期、沒有帳，她也沒跟任何人簽過約。連帶廢除「份量不夠」的講法——**不是不夠，是沒有夠**。**故鄉大火的成因因此變成未定，AI 不得發明。**

## 三、四獸（已定）

貪惡長出來的獸，不是「天地本有、非誰所造的抽象」。不是四兄弟——書上是四個族的不才子，後人合稱四凶。

| **窮奇** | 毀信、助惡（神異經：吃正直的） | 續作 |

### 兩截：趕到邊，再封進骰（已定）

書上**沒寫**牠們離開這個世界，也沒寫進骰子。有寫的只有流放。

**表（世人／史書）：** 舜把四凶族**投諸四裔，以禦螭魅**（《左傳·文公十八年》）。記在舜頭上，因為舜是聖王，沒人跟聖王的功勞過不去。

**裡：** 人皇把獸趕到人間的邊（四裔／荒外）。邊地還在吃，人皇再**封進四顆骰**。封骰這一步是創作。

《神異經》可當「趕到邊、尚未封骰」時獸還在：渾沌在崑崙西，饕餮在西南荒，檮杌在西荒，窮奇在西北荒。**崑崙西與極西血脈的地緣關係——未定**，不得自行接死。

舜不必寫成人皇本人。後人把人皇做的事寫成聖王故事。

《尚書》另一組四凶（共工、驩兜、三苗、鯀）不當換名。《呂氏春秋》鼎上「有首無身」當饕餮的訛傳／樣子，不當引擎。

### 四凶各自的能力（已定方向／細節未定）

**每一頭獸除了性情，還帶一種能力。** 這是牠們封在骰子裡之後，持有者實際會碰到的東西。

| 獸 | 能力 | 本部誰在用 |
| :--- | :--- | :--- |
| **饕餮** | **一點點預知。** 程度輕微、模糊，不是全知 | 主角。他一直當成「骰定福禍」的吉凶指引 |
| **混沌** | **重來，並試各種可能性。** 不是回到過去走同一條路，是把所有岔路都走一遍 | 張角。他能重來，是因為這顆骰在他手上 |
| **窮奇／檮杌** | **未定** | 續作 |

**混沌的能力就是牠的性情。** 牠是「是非不分、亂」那一頭——所以牠給的不是**正確的**那條路，是**全部的**路，而且不告訴你哪條對。持有者只能一條一條試。

**⚠ 兩條共同的硬規則：**

1. **能力有代價。** 不是免費的、不能無限用。**代價是什麼——未定，AI 不得發明。**
2. **能力會越用越弱。** 每用一次就折損一分。**折損的表現與速度——未定。**

**⚠ 這不推翻「她不開價」那條。** 預知是她**身上有的東西**，不是她**賣給主角的服務**——她報她聞到的、看到的可能性，去不去、信不信是他的事。`@角色設定/饕餮.md`「她提供的是可能性，不是條件交換」原封不動。**嚴禁**寫成「你餵我，我告訴你未來」。

**這一條回頭解釋了既有文本：** 主角從序章就把骰子當吉凶指引（「古云『蒼天之數，骰定福禍』…骰子啊骰子，給點提示吧…」），骰子在關鍵時刻給的那些**模棱兩可的提示**，本來就是她那一點預知——只是他以為那是護身符的靈驗。**既有段落不必改寫。**

### ⚠ 能力是持有者的，不是獸給的（已定．硬規則）

**拿著骰子的人，自己就會有那頭獸的能力——或多或少。** 不是獸施捨、不是獸代勞、更不是獸提供的服務。

- **她收不回，也開不了價。** 這是「她不開價」最硬的機制保證：**那本來就不是她的東西可以給。**
- **能力的深淺看持有者**：年紀、悟性、用過多少次、知不知道自己在用。
  - **主角現在很淺**——他太小、沒人教、也不知道那是什麼，只當成「蒼天之數，骰定福禍」的吉凶把戲。**既有段落不必改寫。**
  - **他母親很深**（見 `@角色設定/天王老子.md`「故鄉大火」）。
  - **張角很深**：他重來，用的就是這條——**混沌的能力是他在用，不是混沌替他跑。**
- **代價與折損也記在持有者頭上**（見上兩條硬規則）。用得越多，掉得越快。**掉的是誰的，未定。**

### 骰子的規矩（已定）

**⚠ 四顆各有各的規則。** 四獸不是四兄弟、不是同一陣營、彼此也不合作——牠們只是**都被人皇封了**。封法跟著獸走，**四顆骰不共用一套規矩**。

**以下全部只講麒麟骰。** 混沌骰的封法與傳承**未定，本曲也不需要**——南華能把它交給張角，就表示它跟血脈那一套不一樣。**不得拿麒麟骰的規則去套混沌骰。**

**一顆骰子，一個持有者。**

- 傳承不是自然繼承，是**一個動作：交出去**。
- **交出去＝連能力一起交出去。** 前一任從此沒有了。

**持有者死了會怎樣：不是封印開，是她回到黑暗。**

- 定樁：`@角色設定/饕餮.md`「對外界的感知受限於骰子的狀態與主角的行為」——**持有者就是她的窗。**
- 他一死，她不會出來。她回到一個沒有人、沒有聲音、什麼都沒有的地方，**等下一個撿起骰子的人**。可能是一年，可能是三百年。
- **⚠ 這取代舊句「他一死，封印就開」。** 那句跟「她保護他」自相矛盾，**全案作廢**。
- **她因此有一樣真正怕的東西——但那不是目標。** 恐懼不等於計畫。她救他是**反射**，不是策略；是唯一發生過的那件事不想停下來。

**持有者靠那頭獸的能力，剛好能處理自己的死。**

- **麒麟骰的持有者有預知**，所以看得見自己什麼時候要走，**來得及交接**。這就是這條血脈傳了那麼多代沒斷的原因。
- **混沌骰的持有者能重來**，死了就倒回去（張角那個「病死」做得乾淨，本來就是這條）。
- **未定：** 這是人皇封的時候順著獸性做的，還是別的緣故。**不得發明。**

**沒交接就死了：骰子就躺在那裡。**

- 對沒有那條血的人，它只是一塊石頭——沒有能力、沒有聲音、撿了也不知道撿到什麼。**所以它可以在土裡躺幾百年而天下無事。**
- 而她在那幾百年裡，就在黑暗裡。

### 牢房、鎖、鑰匙（已定）

> **⚠ 取代舊說法「主角本人就是那把鎖，鎖不能壞」。**

- **骰子是牢房，血脈是鎖，持有者是拿鑰匙的人。**
- **個人死了不要緊**（換人拿鑰匙）；**血脈斷了才要緊。**
- 所以血脈會保住它**最後一個攜帶者**——「大難不死」走的是這條，見 `@角色設定/天王老子.md`。
- **⚠ 語意反轉更新：** 舊版是「牢房不許你死」。新版更冷——**他死不了，不是因為他特別，是因為他是最後一個。**
- **蕭靈犀不帶這條血**（她與主角無血緣，見 `@角色設定/蕭靈犀.md`），所以主角目前是唯一的攜帶者。
- **未定：** `劇情/宗緯家.md` 說那是「**消失的部族**」——世上還有沒有別的攜帶者，未定，**不得發明**。

### 人祭與凶戾（已定）

上古世人以活人血食向「天地間的貪」——也就是這幾頭獸——換取力量，**祭品越貴重，換得越多**。人中有皇，與天同級，故人皇之血是最高等級的祭品。末代人皇廢除人祭，斷了貴族換力量的門路，因而被推翻。

- **定樁：** `劇情/趙王洞(遺跡).md` 賈詡那句「殷商時期，曾有一種極其殘酷的古老祭祀。人們妄圖透過血煞與獻祭，從天那裡獲得不可思議的力量。那頭白虎妖物，不過是這種祭祀催生出的失敗品罷了。」——**白虎道妖＝殷商人祭的失敗品**，屬本土軸。
- **凶戾**＝怨、煞、邪凝成一團的實體。哪些叫得醒她、哪些叫不醒，見 `@角色設定/饕餮.md` 第四節「她什麼時候出現」。**本檔不重複列，也不得另立一份清單。**

## 四、外來：逆流河（已定）

### 它是什麼

**逆流河不是河，是兩界之隙。** 定樁文本為 `劇情/小溪村、後山的書本.md`《異聞錄・逆流河考》（貴重品 `BMItem_T13`），原文已寫死，**不改**：

> 那並非凡水，而是此方天地的惡瘡——一道兩界之隙。其水非逆流，而是將另一方天地的天理與萬物，浸染至此世。

要點：

- 漏過來的**不只是生物，還有「天理」**——所以會出現不該長在這裡的草木、不該成立的常理。
- 侵染是**緩慢而持續**的，不是一次性事件。
- 世人多半不知道它存在，偶有耳聞者也只當成水流倒行的地理奇觀。

### 從這道口進來的東西（已定）

### 河伯與異舟（已定）

- 河伯是**擱淺此地的異界旅人**，從逆流河那一側漂來、墜船於此，被村民誤認作「河神」。設定全文見 `@地點/水濂洞.md`，**本檔不重複**。
- **異舟＝逆流河產物**，不是更高一層的存在，也不是本土神跡。它之所以「像科幻」，正因為它帶著另一方天地的天理過來——這與《逆流河考》「將另一方天地的天理與萬物浸染至此世」是同一句話。
- **麒麟骰對星淚石有反應，原因已定：兩者都是「不屬於此世常理」的東西**，骰子認得出那股味道。
  - ⚠ **這不等於同源。** `@地點/水濂洞.md` 舊句「暗示兩者同源」**改讀為「彼此有所感應」**：饕餮是本土軸、星淚石是外來軸，**不同源**。不得寫成人皇的封印技術與異舟同出一處。

## 五、別的文化怎麼稱呼這一套（暫定）

**同一個世界，兩套說法。不是兩套神。**

中原用「道」講這件事；波斯祆教把同一件事講成善惡二神相爭。

| 中原說法 | 祆教（波斯）說法 |
| :--- | :--- |
| 道 | 沒有單一對應詞。他們把整個秩序講成「善惡二元相爭」 |
| 人皇那一格 | **善神 阿胡拉·馬茲達** |
| 四獸／凶戾／邪祟 | **惡神 安格拉·曼紐**，及其散落的碎片 |

因此：

- **「赤眼殘片」＝凶戾類**（本土軸的東西，被波斯人用自己的宗教語言解釋）。黑鐵嶺李大山挖到的紅水晶就是其中之一——它是凶戾核，也是阿SA 口中的惡神碎片，**兩種說法指同一顆**。
- **蔡邕的台詞不必改。** `劇情/竹林小徑.md` L198–200 他說的是「倒與那殘卷中記載的惡神崇拜**有幾分相似**」——推測語氣，正確。
- **阿SA 真心相信她那一套**，她不是在打比方。她的說法在她的文化裡是真的，只是名字不同。
- **誰也不會說破。** 本曲沒有任何角色站出來宣布「其實是同一件事」。玩家可以自己拼；主角拼不出來。
- 大秦（羅馬）、匈奴那幾支是**尋常外邦人**，不帶自己的超自然體系，別跟這一節混。絲蒂娜、赫連娜娜都不在這條線上。

**標暫定的原因：** 對照關係已定調，但「善神＝人皇那一格」到底是平行對應還是後人附會，尚未拍板。**AI 不得把這張表寫進任何角色的嘴，也不得再往下發明祆教的神職、儀式、經文。**

## 六、九黎與那場浩劫（已定／本劇不揭）

### 九黎是什麼（已定）

**「九黎」不是一個新物種，是一個統稱。** 指的是**第零節那兩條軸的怪物全部一起出來**的那場浩劫：

> **九黎＝四凶獸 ＋ 從逆流河爬進來的怪物們。**

所以它接得回層級表：叫「九黎」的東西，拆開來各自都已經在第三節（四獸與凶戾）與第四節（逆流河）裡有位置。**世人不知道那是兩種來歷，只知道怪物一起湧出來，就沿用了上古那個舊名。** 這本身就是一次「表裡真實」。

- **那場浩劫是未來式：179 年還沒發生。** 但它**以前爆發過幾次小的**（見下），而且**現在已經在冒徵兆**（見下下）。這三件事要分清楚。

### 九黎爆發過不只一次（已定）

**這個名字之所以是舊名，因為這種事以前就發生過。** 每一次「怪物一起冒出來」，當時的人都沿用上古那個稱呼。

| 什麼時候 | 發生了什麼 | 定樁出處 |
| :--- | :--- | :--- |
| **上古** | 蚩尤九黎。名字的源頭 | 典籍 |
| **戰國** | 「戰國之世，九黎橫生，**百家伐異，各闢門道**」——諸子百家有一部分就是被這件事逼出來的應對之學 | `劇情/第三章主線_開場.md` 賈詡 |
| **秦** | 「秦帝毀書，古學斷絕，殘存不過奇文異錄」——焚書把那套學問打斷了 | 同上 |
| **漢初** | 又爆一次。**三傑蒐羅戰國殘存的古學，奏請高祖廣納英雄，創立英豪府** | 同上＋`@地點/英豪府.md` |
| **179 年（現在）** | 徵兆已經在冒（見下） | — |
| **司馬家篡魏之後** | **最大的一次，而且再也停不下來。** 張角看見的就是這一次 | 見下節 |

- **兩份既有文本合起來讀，不衝突：** `@地點/英豪府.md` 說三傑「為救蒼生，奏請高祖廣納英雄討伐」（**為什麼建**）；`劇情/第三章主線_開場.md` 說「茫茫歲月，三傑尋其遺創英豪」（**拿什麼建**——戰國留下的斷簡）。同一件事的兩面。
- **英豪府因此是一個「守夜人」機構**：為了應付週期性爆發而常設，「目的是為預防怪物再現」。
- **⚠ 這讓「傳承早已斷絕」變得真的可怕**（郭嘉定樁）：守夜的組織空了，而最大的一次正在路上。**本曲不得讓任何人講出這層對照**，那是玩家日後回想時才成立的。
- **未定：** 漢初那次的規模與細節、三傑各自做了什麼、爆發是否有週期。**不得發明。**

### 179 年已經在冒徵兆（已定／本劇不揭）

**現在這些怪物不是背景雜訊，是沙漏開始漏了。** 逆流河漏得越來越兇、凶戾凝得越來越多——黑血屍、白虎道妖、赤眼殘片、狗頭人蜥人成群定居，每一件單獨看都只是「江湖上的怪事」。

- **每一個箱庭都是一顆沙。** 寫關卡時心裡要有這件事，但**不要在關卡裡點題**。
- **沒有人拼得出來。** 賈詡收著斷簡、張仲景見過那個夢、阿SA 在收碎片、蔡邕在對外邦殘卷——**四個人各拿一角，誰也沒拼齊**，而且他們彼此不通報。這正是本作「表裡真實」的用法。
- **⚠ 紅線：** 怪物**一律用本名**（黑血屍、白虎道妖、狗頭人……），不要叫「九黎怪物」；**不得**有任何角色宣布「怪物變多了，大禍要來了」。玩家玩到後面自己回頭看見圖案，那才是這條線該有的效果。
- 這也讓張角的急迫感有了現場證據：**他看得見沙在漏，別人看不見。**

### 浩劫從哪裡開始（已定）

**起點是司馬家篡魏。** 從那裡起，一切失控——中原接著走進三、四百年的動亂，五胡亂華是其中一段，不是全部。

**這一次跟前幾次的差別：前面每一次都被壓下去了，這一次沒有。** 所以它不叫「又一次爆發」，叫浩劫。

- **這是歷史影射，也是這條線的骨。** 現實歷史上那三百多年就是這麼過的；遊戲裡把「怪物一起湧出來」疊在同一條時間線上。
- **⚠ 司馬、篡魏、五胡亂華、三國歸晉這些詞一律不進遊戲文本**（對白、旁白、道具描述、異聞錄都不行）。179 年沒有人講得出這些名字。它只是給作者定調用的尺。
- **本曲離這裡很遠。** 《旭日初升》收在黃巾（184 前後），距離起點還有八十幾年。**不要**在本曲讓任何人暗示晉、暗示司馬、暗示改朝換代的細節。

### 張角是重來的人（已定／本劇不揭）

- **張角重來過，而且不只一次。** 他不是預言家、不是占卜——他**經歷過**那場浩劫，然後回到了這裡。
- **他重來得了，是因為混沌骰在他手上。** 重來是**混沌那頭獸的能力**（見第三節），不是張角自己的道行、不是太平道的法術、也不是南華教他的。**南華知不知道自己給出去的是這個——未定。**
- **⚠ 他不是每一輪都走到最後。** 混沌給的是「各種可能性」——他在**試**：這條不行就掐掉，換一條再走。多數輪次半途而廢，所以他不必每次都活到浩劫那一年。**至少有一輪他走完了，看見了那場崩壞**，那就是他不肯罷手的理由。
- **⚠ 有代價、而且會越用越弱**（第三節硬規則），**不是無限重來。**
- **他知道天下之後會被九黎踏破。這就是他要造反的理由。** 「蒼天已死，黃天當立」不是野心的修辭，是一個看過結局的人在搶時間；「這天下病了，非猛藥不能去之，我便是那味猛藥」也要照這個底色讀。
- **定樁台詞：** 「你也……見過那場夢了？物怪九黎，蒼生淪陷。」——他問這句，是因為他認得那個夢。

### 這一次是最後幾次之一（已定／作者層）

**玩家玩的這一輪，就是張角快要用完的那幾次之一。他即將迎來自己的結局。**

- 這是他身上那股急迫感的真正來源：**沒有下一次了，或者快沒有了。**
- **⚠ 這是作者層的結構，不是主角能知道的事，也不得寫成玩家全知。** 指南「不得把玩家全知寫成主角動機」那條照舊。玩家可以感覺到這大叔在趕時間；不得由任何人說破為什麼。
- **未定：** 他到底還剩幾次、他自己知不知道這是最後幾次。

### 「張角病死」是怎麼回事（已定／本劇不揭）

**史書說張角在 184 年病死。這是表。**

**裡：死掉的是「張角」這個身分，人沒死——他從此用「張仲景」活下去。**

- 兩個名字在本曲（179 年）就已經同時存在：他行醫走江湖用張仲景，宗教與起事用張角。**黃巾之後，他只留下前面那個。**
- 所以他**看得見自己「死」後的事**——他一直在，只是換了一張臉在人間走。**上一輪的浩劫他是活著看完的**，不是靠預言。
- ⚠ 史載官軍曾**剖棺戮屍**——也就是說，有一具能驗的屍體。**那具屍體怎麼來的——未定，AI 不得發明。**

**一個已經埋在既有文本裡的鉤子：** 他傳給主角的內功叫**「長生功」**（`@角色設定/張仲景.md`）。「長生」二字現在有了第二層讀法。**他為什麼活得那麼久，是不是這門功、還是混沌骰、還是別的——未定，不得發明。** 但寫新段落時可以讓這兩個字自己站在那裡，不必解釋。

### 他的結局，與玩家的努力（已定．本曲收束）

**這一格取代指南舊句「張角死不死與選擇相關」。**

**世界裡的事實，兩邊一樣：「大賢良師張角」必死（那是身分的死），而那個人活下來，成為張仲景。** 這一格歷史鎖死，玩家改不了——不然《傷寒雜病論》就沒人寫了。

**玩家的努力改變的是：他看不看得見這件事。**

| | 玩家看到什麼 | 世界裡發生什麼 |
| :--- | :--- | :--- |
| **真結局** | 大賢良師死了——**而張仲景開始了新的人生**。玩家親眼看見那個大叔還在 | 同左 |
| **一般結局** | **只知道張角死了。** 大叔就此音訊全無 | **一樣**：張仲景仍在，只是玩家（與主角）不知道 |

- **「張仲景」是張角努力換來的新人生的證明。** 這個身分不是化名、不是逃亡用的假皮——是他造反失敗之後，換一種方法繼續救人。**真結局讓玩家親眼看到這件事成立。**
- **⚠ 一般結局不是「他死了」，是「你沒看見」。** 寫一般結局時**不得**下任何「大叔死了」的旁白定論，只能停在**主角所知的範圍**：大賢良師死了，那個大叔從此沒有消息。留白，不補刀。
- **⚠ 真結局的觸發條件——未定。** 「玩家的努力」是什麼、要做到什麼程度，**尚未拍板，AI 不得發明條件。**
- **⚠ 本曲不揭「他為什麼能活下來」。** 真結局只讓玩家看見**結果**（他還在），不解釋重來、不解釋長生、不解釋混沌骰。

### 主角為什麼也夢得到（已定）

- **傳導的是饕餮，靠的是她那一點預知**（第三節）。主角反覆做的那個惡夢（并州被怪物摧毀、自己戰死城牆），跟張角經歷過的是**同一場浩劫**，透過骰子裡的她多多少少滲進主角的睡眠。
- **⚠ 未定：** 她是自己**看見了那個未來**，還是**感應到混沌那一側帶回來的記憶**——兩種讀法都還開著，**AI 不得選邊**。她自己也講不清楚（她本來就不擅長解釋，也不在乎）。
- 因此 `@角色設定/天王老子.md`「受惡夢驅使」那一條要改讀：**那不是他的預感，是別人的記憶。** 他一直以為那是自己的使命感。
- **⚠ 這不得讓饕餮變成有計畫的角色。** `@角色設定/饕餮.md` 的硬規則不變：她**沒有計畫，只是餓**。她是導管，不是敘述者——**嚴禁**寫成她刻意託夢、刻意提示、拿夢當籌碼開價。夢是漏出來的，不是她放的。

### 未定（要拍板才能往下寫，AI 不得自行發明）

1. **重來的細節：** 張角重來過幾次、**還剩幾次**、他自己知不知道快用完了、記得多少、記憶完不完整、改得動多少、代價是什麼、怎麼觸發、怎麼決定掐掉一輪重來。**一律不得發明。**
2. **真結局的觸發條件：** 「玩家的努力」具體是什麼、要做到什麼程度、在哪些關卡累積。**這是本曲收束最要緊的一格，尚未拍板，AI 不得發明條件。**
3. **他憑什麼活那麼久：** 「張角病死」已定為換身分（見上），所以他是**活著看完**上一輪的。但起點在 179 年之後八十幾年，他那時已逾百歲。**靠長生功、靠混沌骰、還是別的——未定，不得發明。**
   - 附帶未定：那具供官軍剖棺戮屍的屍體怎麼來的；他是不是**早就知道**自己會這樣「死」（他是重來的人，理應知道劇本）。
4. **饕餮那一側：** 她是自己預見了未來，還是感應到混沌帶回來的記憶。**無論選哪一種，都必須守住「她沒有計畫，只是餓」那條紅線。**
5. **兩頭獸的能力代價與折損**（第三節）：具體是什麼、怎麼表現、掉得多快。
6. **漢初那次的規模與細節**：三傑各自做了什麼、爆發有沒有週期。**起源已定**（真的爆發過、不只一次），只剩細節。
7. **英豪府「傳承斷絕」斷在哪一代、斷了什麼**：斷的是武學、是名冊、還是那批古學斷簡的讀法。

### 寫作紅線

- **九黎是未來式。** 不要把它寫成 179 年的日常敵人。
- **「張角是重來的人」本曲不揭。** 玩家可以覺得這大叔不對勁；不得由任何角色說破，張角自己也不說。
- **禁詞（連旁白、道具描述、異聞錄都不行）：** 五胡亂華、司馬、篡魏、三國歸晉、輪迴、重來、前世。
- **兩頭獸的能力不得被說破。** 骰子的「指引」在遊戲裡就只是指引；不得有人解釋那是預知，也不得有人提起混沌能重來。
- 主角不知道那個夢不是他的。**不得寫成他察覺了。**

## 七、南華老仙（暫定／本劇不揭）
