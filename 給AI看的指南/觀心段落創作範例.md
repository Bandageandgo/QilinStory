# 觀心段落創作範例：核心原則與骨架

本文件定義了「觀心」事件的核心寫作邏輯，供後續新增觀心事件時對照。

---

## 一、核心原則：四軸邏輯（念頭落點，非標籤）

選項是玩家替燕不凡決定「此念何歸」，**不是**對外台詞，**也不是**把共用內心再推理一步。

| 軸 | 問的是 | 典型落點（寫在分支，不必寫在選項） |
| :--: | :-- | :-- |
| **信義** | 我信什麼「理」？ | 恩仇分明、王法／託付哪條認哪條不認、俠的底線 |
| **仁心** | 我惦記誰？ | **具名的人**（靈犀、李四、部族……），不是空喊百姓 |
| **通達** | 換作是我怎麼過？ | 先活命、先忍、顧不上、不鑽牛角尖 |
| **機略** | 這盤棋怎麼算？ | 避險、不押強權、利害、變強有用 |

寫新段落時：先定四句推理鏈，再讓四軸各接住其中一兩句的落點。

---

## 二、核心原則：四選一含蓄寫法（勿直白對齊座標）

**反例（選項像軸名說明書）：**
> [信義] 「大俠怎能……」「他不仁，我不義。」  
> [仁心] 「底下百姓受苦……」「李四一家，還有被鎖在坑裡的人。」  
> [通達] 「換作是我……」「人還活著就行。」  
> [機略] 「國之大柄……」「不祥之物必有緣由。」

玩家一眼看出「選 1 就是信義」，失去觀心味。

**正例（像嘀咕，軸在分支才顯形）：**

| 軸 | 含蓄選項（宗緯家） | 分支收束 |
| :--: | :-- | :-- |
| 信義 | 「恩是恩，仇是仇。」 | 秦皇先壞信義，部族報仇不覺得理虧 |
| 仁心 | 「功勞那麼大，換來的卻是躲進深山。」 | 換作誰都寒心 |
| 通達 | 「守護蒼生那句？……先顧命要緊。」 | 顧不上託付，哈哈 |
| 機略 | 「靠人封侯，到頭來還不是兔死狗烹。」 | 不把寶押在秦王身上 |

| 軸 | 含蓄選項（黑鐵嶺） | 分支收束 |
| :--: | :-- | :-- |
| 信義 | 「鐵門一鎖便把命鎖死……說得過去嗎。」 | 逼人當祭，告示再狠也不能這樣關人 |
| 仁心 | 「李四額頭磕成那樣……不是傳聞。」 | 大山、媳婦、活生生的人 |
| 通達 | 「礦渣都不敢私留……誰受得了。」 | 腦後懸刀，除了忍還能怎麼辦 |
| 機略 | 「這種事，知道就好，別深挖。」 | 封門了事，少蹚這趟水 |

| 軸 | 含蓄選項（趙王洞） | 分支收束 |
| :--: | :-- | :-- |
| 信義 | 「祈求牠？……就算死，我也不答應。」 | 劈自己選的路，死也不認這命 |
| 仁心 | 「這股力量太邪……絕不能讓它傷了自己人。」 | 最駭人的是差點傷同伴，拼死壓制 |
| 通達 | 「管它什麼力量，現在沒事就好。」 | 既然還能想這些就算我做主，走一步看一步 |
| 機略 | 「若是這『吞噬』之力能為我所用……」 | 管它是妖是魔，只要能變強就由我來做主 |

**要訣：**
- 選項宜短、口語、可與鄰項語意略重疊。  
- **避免**在選項裡堆軸關鍵詞：大俠、百姓、換作是我、國之大柄、行俠、算盤。  
- 分支內心再點明落點即可，亦忌說教（「這才叫務實」「行俠認的是理」等能省則省）。

## 三、段落骨架

| 步驟 | 內容 | 注意 |
| :--: | :-- | :-- |
| 1 | 回憶（畫面／台詞／可讀文本） | 玩家當場經歷的素材 |
| 2a | 轉場旁白①：盤膝，回憶凝成文字 | 不複述細節，只寫「靜坐＋浮現」 |
| 2b | 轉場旁白②：**七言殘響** | 濃縮主題；水滸／說書腔；格式見下 |
| 2c | 麒麟骰（完整包裝）`SetContinueMode(false);SetContinueMode(true)@Message(EndRoll);Continue()@Message(EndRoll);BeginDiceRoll(Auto,InsightCheck,2);` | 難度 2；**禁止**只寫 `BeginDiceRoll` 或 `DiceRoll` |
| 3 | 共用內心 ×4 | **推理鏈**，非逐句拆解回憶 |
| 4 | 四選一（信義／仁心／通達／機略） | 各對應一條推理的「落點」 |
| 5 | 分支內心 ×1 | 收束該軸的念頭 |
| 6 | 共通收尾 | 固定，勿改 |

## 四、七言殘響格式

```
**七字句，七字句；七字句。短尾！短尾！**
```

- 前兩句各七字，以分號連接；第三句七字以句號收束。  
- 尾句二至四字，感嘆收束（如「罷！罷！」「且由天！」「莫覆轍！」）。  
- 語感參考《水滸》阮歌、章回開詩；可化用典故，勿整首照搬。  

---

## 五、共用內心：推理鏈（勿用「逐句複讀」）

**反例（刻意、像複讀石刻）：**
> 「**極西之地**……他們不是中原人。」  
> 「**助秦王掃六合**……功勞不小。」  
> 「**不願為奴**……封印河口。」  
> 「**守護蒼生**……留給我？」

每句只摘石刻關鍵詞，像做筆記，缺少燕不凡自己的推敲。

**正例（自問自答、句句推進）：**
1. **起疑**：石刻說 **極西之地** → 不是中原人 → 可極西是哪？從沒聽說過。  
2. **再推**：**助秦王掃六合** 功勞大 → 秦王卻為 **欲求長生** 緊追 → 與他們何關？  
3. **接問**：**不願為奴** 躲進大山 → 還那麼執著 → 難道跟長生有關？  
4. **收束**：**守護蒼生，勿蹈秦王覆轍** → 沒頭沒尾。

四句形成一條思緒；**加粗**只標錨點，不全文照抄回憶。

## 六、與回憶素材的分工

| 層級 | 功能 |
| :-- | :-- |
| 回憶 | 客觀發生什麼（旁白、NPC、可讀長文） |
| 七言殘響 | 詩意濃縮、定調 |
| 共用內心 | 主角怎麼想、哪裡想不通 |
| 四選一 | 玩家選擇「此念何歸」 |
| 分支內心 | 該軸下的結論 |

回憶裡已寫清楚的資訊，內心不必再講一遍；內心只寫**疑問、推論、情緒**。
