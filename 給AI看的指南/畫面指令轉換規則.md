# 畫面指令轉換規則（對話背景圖／轉場／畫面特效）

本文件說明三組**畫面層**指令在劇情 Markdown／JSON 裡怎麼放：對話背景圖（`EnableDialogueBG`／`DisableDialogueBG`）、轉場（`PlayFeelFeedback(FadeInOut…)` 複合指令）、畫面特效（`PlayOrStopParticle`／`StopAllParticle`）。三組規則與 ID 表皆**依 `Json/` 現行用法擷取**（2026-08-27 作者拍板收錄），轉 JSON 另見 `劇情/轉成json指南.md` §3.7～§3.9。

引擎標記不受文風審校約束；但**漏關**（背景圖沒關、特效沒關、轉場沒 `Continue()`）在遊戲裡是肉眼可見的錯，**視同錯字**。

## 0. 三條鐵則

1. **養成模式的任務對話：首格開對話背景圖，尾格關。** 沒關，回到養成介面時背景圖會蓋住養成 UI。
2. **凡是「畫面要切」就走轉場複合指令，四段固定**：禁止點擊 → 轉場 → 恢復點擊 → `Continue()`。缺任何一段畫面會卡住或閃畫面。
3. **畫面特效有開就有關。** `Play` 之後，下一格（或特效該結束的那格）`Stop`；場面收尾用 `StopAllParticle()` 清乾淨。

## 1. 對話背景圖 `EnableDialogueBG` / `DisableDialogueBG`

### 1.1 用在哪

- **養成模式的探險事件**：`Json/主線事件/`、`Json/探索事件/` 底下的主線任務、支線任務對話。這些對話是從養成介面點出來的，畫面本身沒有場景，**要靠背景圖撐場**。
- **箱庭（大地圖／小溪村／破廟／趙王洞……）**：走 3D 場景，**平常不開**；只有劇情臨時切進室內插圖（例如進屋、進遺跡）才開，離開該段時照樣要關。
- 事件圖 `EnableEventBG(圖檔ID,FullScreen)`／`DisableEventBG(FullScreen)` 是另一套（全螢幕插圖，圖在 `圖檔/`），本節不管；兩者切換時的寫法見 §2.3。

### 1.2 首格：開

背景圖指令放**該對話第一個節點**的 `Sequence` **開頭**，在 `SetPortrait` 之前：

```
"Sequence": "EnableDialogueBG(TrainingGround);SetPortrait(MC1,pic=1);AudioControl(PauseLowerMusic);AudioControl(PlayMusic,BGM_19);"
```

既有稿另一種常見寫法：對話前面多一個空白起始格 `actorID "MC1"`、`text "「...」"`、`Sequence "SetPortrait(MC1,pic=1);EnableDialogueBG(Forest);Continue();"`（`Continue()` 讓它自動跳過）。兩種都合法；**新寫的稿用第一種**（少一格），除非第一格本來就是擲骰或轉場等不能摻立繪的功能節點，才把背景圖放進前置空白格。

Markdown 寫法（第一句旁白或台詞底下）：

```
**旁白:**：[panel=6]＊（你來到後山，卻見童淵並未練槍……）＊

**Sequence EnableDialogueBG(TrainingGround);SetPortrait(MC1,pic=1);**
```

### 1.3 尾格：關

對話**每一條結尾**都補一個獨立空節點：

```json
{
  "entryID": 3898,
  "actorID": "0",
  "text": "",
  "Sequence": "DisableDialogueBG();Continue();",
  "links": []
}
```

- `text` 為 `""`，所以 `Continue();` **必寫**（同擲骰緩衝格的道理，否則卡住）。
- **有幾個結尾就關幾次**：擲骰成功／失敗各自收尾、選項分岔各自結束，每條 `links: []` 的路都要落在一個 `DisableDialogueBG();Continue();` 上（`探索事件/179年/3月.json` 一段四個結尾、四個關背景格）。
- 尾格可以順便收其他東西：`DisableAllCharacterExpression();DisableDialogueBG();Continue();`、`DisableDialogueBG();StopAllParticle();Continue();`、`DisableDialogueBG();MapLock(JinYangArena, unlock);Continue();`。**`DisableDialogueBG()` 放在 `Continue()` 之前。**
- 尾格是結束後**銜接養成介面**用的；若對話結尾是 `ShowEnding(...)`、`LoadLevel(...)` 直接離開養成模式，既有稿有時省略——**新稿一律不省**，多關一次不會壞，漏關會。

Markdown 寫法（劇本最後一句底下獨立一行）：

```
**Sequence DisableDialogueBG();Continue();**
```

### 1.4 中途換景

同一段對話從甲地跳到乙地，**不要**裸寫 `EnableDialogueBG(乙)`——畫面會硬切。走 §2 的轉場複合指令，把 `EnableDialogueBG(乙)@1` 夾在黑幕裡。直接 `Enable` 新 ID 就會蓋掉舊圖，不必先 `DisableDialogueBG()`；只有切去**事件圖**時才需要 `DisableDialogueBG()@1;EnableEventBG(...)@1`（兩層不同）。

## 2. 轉場

### 2.1 固定複合指令（黑幕淡出再淡入）

```
SetContinueMode(false);PlayFeelFeedback(FadeInOut,1,0.5,1,#000000,1);［畫面全黑時要做的事］@1;SetContinueMode(original)@2.5;Continue()@2.5;
```

| 段 | 指令 | 作用 |
| :--- | :--- | :--- |
| ① 禁止點擊 | `SetContinueMode(false);` | 轉場期間玩家點不動，免得黑幕中被點過去 |
| ② 轉場 | `PlayFeelFeedback(FadeInOut,1,0.5,1,#000000,1);` | 1 秒淡黑、停 0.5 秒、1 秒淡回，共 2.5 秒。**參數照抄，不要調** |
| ③ 黑幕中換景 | `EnableDialogueBG(新ID)@1;` 等 | 掛 `@1`＝畫面全黑那一刻才做，玩家看不到切換的瞬間 |
| ④ 恢復點擊 | `SetContinueMode(original)@2.5;` | 淡回完成才還回點擊。**一律 `original`，不寫 `true`**（同擲骰四段包裝，見 `擲骰指令轉換規則.md`） |
| ⑤ 推進 | `Continue()@2.5;` | 轉場格本身沒台詞，不 `Continue` 會停在黑幕後的空格 |

- 轉場格是**獨立空節點**：`actorID` 用 `"0"`（既有稿也有 `"role2"`），`text` 為 `""`，**不得**與台詞、`SetPortrait`、`BeginDiceRoll`、`BeginFight` 合併。
- `Json/` 全案這條複合指令原樣出現 30 餘處，是**唯一標準寫法**；`@2.5` 對應轉場總長，`@1` 對應全黑時刻，兩個時間點不要改。
- 第③段可以掛多條，全部 `@1`：換背景圖、`OpenPanel(N, close)@1`（收掉位置 N 的立繪面板，舊立繪才不會留在新景裡）、`DisableCharacterExpression(N)@1`、`ModifyData(GameDate,…)@1`／`ModifyData(Rest)@1`（時間跳躍）、`AudioControl(PlayMusic,BGM_xx)@1`。沒有東西要換也可以整段照用（純粹表示「過了一陣子」）。

### 2.2 什麼時候要轉場

**畫面要切就轉場**，具體是：

- 換對話背景圖（§1.4）。
- 對話背景圖 ⇄ 事件圖之間切換（§2.3）。
- 時間跳躍：「翌日」「數日後」「入夜」——配 `ModifyData(GameDate,年,月,Early|Late)@1` 或 `ModifyData(Rest)@1`。
- 換場景：`LoadLevel(...)`、進結局 `ShowEnding(Ending_N)@1`。
- 劇情上「昏過去／醒來」「一段路程」。

**不要轉場**：同景、同時間、只是換人講話；立繪換位、單純換 BGM。

### 2.3 常見變體（照抄）

- **切到事件圖**（全螢幕插圖）：
  `SetContinueMode(false);PlayFeelFeedback(FadeInOut,1,0.5,1,#000000,1);OpenPanel(1,close)@1;DisableDialogueBG()@1;EnableEventBG(圖檔ID,FullScreen)@1;SetContinueMode(original)@2.5;Continue()@2.5;`
- **從事件圖切回背景圖**：
  `SetContinueMode(false);PlayFeelFeedback(FadeInOut,1,0.5,1,#000000,1);DisableEventBG(FullScreen)@1;EnableDialogueBG(背景ID)@1;SetContinueMode(original)@2.5;Continue()@2.5;`
- **只淡黑不回來**（接結局、接觀心、段落收尾在黑幕）：
  `SetContinueMode(false);PlayFeelFeedback(FadeOut,1,#000000,1);SetContinueMode(original)@1;Continue()@1;`
- **從黑幕淡入**（一段的開場、醒來）：
  `SetContinueMode(false);PlayFeelFeedback(FadeIn,1,#000000,1);Continue()@1;`
- **轉場前先清特效**：`SetContinueMode(false);StopAllParticle();PlayFeelFeedback(FadeInOut,…);…`（見 §3.3）。

### 2.4 禁止

- `SetContinueMode(true)`——會把玩家的手動模式改成自動推進。
- 只寫 `PlayFeelFeedback(FadeInOut,…)` 不包四段（玩家在黑幕中點擊會跳格、或轉場後卡住）。
- 把 `EnableDialogueBG` 不掛 `@1` 直接寫在轉場格開頭（畫面還沒黑就換了）。
- 轉場格塞台詞、立繪、擲骰、戰鬥。
- `SetContinueMode(false)` 與 `Continue()@Message(...)` 各寫兩次（複製貼上殘留，`大地圖/水濂洞.json` 有此舊錯，勿仿）。

### 2.5 Markdown 寫法

轉場在劇本裡獨立一行、上面**沒有台詞**，轉 JSON 時自成一個空節點：

```
**旁白:**：[panel=6]＊（──行至中途，你發現前方有熟悉身影在採藥。）＊

**Sequence SetContinueMode(false);PlayFeelFeedback(FadeInOut,1,0.5,1,#000000,1);EnableDialogueBG(Forest)@1;SetContinueMode(original)@2.5;Continue()@2.5;**

**蕭靈犀:** [panel=1]「表哥，你看！小犀找到了很多沒見過的藥草呢！」
```

## 3. 畫面特效 `PlayOrStopParticle` / `StopAllParticle`

### 3.1 指令

```
PlayOrStopParticle(特效ID,Play);
PlayOrStopParticle(特效ID,Stop);
StopAllParticle();
```

### 3.2 有開就有關

- `Play` 掛在**特效發生那句**的 `Sequence`（可與 `SetPortrait`／表情同格）。
- **下一格**的 `Sequence` 開頭掛同 ID 的 `Stop`——寫法比照 `DisableCharacterExpression`：上一句的特效，下一句先關。
- 特效要跨幾句（煙霧籠罩整段對話、雨下到離開）才往後延到「特效該結束的那格」關；**不能不關**。
- 一格同時 `Play` 兩個以上（例：`Punch_Single_ScreenRed` ＋ `BloodSplash_Left`），關的時候一個一個 `Stop`，或直接 `StopAllParticle();`。
- ⚠ 既有稿裡煙霧／黑雲／血跡／觀心類都有關，但不少打擊類（`Punch_*`、`Sword_*`）沒關。**新稿一律關**，不要照抄那些漏關的節點。

範例：

```json
{ "entryID": 39, "text": "[panel=6]＊（塵土飛揚……）＊",
  "Sequence": "SetPortrait(MC1,pic=3);PlayOrStopParticle(Smoke_Dust,Play);" },
{ "entryID": 40, "text": "[panel=1]「咳咳……這是什麼鬼地方？」",
  "Sequence": "PlayOrStopParticle(Smoke_Dust,Stop);SetPortrait(MC1,pic=4);" }
```

### 3.3 `StopAllParticle()` 清場

一次把所有特效關掉，用在：

- 轉場複合指令裡，緊接 `SetContinueMode(false);` 之後（§2.3 末條）。
- 對話尾格：`DisableDialogueBG();StopAllParticle();Continue();`。
- 一段動作戲結束、畫面要靜下來的那格。

有了 `StopAllParticle()` 就不必再逐一 `Stop`，但它**不能取代** §3.2 的「下一格關」——一次性打擊特效若拖到轉場才清，中間幾句畫面都會留著。

### 3.4 打擊組合（既有稿寫法）

打擊特效常配畫面震動並鎖 1.5 秒點擊，整格照抄：

```
SetPortrait(MC1,pic=4);SetContinueMode(false);PlayOrStopParticle(Punch_Single_ScreenRed,Play);PlayOrStopParticle(BloodSplash_Left,Play);SetGameObjectShake(P0,ShakeNormal,XYAxis,1,20,0);SetContinueMode(original)@1.5;Continue()@1.5;
```

（此格 `text` 為 `""`，所以有 `Continue()@1.5`；若掛在有台詞的句子上則不寫 `Continue()`。）下一格 `PlayOrStopParticle(Punch_Single_ScreenRed,Stop);PlayOrStopParticle(BloodSplash_Left,Stop);`。

### 3.5 有主的特效，不要隨手用

| 特效 | 歸誰管 |
| :--- | :--- |
| `Meditate`、`Meditate_*DiceLight` | 觀心段落，見 `觀心段落創作範例.md` |
| `DiceTransition_*`、`DiceShow_Red` | 骰子演出；`DiceShow_Red` 只用於饕餮初登場（`Json/古墓演出劇情.json`） |
| `TaotieAura`、`TaotieAura_Loop` | 饕餮，段落須過 `@角色設定/饕餮.md` 第十節 |
| `SecretSpot`（背景檢定） | 系統檢定用 |

一般劇情只用 §3.6 表裡的打擊、環境、氣氛三類。
