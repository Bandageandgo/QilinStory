# 貴重品指令轉換規則

本文件說明如何在劇情 Markdown／JSON 中給予玩家物品。轉 JSON 見 `轉成json指南.md` §3.6。

## 目前沒有一般道具

劇情裡給玩家的東西**一律是貴重品**。沒有「一般道具／背包道具」這套系統，**不要**寫 `Inventory` 或 `AddItem`。

## 正確指令

```
ModifyData(Valuable,Player,DragonHorn,1);
```

-   `Valuable`：資料類別（貴重品）。
-   `Player`：主角（CSV 範例有時寫 `MC1`，劇本慣例用 `Player`）。
-   `DragonHorn`：貴重品 ID。**依該件實際 ID 替換**，必須是英文 ID，不可寫中文名。
-   `1`：數量（或該貴重品系統要求的數值）。

可與立繪／表情寫在同一條 Sequence：

```
**旁白:**：[panel=6]＊（…… **【獲得貴重品：蛟龍角】**）＊
**Sequence DisableCharacterExpression(3);ModifyData(Valuable,Player,DragonHorn,1);**
```

## 禁止的舊寫法

| 錯誤 | 正確 |
| :--- | :--- |
| `ModifyData(Inventory,AddItem,DragonHorn,1);` | `ModifyData(Valuable,Player,DragonHorn,1);` |
| `ModifyData(Inventory,AddItem,RiverGodsTear,1);` | `ModifyData(Valuable,Player,RiverGodsTear,1);` |
| `AddItem(FanZhenCao,1);` | `ModifyData(Valuable,Player,FanZhenCao,1);` |

CSV「特殊標籤」亦以 `ModifyData(Valuable,...)` 開頭，但**沒有數量參數**（例如 `ModifyData(Valuable,MC1,SwordProficiency);`），那是標籤不是物品，不要拿來發蛟龍角。

開啟貴重品便籤：`ShowValuableMemo(TaiXuanJing);`（與獲得指令分開）。
