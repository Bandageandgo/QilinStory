> **全新場次。** 材料出自 `@角色設定/呂信.md` 基本設定「他人評語（賈詡）」——**該條至今全案沒有用過**，而角色檔自己標明它「**可成為呂信內心的一根刺，也可成為他日後自我辯解的伏筆**」。
> **⚠ 這一支把那句評語落地，而且是落到主角手上，不是落到呂信臉上。** 賈詡對主角說，主角決定要不要轉述。

## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關的特殊處：主角手上拿到的是一句話，而那句話是一把刀。**

| | 內容 |
| :--- | :--- |
| **那句話** | 賈詡評呂信：**與其說像項羽，更像英布** |
| **為什麼是刀** | 呂信極度崇拜項羽。**而那個「純粹」的內容是——輸了不替自己找退路（烏江有船，他沒上）**；英布正好相反，他一輩子都在找位置，換過邊、不只一次，最後謀反被誅 |
| **俠的做法** | 據實以告。**你等於當面告訴他：師父看出你是會替自己找退路的那種人** |
| **管用的做法** | 挑好聽的說。**你保住了關係，他繼續當你的大哥** |
| **⚠ 而管用那條更傷** | 因為**他本來就想聽那個**。你給了他他要的東西，而他信了 |

**⚠ 這一關與 `劇情/舊創作稿/羽之演武.md` 的「好紅的臉」不同，不要寫成同一個引擎。**

- 〈羽之演武〉：**你拿一個人的痛處去打他**，為了過關。
- 〈英布〉：**你手上有一個人的痛處，而他自己開口問你**。你要決定給他什麼。

**前者是攻擊，後者是回答。** 這一關沒有「用它獲得好處」的選項——**它只有「說什麼」。**

### 這一關扣在他那本帳上

依 `給AI看的指南/文本創作指南.md` 0.2.2：

| 呂信 | 正 | 反 |
| :--- | :--- | :--- |
| — | 不擇手段是為了重建英豪府（**重感情還在**） | 為了出人頭地、倚仗武力，**變質** |

**「英布」就是那個「反」的名字。** 賈詡等於提前把答案講出來了，而且講得很準——**驍勇絕倫，卻少了項羽那種純粹，多了一點現實與野心，更懂得在亂世裡為自己找位置。**

**⚠ 本關不做結算，只讓玩家第一次看見那個「反」長什麼樣子。** 結算點在哪一關、門檻多高＝**未定，AI 不得發明。**

**⚠ 寫法紅線：**
1. **呂信不承認這件事扎到他。** 他問得像隨口問，聽完像沒事人。**全關他不得說出「賈師父是不是覺得我……」這種話。**
2. **賈詡不承認那句話是他說的，也不否認。** 依 `@角色設定/賈詡.md`：對外話術克制、**習慣把風險與責任推回執行者**。
3. **不得有人提「呂布」「三姓家奴」「日後背主」。** 那是玩家的知識，不是角色的。
4. **⚠ 也不得讓任何人替呂信辯護或定罪。** 這一關只把那句話遞出來，**誰都不下判語**。

## 附錄二：設計筆記

1. **那句評語不落到呂信臉上，落到主角手上——這是整關的設計核心。** 如果讓賈詡當面說，那是賈詡的戲；讓主角轉述，才是玩家的戲。**而且它自然而然地變成一個「你要說什麼」的選擇，不必硬掰一個引擎。**
2. **「管用」那條比「俠」那條更傷，而玩家未必察覺。** 挑好聽的說，保住了關係、換來一夜暢快的酒——**代價是他繼續不必面對那件事。** 這一關不點破，只在洞悉成功時給玩家看見「他其實知道」。
3. **洞悉改變的不是結果，是性質。** 沒看穿：你騙了他。看穿了：**你們合謀。** 同一個選項，同一段對白，玩家的感受完全不同——**這比多給一個選項有效得多。**
4. **賈詡從頭到尾沒承認那句話是他說的。** 「你是替誰問的」（不是問句）、「不必答」、「你要拿這些去跟誰說什麼，是你的事」——**三句都在把責任推回主角**，這正是 `@角色設定/賈詡.md` 寫的「用幾句話定義邊界，再把風險和責任推回執行者」。
5. **項羽那三遍是為了「烏江有船，他沒上」那一幕。** 呂信講故事會偏題，但那個結尾他每次都講——**他自己不知道自己在強調什麼。**

   **⚠ 史實校正（2026-08-25）：** 初稿寫的是「項羽到死都沒有換過主子」，**那句是錯的，已刪**。項羽有主子（項梁立熊心為楚懷王、後尊義帝），而且**他殺了主子**：鉅鹿之戰前懷王以宋義為上將軍壓在他頭上，項羽殺宋義奪權；其後遷義帝於郴縣並派人弒殺——**奉命動手的人之中就有英布**。**所以「忠不忠」是錯的軸，這兩人在這件事上是同謀。**

   **真正的軸是角色檔原句寫的那一組：「悲劇英雄式的純粹」對「更懂得在亂世裡為自己找位置」。** 講白了就是——**項羽輸了不肯替自己找退路（烏江有船而不上）；英布一輩子都在找位置，而且找得很準。** 賈詡 §2-1 那句與本節的路標都已照此改寫。

   **⚠ 任何後續段落都不得再以「忠誠／背主」當作項羽與英布的對比軸。**
6. **「從那天起，他不再講烏江了」** 是說實話那條唯一的長期代價，而且不解釋。**不得補寫他為什麼不講。**
7. **⚠ 紅線再說一次：** 不得有任何人提「呂布」「三姓家奴」「日後背主」。**玩家知道，角色不知道——這一關全部的重量都靠這個落差撐著。**
8. **⚠ 待填：** 無。本支無戰鬥、無小遊戲、無貴重品、無數值門檻，**可直接進 JSON**。
