## 場景與人物（供讀劇情用；自舊創作稿 `黑鐵嶺礦坑.md` 搬入）

**地點：** 雲中三十里外的黑鐵嶺，原為官營鐵礦。礦工挖到不祥之物後接連發瘋失蹤，官府鎮壓不住，索性封坑了事。坑口木門貼滿殘破符咒，旁有看守屋與一口枯井。
**核心衝突：** 李大山私藏一塊紅色晶體、將它嵌上泥塑人像充作「神眼」，礦工在坑底成了祭品；玩家在祭壇前要決定救人、殺人，還是順從殺意。
**主要獎勵：** 寒鐵礦（蒲元的委託，`CF17`）、糖炒栗子、血池淬體（大幅內功經驗）、救人線的張氏醫術之約。
**登場人物：** 燕不凡（`MC1`）、赫連娜娜（`MC22`）、李大山（`role128`）、張氏（`role129`）、阿婆（`role5`）。
**任務旗標：** `CF16`（礦坑主線，條目 1 開門／水井、條目 2 深入、條目 3–5 三種收場）、`CF17`（寒鐵）、`CF18`（阿婆）、`CF21`（血池，踏入即 `active`、毀池或失敗即 `abandoned`）、`Variable["GodSlayerDestiny"]`（血刀隱藏選項）、`Variable["KillKill"]`（殺意）、`Variable["BlackIronRidgeMineFirstJump"]`（首次垂鍊而下）。
**本檔 20 個入口：** 開場 → 木門 → 枯井 → 坑內開場 → 告示板 → 休息室 → 食堂 → 未寄出的信 → 礦石 → 石桌孔槽 → 黑刀插槽 → 石門 → 機關開啟 → 監獄 → 深淵洞口 → 地底密室 → 血池 → 阿婆 → 水道 → 祭壇。
