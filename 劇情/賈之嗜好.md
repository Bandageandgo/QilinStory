## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關的特殊處：主角第一次嘗試，用的就是俠的做法——而它當場失敗了。**

| | 內容 |
| :--- | :--- |
| **俠的做法** | 「晚輩今日確實一片赤誠。」——這句話沒有半個字是假的 |
| **它的下場** | 「朽木難雕。賈某今日還有要事，你請回吧。」**被請出門，一句多的都沒有** |
| **管用的做法** | 八百錢。**或者四百錢加一張嘴**，把一半的錢說成整份的誠意 |
| **哪裡不是俠** | 這是行賄。**兩條都是。** 差別只在一條付得乾脆、一條付得漂亮 |
| **主角學到什麼** | 「真心誠意」在這扇門後面是有匯率的。**而他學會了，還用了** |

**⚠ 這一關沒有「俠」的過關路，這是刻意的。** 第一次的赤誠已經演過、也輸過了；玩家回頭再來的時候，手上只剩管用的做法。**不要為了平衡再補一條清白的過關路**——那會把這一關唯一的重量拆掉。

**⚠ 賈詡的寫作紅線（`@角色設定/賈詡.md`、`@地點/英豪府.md`）：**
1. **他不說，也不暗示他為什麼重建英豪府。** 不得讓他自陳、不得讓他解釋九黎。本關他只是一個在解剖屍體、順便收錢的人。
2. **不得寫成什麼都早就知道的萬能 NPC。** 他認得主角是故人之子，**但本關一個字都不提**。
3. **不得讓他宣布「怪物變多了」。** 桌上有幾具屍體就是有幾具，不作結論。
4. **怪物一律用本名**（`給AI看的指南/世界觀.md` 第六節）：本關出現的是**黑血屍**，不得寫成「九黎怪物」。

**⚠ 賈詡不在 0.2.2 帳上，本關不做結算。** 只留一個記錄用的樁，見附錄一。

## 附錄二：設計筆記

1. **這一關的重點不是錢，是「主角先誠實過一次」。** 如果直接讓玩家在第一次見面就選「掏八百」，這一關就只是一個付費門。**必須先讓他把最漂亮的那句話說出口、然後被兩個字打發掉**，後面那袋錢才有重量。
2. **口才那條比八百錢那條「更管用」，這是刻意的。** 四百錢買到同一扇門，還多賺一句「該報，該報」。**遊戲不該懲罰玩家聰明**——高概念要的是讓玩家發現「原來這也管用」，而不是讓他覺得自己作弊。真正的代價寫在收尾那句「高興得沒有想像中那麼久」。
3. **洞悉在這一關放在「事成之後」。** 前面兩關（〈仗義疏財〉在人頭那一拍、〈羽之演武〉在躺地上那一拍）都放在事情正發生的當下；這一關放在事情已經辦完、鬆一口氣的時候——因為賈詡的怪，是要等事情辦完了才看得出來的。
4. **小犀的八百錢是喜劇，也是帳。** 依 `@角色設定/蕭靈犀.md`，她對錢的執著源於不安全感而非貪婪。所以她的反應要是**真的痛**（三個月飯錢），不能只當笑點收掉——那筆錢是真的沒了。
5. **黑血屍那一具屍體，賈詡一個字都沒提。** 他不知道那跟主角有什麼關係，主角自己認出來，玩家自己涼一下。**不要讓他開口點破**——一旦點破，他就變成萬能 NPC 了（紅線 2）。
6. **「談事講究真心誠意」與「不必謝，這是買賣」是同一個人。** 前一句是考題，後一句是答案。他從頭到尾沒有騙人——**是主角自己以為那句話講的是誠意**。
7. **可延伸：** 過了這一關的玩家，接的就是 `劇情/舊創作稿/趙王洞(山賊窩).md` §0 的派任（賈詡的第一個委託；⚠ 該段從未轉檔進 JSON，見 `劇情/趙王洞.md` §1 疑點乙-6）。兩段並看，賈詡這條線才有頭有尾：**他先跟你收了錢，然後才派你去做事**——順序不能反。
