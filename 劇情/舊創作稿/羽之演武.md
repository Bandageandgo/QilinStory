## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關的特殊處：這一關的「管用的手」，是主角自己看出來的。**

| | 內容 |
| :--- | :--- |
| **這一手是什麼** | 打不贏他，就不打了——**丟開兵器賭他的規矩**，或者**說出那三個字**。兩樣都不必比誰的刀快 |
| **哪裡管用** | 兩條都真的過得了關。丟兵器那條連傷都不必受；那三個字更快，一句話就結束了整場考試 |
| **哪裡不是俠** | 一個是拿他的「義」當武器（他不斬手無寸鐵之人，所以你就空手），一個是拿他壓了半輩子的病當武器。**話本裡這叫機智應變，手法不是** |
| **主角的位置** | **這一關他自己動手。** 而且那隻手是他先「看清楚一個人」才拿到的——洞悉成功，才會出現第三個選項 |

**⚠ 這一關的洞悉，跟〈仗義疏財〉的洞悉方向相反。**

- 〈仗義疏財〉：看清楚一個人，是為了**看懂他為什麼那樣做**。
- 〈羽之演武〉：看清楚一個人，是為了**知道打哪裡最痛**。

**同一個檢定、同一句「你要不要看清楚這個人」，得到的是一把刀。這就是高概念那句「每一手都管用」最乾淨的一次演出。**

**⚠ 子羽在 0.2.2 帳上**（2026-08-25 補開；六本帳為張角／呂信／郭嘉／子羽／饕餮／主角）。**但本關不做結算**——他的結算點在 `劇情/歸姓.md`（人物結局）。本關留的三個 flag **只是記錄，不是分數**：一用途是往後場次裡「他怎麼看你、站得離你多遠」，二用途是那本帳的入口。詳見附錄一。

**⚠ 寫法紅線：**
0. **那三個字全劇只發作這一次。** 主角是**第一個**對他說「好紅的臉」的人（舊稿裡是蕭靈犀，已廢）。5-3 之後，**往後任何場次不得再讓任何人說一次**——包括不得寫成「有人又說了」的旁白。用掉了就沒了。
1. **子羽不解釋自己的紅臉。** 全關他一個字都不提殺心、不提亡命、不提妹妹。玩家要嘛從洞悉看出「他在忍別的東西」，要嘛看不出來。**看不出來是允許的結果，不是懲罰。**
2. **不得把〈機略〉那條寫成「主角失手」。** 那是主角**知道會怎樣、還是說了**——知情的選擇才有重量。
3. **子羽認罰不認錯**（`@角色設定/子羽.md` 性格特質 4）。他破了規矩會自己去領罰，但**不會道歉**，也不會說「我不該砍你」。

## 附錄二：設計筆記

1. **為什麼把洞悉放在「躺在地上」那一拍。** 這是全關唯一一個主角**沒有別的事可做**的時刻——不能打、不能跑，只能看。而他看到的東西會變成武器。**〈仗義疏財〉的洞悉讓你看懂一個人，這一關的洞悉讓你拿到打他的地方**，兩關並看，高概念那句「每一手都管用」才立體。
2. **失敗不懲罰。** 依指南 0.2.3，擲骰失敗＝「這條路沒開」。內功失敗＝昏過去、厚黑失敗＝被拍飛，兩者都只是**這次沒過，改天再來**，沒有人死、沒有人殘廢。**主角在 5-3 的重傷是他自己選來的，不是骰子判的**——這條界線要守住。
3. **通達那條刻意不給入門禮。** 三條過關路的獎勵不一樣，這本身就是內容：戰勝與站起來拿到那一招（他認你的武／你的骨氣，**所以他有東西要教你**）；丟兵器那條他只認你賭贏了，**沒有東西可教**；那三個字那條他自己走了，什麼都沒留。**贏的方式不同，拿到的東西就不同**——不必用數值講。
4. **子羽全關不提殺心。** 他最接近自陳的一句是「用得上的，不會只有你一個」——那不是告白，是警告。`@角色設定/子羽.md` 的「簡短斷語，不解釋、不抒情」在這裡照辦。
5. **《春秋》出現三次，都不解釋。** 開場他在讀、通達尾他攤著書半天沒翻頁、5-3 他走後風把書翻過兩頁。這是角色檔性格特質 6 的「他內心渴望大義的證明」，**用道具演，不用嘴說**。
6. **小犀不進武館，而且這一點現在是硬規則。** 依 2026-08-25 拍板，**本場就是初遇**，舊稿裡「蕭靈犀無心說過同樣那句話」的場面已廢——所以 **5-3 那三個字，主角是第一個說的人，也是唯一一個。** 她若在場，5-3 就會變成另一個故事（誰先說的、他認不認得出來），而那個故事本作不演。<br>**⚠ 不得為了加重量而回頭補一個「有人曾經說過」的前情。** 那正是被廢掉的東西。
7. **可延伸：** 若〈呂之門路〉日後補寫，兩支遴選考題剛好是一組對照——呂信教你**摸金**（他把管用的手直接交到你手上），子羽逼你**自己找出**管用的手（他什麼都沒教，你卻學會了）。
