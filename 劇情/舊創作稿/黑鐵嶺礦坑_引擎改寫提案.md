## 一、結論先講

**引擎換了，這個箱庭維持三選一，但拆分方式與解鎖條件都要換。**

1. **【血刀】改用「威嚇專長」檢定，不再靠命盤解鎖。** 命盤／退格已廢案，「需解鎖血刀命盤」這個前提不能留。改成看角色是否具備、以及威嚇修為夠不夠：**檢定成功→只有李大山死，張氏被嚇住但活著；檢定失敗→張氏一起死**（原文結果，保留）。
2. **【血刀】跟【殺伐】的差別不再是「殺一個還是兩個」，是「他自己選擇冷血對兩個人動手，還是只解決那個回不去的人」。** 張氏死不死是威嚇檢定的結果，不是玩家一開始就選定的。
3. **【血刀】造成的死亡是他自己動手，因果不在骰子身上。** `@角色設定/饕餮.md` 第五節「爆走＝廢人，不死」，管的是**她吃人吃過頭、按不住**的情況；【血刀】的死亡是燕不凡自己選擇對張氏動手（或放任她死於自己刀下），責任在他，不在她——**跟骰子有關的只有「她事後吞掉神像殘留邪力」那部分，記一次，不是她殺的人。** 兩條規則因此不衝突。
4. **她想吃的東西寫得太窄（V1 已修正，本版沿用）。** 這條沒有引用任何廢案術語，不變。
5. **【殺伐】【血刀】之後原文完全沒有回音，這裡補一場短夢（改動 3c）。**〈`劇情/舊創作稿/初出茅廬之二.md` 旅店夢〉立下的先例是：她吃過之後，當晚在夢裡見到少女。黑血屍那次他是昏迷中被動挨過去的，沒有選擇；這裡是他第一次**清醒地**主動選擇讓她吃人，理論上更該有反應，原文卻毫無回音。**⚠ 這條有一個未拍板的判斷：** `@角色設定/饕餮.md` 第七節寫「本曲她只有這三場實際出場（地基）……不要從舊稿長出第四種她」。本提案的讀法是：這句話禁止的是「寫出語氣不同的第四種饕餮」，不是禁止她用同一套已定調的聲音**重現**——所以改動 3c 刻意複用旅店夢的空間與冷淡疏離感，不新創語氣。**這個讀法本身待你確認，若認定黑鐵嶺不該再見到她，改動 3c 整段刪掉即可，不影響 3a／3b。**

## 二、新引擎怎麼套

**引擎問的是「這次，用俠的做法，還是用管用的做法？」（指南 0.2.1）；「管用」這條路底下又分成不情願與順從兩種。**

| | 俠（救贖） | 管用・不情願（殺伐） | 管用・順從殺意（血刀） |
| :---- | :---- | :---- | :---- |
| 玩家做什麼 | 自己破神像、扛下傷害 | 推開張氏，只斬李大山 | 不推開張氏，對兩人動手 |
| 前提 | 無 | 無 | **需具備威嚇專長**（取代舊命盤解鎖） |
| 張氏的下場 | 沒事，李大山也活 | 沒事，丈夫死 | **威嚇檢定成功→活；失敗→死**（原文結果） |
| 她吃到多少 | 極輕微（見改動 4） | +1（她收殘留邪力） | +1（她收殘留邪力）——**死亡因果在燕不凡，不在她** |

**這樣分的好處：**【殺伐】與【血刀】現在有清楚的性格差異——**殺伐是不得已，血刀是選擇冷血**，而血刀是否真的波及無辜，交給威嚇檢定，不是玩家一開始就拍板兩條命。命盤解鎖換成「威嚇專長」這種角色build門檻，性質是技能需求，不是道德階梯，不違反饕餮.md 廢案清單。
