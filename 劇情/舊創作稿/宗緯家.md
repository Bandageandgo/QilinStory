# 地點：宗緯家 (野外獵戶營地)

> **區域描述：** 位於深山中的一處隱蔽山谷。這裡地勢複雜，玩家首先抵達的是**下層溪谷**，這裡是獵戶的日常營地和水源；透過藤蔓可攀爬至視野開闊的**上層平台**，那裡是宗緯搭建的觀景住處。
> **主要機制：** 下層調查 -> 上層調查 -> 觸發戰鬥 -> 瀑布密境探索 -> 狗頭人契約。
> **出場角色：** 燕不凡 (MC1)、獵戶宗緯 (role97)、狗頭人 (role107)。
