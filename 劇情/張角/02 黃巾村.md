## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關沒有引擎要轉。這一場是兩本帳看見東西的地方：她看他，程寶替張角看他。**

| | 內容 |
| :--- | :--- |
| **三樣互相矛盾的真（張寧.md 第七節）** | ①符水真的有人喝好了，不解釋。②她的草真的壓得住，但這一批份量沒試過，差一分是毒。③你染了，她的草是唯一的藥 |
| **她那本帳看什麼** | 母題「誰先」走到最後一次：那一碗他先喝、河裡他先跳、兩批他搶或不搶，**這一次她先吞**。你躺著，搶不了。玩家沒有選項 |
| **張角那本帳看什麼** | 他不在，程寶在。程寶看見這孩子怎麼對那些病人：抬水、餵藥、被傳染了還在病舍裡。**這一支不記 entry**，張角讀的是她線的記錄 |
| **主角能做的** | 幫手。醫術檢定決定他幫得上多少，不決定她吞不吞 |

**⚠ 寫法紅線（她線第十二節全部適用，另加）：**
1. **她死不死，這一場不揭。** 收在她給了你份量、你昏過去。
2. **她不說謝、不說軟話、不哭；她算過才吞。** 旁白只寫她做了什麼、算了什麼。
3. **符水為什麼有效不解釋；弟子不是騙子。** 有人喝好了，也有人喝了沒好，兩種都在。
4. **弟子對她客氣，沒有人說「因為妳是他女兒」。**
5. **主角不勸她。** 他想搶那一口，搶不到，因為他躺著。
6. **不得有人說「怪物變多了」。** 這村子鬧的是病。
