## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關問的是：救人的人，要不要打著旗進去。**

| | 內容 |
| :--- | :--- |
| **差事** | 太平道發給府的：護一隊弟子和符水到一座疫村。路上有怪，是正經的誅怪委託，結盟收入 |
| **卡在哪** | 村口。村裡的人不讓太平道進，怕的是外面來的道人，不是病 |
| **管用的做法** | 打著大賢良師的旗進去。旗一亮，村正不敢攔，人和符水一次全進 |
| **俠的做法** | 旗收起來，人進去；或者符水放下，帶張寧的藥進去。村人不怕大夫 |
| **哪裡不是俠** | 打旗管用，可是進去的是太平道，不是救人的人。**村人記得的是誰進了村** |
| **張角看見什麼** | 他不在場，程寶在。程寶回去講給他聽的，是這孩子怎麼進的村 |

**⚠ 本關只負責讓他看見，不做結算。** 結算在廣宗（`劇情/故事大綱.md` 廣 2）。旁白不評論三條路的對錯。

**⚠ 寫法紅線：**
1. **太平道不是賊，村人也沒有錯。** 村正攔人是因為去年來過一批道人，走了之後村裡多了三座墳；他不知道那是不是同一批。**這件事不解釋**，他只講他看見的。
2. **程寶、韓梁不勸主角。** 韓梁會催，程寶會等；哪條路都由主角自己走。
3. **張寧全場不提她爹。** 弟子對她客氣，她當沒看見。
4. **不得有人說「怪物變多了」。**
