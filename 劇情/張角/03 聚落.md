## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關問的是：人救下來了，然後呢。**

| | 內容 |
| :--- | :--- |
| **場上發生什麼** | 那座村活下來的二十幾個人，跟著程寶到了雲中。村裡田荒了、人死了一半，他們待不下去。太平道要帶他們去冀州 |
| **管用的做法** | 交給太平道。他們有糧、有地方、有人手，一句話人就走了，府裡一文錢不用出 |
| **俠的做法** | 留下來，安在流離區，自己想辦法。沒有府的名義，沒有太平道的名義，就是把人安頓下來 |
| **哪裡不是俠** | 留下來也是用手段：跟棚戶借地、跟糧行賒米、小犀記的帳全是欠的。**他做的事跟結局那幅畫一模一樣，只是小** |
| **張角看見什麼** | 他以張仲景的身分路過，親眼看見。**這是三支裡唯一他親眼看見的一支** |

**⚠ 本關只負責讓他看見，不做結算。** 旁白不評論。**留下不寫成對，交出去不寫成錯。**

**⚠ 寫法紅線：**
1. **張仲景不勸、不誇、不點破。** 他看了，說兩句郎中會說的話，走了。
2. **主角不追問他任何事。** 六月那場之後他知道大叔是誰，這一場他當大叔還是大叔。
3. **程寶不搶人。** 主角說留，他就走；主角說交，他就帶。
4. **小犀那張單子是這一場的收尾，兩條路各一版。**
