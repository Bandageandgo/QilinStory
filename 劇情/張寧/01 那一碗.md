## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關的特殊處：這一關沒有選擇。他做了那件蠢事，而這件蠢事是全線的起點。**

| | 內容 |
| :--- | :--- |
| **管用的做法** | 她的。一碗從毒裡熬出來的藥，份量算到一根頭髮，灌下去人就活。**管用，只是沒有人敢信** |
| **俠的做法** | 他的。當著一屋子叫它毒的人，把那碗端起來先喝——**替她的藥作保** |
| **哪裡不是俠** | 那份量是照病人配的，到他身上就是毒。他不懂，他還是喝了。**這不是勇，是蠢**——她自己會這樣說 |
| **代價** | 他躺一夜；她守一夜 |
| **她那邊發生什麼** | 他是第一個因為「這是她配的」就把她的毒喝下去的人。**同一晚她也看見：他不是為她喝的，他為誰都會喝。所以這個人一定會這樣死。** 喜歡上他，跟看出他會怎麼死，是同一晚 |

**⚠ 這一關不推變數、不做結算、也不記任務 entry。** 她線的變數從 `03 第一批` 才開始算。

**⚠ 張寧的寫法紅線（`張寧.md` 第十二節）：** 她不說謝、不說軟話、不哭。這一場的溫柔只准出現在她的手上，一次。她罵得越狠手越穩。「作為一個醫者」這種句式一出現她就死了。**那一口不寫成英雄，寫成笨。**

## 附錄：設計筆記

1. **契機就是那一口。** 不是他救了病人，是他當著一屋子叫它毒的人，喝了她的毒，因為那是她的。所以那一口不給選項——玩家沒得選，她也沒得選。
2. **三選一改的是她有沒有聽見。** 「妳配的」讓她的嘴停了一下；另外兩句她照罵。三條都通向同一件事，只有 entry 2 記下他說過。
3. **同一晚兩件事。** 他信她的藥，這是她喜歡上他的理由；他為誰都會這樣喝，這是她看出他會怎麼死的理由。兩件事都不點破，第五拍那盆草是她的回答。
4. **旁白多的地方只有藥房那一夜**，因為病人說不了話。其餘段落旁白格都比台詞少。
5. **她全場沒有一句軟話。** 「錯的是你」「你還想有下回」「我就真的下毒」——最後那句是玩笑，他笑了，她沒有。
6. **節奏檢查留下的三句碎句，是刻意的（2026-09-04 初稿跑 `文風節奏檢查.py` 後處理）：** 張寧「不喝就死。」、你「妳配的。」、張寧「錯的是你。」——這三句是這一場最重的三下，依文風指南自檢 4a「碎句只給……一場戲最重的一下」保留；其餘十二句碎句已全部併成完整句。旁白零碎句。
   **腳本另標「你」平均字數偏低（8.3）——不改。** 主角在這一場是搭腔的人和作保的人，他的短問短答（「我先喝一口，你們看著。」「可他活了，不是嗎。」）是戲，不是斷句；他的碎句清單已空，不再灌字數。
