## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關有兩處在問這句，一處在河裡，一處在小屋。**

| | 河裡 | 小屋 |
| :--- | :--- | :--- |
| **俠的做法** | 先跳下去撈她，背上挨那一擊 | 替蠶兒瞞著她爹；或者把話交給張寧 |
| **管用的做法** | 先殺了那東西再撈人——她嗆幾口水，你少挨一擊 | 如實回報。委託是委託，酬金照拿 |
| **代價** | 俠：你帶傷／管用：她嗆水，事後她說你判斷對，可她包紮時話少了 | 俠：沒有酬金／管用：蠶兒被送回去，往後怎樣不在委託之內 |
| **她看見什麼** | 他先跳了——「誰先」母題第二次（第一次是那一碗他先喝） | 他在別人的父女事上怎麼下手 |

**⚠ 本關不推變數**（`張寧.md` 第六節：`03`／`05` 才開始算）。**四軸掛在小屋那組選項**（各 0.2），河裡那組不掛——那是身手不是價值觀。

**這一支是她的鏡子，不是她的傷口。** 蠶兒的爹拿女兒當養蠶的手，蠶兒逃出來又栽進一個一樣的男人手裡。她對蠶兒說的那段話（「妳一雙手便養得活自己」）是舊稿最好的一段，**留著，只把斷句併成整句**。她自己聽不聽得見那是在說誰，**不點破**。

**⚠ 張寧的寫法（`張寧.md` 第十二節）：** 她不說謝、不說軟話。包紮時罵得最狠、手最輕。她餓昏那一段是喜劇底，可以讓她狼狽，**不能讓她撒嬌**。

## 附錄：設計筆記

1. **河裡那一下是「誰先」的第二次。** 那一碗他先喝，這回他先跳。她罵他傻，包紮時手最輕。**這一支不推變數，只讓她看見。** 另一條路（先殺牠）她說「你判斷對」，這也是真話——實用主義者認同實用的做法，可她擰袖子的時候沒看你。兩條路的差別全在她的手上，不在她的嘴上。
2. **戰敗不是死路。** 舊稿寫「不敵怪物，被拖入水，從此再沒浮出來」，那是 game over，照 `郭嘉/01 逝者無聲` 的改法拿掉：兩個人被沖到下游，牠沒回來，代價是那一段沒有她的「傻瓜」。
3. **蠶兒是她的鏡子，不點破。** 一個被爹當成養蠶的手、逃出來又栽進一樣的人手裡的姑娘；一個被爹丟在荒山、靠自己一雙手站住的姑娘。她對蠶兒說「妳一雙手便養得活自己」的時候，她在說誰，玩家自己聽。**任何角色不得說破。**
4. **舊稿的鬥嘴段全留。** 「欲蓋彌彰」「男女授受不親」「嫂溺援之以手者權也」「發乎情止乎禮義」——全是漢代讀書人會引的話，年代對得上，成立條件也對得上（7.6）。「解釋就是掩飾，掩飾就是事實」那句現代梗刪了，換成她自己的話。
5. **餓昏那一段是喜劇底，不是撒嬌。** 她可以狼狽（肚子叫、鼻子先醒），不可以軟。醒來第一句是「這是什麼情形」，不是「你怎麼在這」。
6. **她爹只出現一勺。** 主角說「我爹偷偷塞胡餅」，她勺子停了一下，一句「你爹……是麼」。兩個爹擺在同一張桌上，她只停了一勺——**這是全場唯一一個 `[em7]`**，省著用在這裡。
