> **本檔由 `Json/` 回讀產生，不是創作稿；遊戲內文案的唯一事實來源是各章節對應的 JSON。**
> 改字請指名錨點（例：「`主線事件/180年/2月.json` #4055 這句改成…」）→ AI 改 JSON → Unity 同步 → 重新回讀本檔對應章節。直接編輯本檔的文字**不會進遊戲**。
> 規則：`給AI看的指南/Unity對話同步流程.md`〈文案總覽稿〉；本檔各章節在其他總覽稿的收錄關係見 `劇情/索引.md`。

> **怎麼讀本檔**
> - 一份 JSON ＝ 一個 Unity 對話 ＝ 養成模式某個月份「主動觸發」的主線事件，**依月份分章**。179 年見 `劇情/179年 主線事件.md`；選「探險」指令才觸發的支線見 `支線任務-雲中.md`。
> - 每段從入口往下讀，遇到分岔就往下標示（`▶`＝第一層、`▶▶`＝第二層）；不同路線又走回同一句時，只寫「→ 接 `#N`」，不重複貼一次。
> - 「**◆ 玩家選擇**」是玩家點選項的地方；「`- 分流：…`」是遊戲自己依條件挑路走。
> - 文案中的 `<br>` 在原始 JSON 裡是**真正的換行字元**（本年度兩份 JSON 大量使用兩行式排版），不是新加的標記。
> - 回讀＝照抄；發現的問題一律只寫進各章末尾「回讀時發現的疑點」，不動 JSON。
