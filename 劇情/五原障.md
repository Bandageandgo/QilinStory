# 支線：五原障（呂信・尋找答案）

> **全新場次。** 呂信線第五支，**直接延續 `劇情/渡江.md`**。
> **線路圖：**〈呂之門路〉→〈仗義疏財〉→〈英布〉→〈渡江〉→ **〈五原障〉** → 人物結局。
> **⚠ 前置：** 完成 `劇情/渡江.md`（`LuXin_AskedTheQuestion`）。
> **⚠ 這一支是「尋找答案」。** 而它的結論是：**答案不在別人身上。** 寫的時候要守住這一條——三個對照都給了，**但沒有一個是解答**。
> **⚠ 地點只做一座地城，不做五原城。** 五原在三國是郡，與雲中郡同級；**本檔不建城鎮**，只在大地圖上開一個點，玩家實際進入的是一座**廢棄障塞**（形狀比照趙王洞、水濂洞）。地點檔見 `@地點/五原障.md`。

## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關的特殊處：呂信回到了那個把他教成「英布」的地方。**

`劇情/第三章主線_開場.md` L114 娜娜講并州：

> 「雲中、雁門、朔方、**五原**這一路，貼著塞外。漢人屯田牧馬，匈奴、雜胡也在這兒落腳……派系一多，規矩就雜；**誰強誰說話，誰弱誰低頭。**」

**在五原，「該不該為了活下去改變自己」這個問題，答案本來就是「該」。**

| | 內容 |
| :--- | :--- |
| **他來找什麼** | 〈渡江〉那個問題的答案：**霸王要是渡了那條江，他還是霸王嗎** |
| **他會遇到誰** | 一個當年沒走的老兵。**而那老兵現在替佔了這裡的馬賊認路、看水井，換一口飯** |
| **那就是答案** | **你不用離開，也可以不再是原來的你。** 老兵人沒動過，可是他早就渡了 |
| **為什麼這一刀最痛** | **因為呂信也沒走**——他拒絕了褚人飛。**可是他停了三息**（`劇情/渡江.md` §3） |

### ⚠ 這一支真正的結構：答案一直在他的記憶裡

**這座障塞就是他小時候待的地方**（`@角色設定/呂信.md`：「來自邊地，**自幼見慣紛亂與廝殺**」）。他看著那一隊戍卒長大，而那隊人後來怎麼了，**是他這輩子第一次看見的答案**。

**他不是來找答案的。他是回來確認一件他早就知道的事。**

**⚠ 全關不得有人把這句話講出來。**

### 〈渡江〉三顆種子的回收

**主角當初給的答案，會變成呂信現在的立場——而他不知道那是主角教他的。**

| 〈渡江〉答過 | 呂信在 §7 的立場 | 而現場撞到什麼 |
| :-- | :-- | :-- |
| `LuXin_AnsweredNo`（渡了就不是了） | 主張**算帳**——「他早就不是了」 | **老兵活得比想像中好，而且平靜。** 你的答案被打臉 |
| `LuXin_AnsweredYes`（他還是他） | 主張**放過**——「他只是活下來了」 | **老兵早就不是原來的人，而他沒走。** 你的答案被打臉 |
| `LuXin_AnsweredUnknown`（沒人知道） | **不表態**，把決定丟回給主角 | 兩樣都看見了，而你還是不知道——**因為那個答案本來就沒說什麼** |

> **⚠ 唯一沒被打臉的，是那個什麼都沒回答的答案。** 這就是「尋找答案」的結果。**收尾不得點破，只演。**

**⚠ 呂信在 0.2.2 帳上，但本關不做結算。** 結算點在**人物結局**那一支（未寫）。門檻＝**未定，AI 不得發明。**

**⚠ 寫法紅線：**
1. **老兵不是可憐人，也不是叛徒。** 他平靜、務實、不辯解。**他甚至覺得自己沒做錯什麼**——因為這裡早就沒有誰可以背叛了。
2. **不得發明呂信的家人。** 角色檔只寫「來自邊地」。老兵認得他，**但只認得「以前老在牆根下打轉的那個小子」**——不得提父母、兄弟、師父。
3. **馬賊與這座障塞沒有淵源**（已拍板）。他們就是一夥佔了空屋的亡命之徒，**不要給他們身世**。
4. **呂信全關話比平常少。** 他不解釋自己為什麼請纓、不說這裡是他小時候的地方——**那要由老兵說破。**

## 附錄二：設計筆記

1. **一座障塞就夠了，不必做五原城。** 五原是郡，跟雲中同級；真要做城鎮，成本遠超這一支的需要。**大地圖開一個點、進去是一座地城**——這是趙王洞、水濂洞已經在用的形狀。
2. **「答案」由三個東西合起來給，而且沒有一個是解答：**
   * **牆上的名字**——走的人不算數（結構）
   * **簡牘**——沒有人叛逃，是這裡先不要他們的（真相）
   * **老兵**——他沒走，而他早就不是原來的人了（活體）
   **三樣都是真的，互相不能調解。** 這正是「尋找答案」該有的結果。
3. **老兵不可憐、不辯解、不感激。** 他放下水桶、挪三步、蹲牆角的動作要寫得**熟練**——那個熟練比任何台詞都說明問題。而玩家放過他時，**他連謝都不謝**，因為在他看來這事本來就跟他沒關係。
4. **§7 讓呂信先開口，這是本關最重要的機制。** 主角在〈渡江〉給的答案，變成呂信現在的立場——**而他不知道那是主角教他的。** `LuXin_AnsweredUnknown` 那條他把問題丟回來，還把那晚的位置記反了（「你問過我一次」）——**他不想承認是自己在問。**
5. **騎術分三層，而且都不碰戰鬥系統。**
   * **§1 純演出**——建立他的騎術，也建立這片地沒有街、沒有牆、沒有規矩。
   * **§2 騎術小遊戲**——玩家自己下場追那個哨騎。**用既有的小遊戲，不是檢定。**
   * **§8 傳授**——技能卡。
   **⚠ 本作沒有馬上戰鬥系統**，所以三場戰鬥全是下馬步戰，**而且 §2 末尾用「這種坡，馬上使不開」把場面拉回地面，不默默切換。**
   **而那句「坐馬的人怕摔」故意留下半句，到 §8 才給**——「騎馬的人不怕摔，因為他知道自己一定會摔」。**那句話同時是騎術口訣，也是他對這一整趟的結論。**
6. **摔十七次對上牆上十七個名字。** 不解釋、不點破。**若覺得太巧可以改數字，但我建議留著。**
