# 趙王洞(山賊窩) - 劇情大綱與區域規劃

## 📖 劇情大綱與流程
**地點：** 趙王洞（山賊窩/地牢區）
**登場人物：** 主角、廖化(role127)、雍仔、赫連娜娜、太平教眾(127)。

**【流程設計】**
1. **[開場中計]** 
   - 承接英豪府遴選，主角與雍仔、赫連娜娜結伴來到趙王洞。
   - 沒遇到廖化，但太平道眾人說他在外頭辦事待會就回來，並熱情獻上茶水解渴。
   - 主角三人喝下摻了迷藥的茶水，相繼昏迷中計。
2. **[地牢甦醒與相認]**
   - 主角在地牢中醒來，發現雍仔和娜娜不在身邊，已被轉移到更深處，因此有了深入虎穴救人的強烈動機。
   - 發現隔壁關著廖化，廖化解釋自己因被卞喜陷害而暫且羈押在此。
3. **[智取看守（越獄）]**
   - 看守來巡視，主角利用不同手段（口才威嚇 / 巧手偷鑰匙 / 直接戰鬥）制服看守。
   - 救出廖化，兩人正式結伴同行。
4. **[探索山寨（收集情報與伏筆）]**
   - 兩人逃出地牢，沿途經過幾個山賊的生活區域（如廚房、休息室等）。
   - 透過戰鬥/潛行，以及調查環境（肉鼎、山賊的恐慌筆記），鋪墊卞喜在深處進行恐怖獻祭的懸疑氛圍。
5. **[突破大廳/長廊，前往山道]**
   - 解決山寨的主要守衛，來到通往地下的入口。
   - 準備進入下一階段：趙王洞(山道)。

## 🗺️ 可利用的區域規劃 (結合《初始地牢》草案與場景圖)

從場景圖可以看出，整個山賊窩位於一個巨大的地下溶洞中，分為高處的石製牢房區，以及下方依山壁而建的幾座木製建築。我們可以這樣安排：

### 1. 高地牢房區 (對應草案：主線01_牢房)
*   **視覺位置：** 場景圖最上方，有金屬柵欄與石牆的區域。
*   **用途：** 主角醒來、與廖化相認、越獄的起點。
*   **可用機制：** 保留草案中的「擲骰檢定」機制來對付看守（口才誆騙、巧手偷竊、直接戰鬥）。

### 2. 中央大木屋：大廳 / 主寨
*   **視覺位置：** 走下坡道後，場景圖右側最大的木製建築。
*   **用途：** 區域的樞紐與最後防線。
*   **可用內容：** 
    *   這裡要設計戰鬥，因為都是卞喜的爪牙，然後打贏戰鬥後，廖淳和主角說機關位置可以直接打開通道(到外面的山道)

### 3. 右下小木屋：廚房 / 伙房 (對應草案：主線02_廚房)
*   **視覺位置：** 場景圖右下方的較小木屋。
*   **用途：** 戰鬥與恐怖氛圍鋪墊區。
*   **可用內容：**
    *   兩個太平教眾在顧火的對話（抱怨老大最近很詭異，抓了肥羊也不吃）。
    *   可選擇威嚇或戰鬥。
    *   **環境調查：** 調查大鼎（發現令人作嘔的腥臭肉塊）、調查書簡（發現詭異的食譜或紀錄）。

### 4. 左下水潭木屋：山賊宿舍 / 休息室 (對應草案：支線02、支線03)
*   **視覺位置：** 場景圖左下方，旁邊有一池幽藍水潭的木屋。
*   **用途：** 資源收集與劇情伏筆（恐懼筆記）。
*   **可用內容：** 
    *   遭遇正在休息的太平教眾（戰鬥）。
    *   **關鍵道具：** 撿到破碎的紙條/筆記。筆記內容改為：教眾們察覺到進了「深洞」的兄弟都沒回來、卞喜老大行為反常、半夜有慘叫聲等。藉由教眾自身的恐懼來渲染深處的危險。
