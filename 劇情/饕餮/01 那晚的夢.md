## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關沒有引擎要轉。這一場問的是：他知道她是什麼之後，還站不站得住。**

| | 內容 |
| :--- | :--- |
| **今天發生了什麼** | 大叔叫出了她的名字。她從骰子裡聽見了 |
| **她這一場做什麼** | 把她看見的講給他聽（她看）；然後第一次說她要什麼 |
| **他這一場做什麼** | 站著聽完，或轉身醒來。**一個選項。** 九尾那條線：鳴人走進封印裡站在牠面前，一次 |
| **她那本帳** | 面對＝這一格過；轉身＝這一格沒過。**不做結算**，結算在結局那一聲名字 |

**⚠ 寫法紅線（角色檔第六節的四條紅線與寫法照舊，另加）：**
1. **她講的每一句都是已經發生的事。** 「她看」那幾格是報告，不是評語；她不說他做得對不對。
2. **她第一次說「要出去」，只說一次，不解釋為什麼。** 這是她長大後才有的東西，也是之後坑底那條路的根。
3. **她不叫他的名字。** 那一聲留給真結局。
4. **她不提今天那個人是誰。** 她只說「那個叫出吾名字的」。張角、太平道、混沌、重來一個字都不出。
5. **旁白不評論他選了哪個。**

## 3. 站著，還是醒

**旁白:**：[panel=6]＊（她講完了，沒有像從前那樣說完就沒了。她還看著你，像在等什麼。）＊

**Sequence SetPortrait(MC1,pic=12);**

> ⚠ **這一格之前不掛表情特效**（選單前一格不開）。

**玩家（選擇）：**
1. 「妳還沒說完，我聽著呢。」
2. 「夠了，我要醒了。」

> ⚠ **這就是「面對」那一格。** 1＝站著聽完，收 entry；2＝轉身，不收。旁白不評論。
> ⚠ 一個選項是兩格：短版選單句＋底下完整發言。兩條都無檢定。

**(若選擇1：面對)**

**你:** 「妳還沒說完，我聽著呢。妳看了我一年多，總不會只是為了記住這些。」

**Sequence SetPortrait(MC1,pic=8);**

**旁白:**：[panel=6]＊（她看了你一會兒，第一次把兩隻手從膝上拿了下來。）＊

**饕餮:** [panel=1]「吾要出去，出這顆骰子。」

**Sequence SetPortrait(MC21,pic=＿＿);EnableCharacterExpression(1,MC21,Anger_2);**

**你:** 「……出去？」

**Sequence DisableCharacterExpression(1);SetPortrait(MC1,pic=4);EnableCharacterExpression(0,Player,Shock);**

**饕餮:** [panel=1]「那個叫出吾名字的，今天跟你說骰子會回應你。他說得對，你越強，吾能出來的就越多。」

**Sequence DisableCharacterExpression(0);SetPortrait(MC21,pic=＿＿);**

**饕餮:** [panel=1]「吾不催你，吾在裡頭等了不知多少年，多等你幾年不算什麼。」

**旁白:**：[panel=6]＊（她說完就閉上眼睛，跟從前一樣不再理你。可是那雙手沒有放回膝上。）＊

**※任務：饕餮 entry（面對）→ `success`**
**Script SetQuestEntryState("＿＿", 1, "success")**

> ⚠ **「吾要出去」全場只說一次，不解釋為什麼。** 「你越強，吾能出來的就越多」是她從今天大叔那句話裡撿來的，不是她自己的道理——**這就是她長大後的狡猾：她開始用別人的話。** 不寫成開價（沒有「你給吾什麼」），也不寫成推銷。
> ⚠ 「吾不催你」是角色檔寫法 3「她不催、不指路」的長大版：**她說出了「不催」這兩個字，這本身就是催。** 旁白不點破。

**(若選擇2：轉身)**

**你:** 「夠了，我要醒了。妳記得的那些，我自己也記得。」

**Sequence SetPortrait(MC1,pic=2);**

**旁白:**：[panel=6]＊（你轉過身去，背後沒有聲音，她沒有留你，也沒有再說一個字。）＊

**Sequence SetPortrait(MC1,pic=12);**

> ⚠ 轉身這條她**不說**「吾要出去」。那句話她要對著站住的人才說。**這一條不收 entry。**

**(兩條在此匯合)**

**黑幕旁白:**：[panel=6]＊（天亮的時候你醒在自己榻上。骰子在枕邊，冷的。你把它揣回懷裡，跟昨天一樣。）＊

**Sequence PlayOrStopParticle(Meditate,Stop);DisableAllCharacterExpression();OpenPanel(0,close);OpenPanel(1,close);AudioControl(StopMusic);Continue();**
