## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關的特殊處：呂信回到了那個把他教成「英布」的地方。**

`劇情/舊創作稿/第二章主線_開場.md` L114 娜娜講并州：

> 「雲中、雁門、朔方、**五原**這一路，貼著塞外。漢人屯田牧馬，匈奴、雜胡也在這兒落腳……派系一多，規矩就雜；**誰強誰說話，誰弱誰低頭。**」

**在五原，「該不該為了活下去改變自己」這個問題，答案本來就是「該」。**

| | 內容 |
| :--- | :--- |
| **他來找什麼** | 〈渡江〉那個問題的答案：**霸王要是渡了那條江，他還是霸王嗎** |
| **他會遇到誰** | 一個當年沒走的老兵。**而那老兵現在替佔了這裡的馬賊認路、看水井，換一口飯** |
| **那就是答案** | **你不用離開，也可以不再是原來的你。** 老兵人沒動過，可是他早就渡了 |
| **為什麼這一刀最痛** | **因為呂信也沒走**——他拒絕了褚人飛。**可是他停了三息**（`劇情/呂信/04 渡江.md` §3） |

### ⚠ 這一支真正的結構：答案一直在他的記憶裡

**這座障塞就是他小時候待的地方**（`@角色設定/呂信.md`：「來自邊地，**自幼見慣紛亂與廝殺**」）。他看著那一隊戍卒長大，而那隊人後來怎麼了，**是他這輩子第一次看見的答案**。

**他不是來找答案的。他是回來確認一件他早就知道的事。**

**⚠ 全關不得有人把這句話講出來。**

### 〈渡江〉那個問題怎麼回收

他在〈渡江〉問「霸王要是渡了那條江」；在五原他看見一個沒走卻早就變了的老兵，§9 自己說出「五原沒有江」。**主角那晚答了什麼，本關不讀**（原本 §7 讓他照你的答案先表態，作者 2026-08-28 砍了）。

**⚠ 呂信在 0.2.2 帳上，但本關不做結算。** 結算點在**人物結局**那一支（未寫）。門檻＝**未定，AI 不得發明。**

**⚠ 寫法紅線：**
1. **老兵不是可憐人，也不是叛徒。** 他平靜、務實、不辯解。**他甚至覺得自己沒做錯什麼**——因為這裡早就沒有誰可以背叛了。
2. **不得發明呂信的家人。** 角色檔只寫「來自邊地」。老兵認得他，**但只認得「以前老在牆根下打轉的那個小子」**——不得提父母、兄弟、師父。
3. **馬賊與這座障塞沒有淵源**（已拍板）。他們就是一夥佔了空屋的亡命之徒，**不要給他們身世**。
4. **呂信全關話比平常少。** 他不解釋自己為什麼請纓、不說這裡是他小時候的地方——**那要由老兵說破。**
5. **⚠ 唯一的例外是馬（2026-08-29 加）。** `@角色設定/呂信.md` 性格特質 4「愛馬、懂馬、馬痴」：**只有講馬的時候他會多話**，而且不覺得自己在多話。本支四處演它——§1 他怎麼騎、§2 他怎麼把人卸下來而不動那匹馬（以及射馬那條的代價）、§2-探2 他看牙口摸腱子、§8 他把馬全放了。**四處都只演動作，不許他自陳「我愛馬」。**
