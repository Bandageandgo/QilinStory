## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關的特殊處：這一關不是主角自己伸手，是他站在旁邊看別人伸手。**

| | 內容 |
| :--- | :--- |
| **這一手是誰的** | 呂信的。不聽完就去砍、提著人頭回桌、拿錢把人打發走 |
| **哪裡管用** | 一炷香就結案。土匪死了、父女拿了盤纏、同夥當晚一次清乾淨。主角想了半天沒想出的辦法，他做完了 |
| **哪裡不是俠** | 沒審、沒證、沒問過那父女要不要；牆上留名是為了引人來殺。**話本裡這叫替天行道，手法不是** |
| **主角的位置** | 全程只能接話、只能跟上。**他這一關學到的是「原來還能這樣辦」——這正是高概念那句「每一手都管用」** |

**對應 0.2.2「累積的是人・各自結算」：**

| 呂信 | 正 | 反 |
| :--- | :--- | :--- |
| 同樣散財殺人 | 不擇手段是為了重建英豪府（**重感情還在**） | 為了出人頭地、倚仗武力，**變質** |

**⚠ 本關只負責讓玩家「看見他的理由」，不做結算。** 依指南 0.2.2，**每個人的結算點在哪些關卡、門檻多高＝未定，AI 不得發明**。**本檔不留旗標。** 看不看得見，只在第 3 節背景洞悉的成敗旁白裡當場結算。

**⚠ 不給數字（指南「症狀：不給數字」）：** 不做聲望條、不做恐懼值、不在 UI 顯示。玩家看不看得見他的理由，只反映在**別人怎麼叫他、怎麼看他**——本關落在「散財義士」這個稱呼上。

**⚠ 寫法紅線：** 呂信**不得自陳**「我這麼做是為了英豪府」。他的迷惘用豪語包住（`@角色設定/呂信.md` 性格特質 2、3）；玩家要嘛從背景洞悉看出來，要嘛看不出來。**看不出來是允許的結果，不是懲罰。** 看穿了，他裝傻，不認。

## 附錄二：設計筆記

1. **為什麼把洞悉改成背景檢定。** 高概念要的是「管用但不俠」被**看見**，而不是被評價。玩家沒得選要不要看——看不看得見，看的是他眼力，不是他想不想當觀察者。看清楚了，這一手依然不是俠該用的；看不清楚，那就只剩一顆人頭跟一袋錢。
2. **失敗不懲罰。** 依指南 0.2.3，擲骰失敗＝「這條路沒開」，不是有人死。洞悉失敗只是看不出來，劇情照走、獎勵不給。
3. **戰鬥失敗也是內容，不是懲罰。** 酒量過了才下場。打輸了呂信會把你護在身後——這既符合他「護短、有難先上」的人設，也剛好把他的另一面（倚仗武力）演給玩家看。**輸了看到的東西，跟贏了不一樣，但都是內容。** 不另記旗標。
4. **呂信不解釋自己。** 看穿了，他裝傻（「大家都說我空有武力、少思慮」）；最接近自陳的一句是「填不了的，就別跟我算」——那不是宣言，是推開話題。`@角色設定/呂信.md` 的「用簡單包裝迷惘」在這裡照辦。
5. **三萬六那句改由呂信自己撂。** 玩家問的是這趟差事的報酬夠不夠散；他回「夠什麼夠。三萬六。」——「他為什麼散財」跟「府裡缺錢」仍在同一張桌上撞一下，而不必讓主角先把帳房的數字念出來。出處仍是 `劇情/舊創作稿/第二章主線_開場.md`。
6. **女兒全程不開口。** 一來省 panel 槽（呂信固定 panel 1、農民／寨主固定 panel 2，不必動用 3），二來這場戲的重點不在受害者，在動手的人。
7. **可延伸：** 若日後補寫呂信的遴選考題〈呂之門路〉，那一關是「他教你摸金」——同一個人，同一套「管用但不俠」，換成主角自己動手。兩關並看，呂信這條線才完整。
8. **⚠ 呂信在第 2 節必須先問那一句「離了這村，有處去麼」。** 背景洞悉成功的旁白（「你想起他**起身前**多問了一句」）整個押在這裡——**沒有這句，那段回憶就是憑空捏造的**。順帶：他問完就走，正好是第 3 節「這種事聽到重點，便足矣」的前身。
9. **第 3 節選單是問資訊／推進，不是價值觀。** 1、2 與後面的對白同意思、不同句，不縮減；3 換成「這事了了，還喝嗎」，玩家看得見這條是往下走。
10. **酒量檢定是手動擲骰，失敗＝打不了這場。** 依指南 0.2.3，擲骰失敗＝「這條路沒開」——開的是下場那條路，不是有人死。過了：他看見你跟出來，誇兩句，加好感（`ModifyData(FavorabilityExp,MC2,25);`），然後一起打。沒過：他按你回凳，自己了；門外只聽見刀，聽不見「我包圍了你們」。它同時把第 4 節那三罈酒兌現。
