## 名字

**白鹵澤。** 鹵＝鹽鹼。一片枯死的鹽澤，澤水早乾，剩白花花一層鹽殼。并州再往北、出長城舊塞的荒地——確切方位不進文本，她帶路。

## 是什麼（表裡）

| 層 | 內容 |
| :--- | :--- |
| **表** | 死地。鹽殼、白、風。寸草不生，鳥都不落。邊地人不來，沒什麼好怕的——**就是空**。 |
| **裡** | 一道**痕**橫貫全澤：沿著那道痕，鹽殼底下壓著的草是**綠的**，不合時令（跟妖林「冬月而榮」同款異象——玩家自己對，沒人說）。痕的中段有一具**殼**：那東西蛻下來的一層。**幽冥禁地所守之物沒有被人搬走——是自己走的**，在這裡蛻了一層，繼續往北。 |
| **深（本曲不揭）** | 那東西是什麼、為什麼走、往北是哪——**不揭，二部。** 全場沒有任何角色說出「它自己走了」；殼、蛻、痕擺在那裡，玩家自己拼。 |

## 結構（三段，直線）

1. **澤面**——白到晃眼。唯一的路標就是那道痕。沿痕走；風大，來回都是自己的腳印被吹平。（無戰鬥或僅少量雜兵，作者定。）
2. **殼**——痕的中段。半透、比屋還大、掐不碎；裡面是空的。**它不是敵人，沒有戰鬥**——這一段的可怕在你繞著它走完一圈，它什麼都不做。她爹的字在殼邊的鹽殼上刻過一行，風磨掉了大半，剩「……非死物……」三兩個字可辨。
3. **澤心・舊營**——痕出澤的地方，有一個**舊營地**：石頭壓著的火塘、一口埋了半截的鍋、鹽殼上刻著一個記號——**天機盤的樣子**。是她爹的最後一個營。營再往北，痕出了澤沿。**戲在這裡斷**：不追、追不上、也沒有下一句。
   - ⚠ 她在營地的反應：照她的規矩演（不哭給人看）；旁白不下判語。台詞寫的時候再定，**「爹」字在這一場她說不說得出口，留給寫戲時作者裁**。
   - **末卷（`WanderingNotesPage7`，給吾女的信）放這裡最順**——他最後一個營留給她最後一卷。不綁死，作者排。

## 紅線

- **那東西不出場、不命名、不描述本體**——只有殼與痕。
- 爹的下落**斷在澤北緣**，不給方向、不給屍體、不給遺言（末卷那封信就是遺言的位置，別再加）。二部再接。
- 澤心無 Boss。這座地城的重量在「空」，塞怪物就毀了。
- 「非死物」三個字是上限——刻字不再多一個字。
