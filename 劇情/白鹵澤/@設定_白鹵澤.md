## 二、名字與地理

**白鹵澤。** 鹵＝鹽鹼。一片枯死的鹽澤，澤水早乾，剩白花花一層鹽殼。并州再往北、**出長城舊塞**的荒地——確切方位不進文本，她帶路。

- 路程：**出塞往北，沙走三日**（〈死地生綠〉她說的；繞開的話五日）。
- 邊地人知道這地方，但不來——**不是因為怕，是因為沒東西**。趕駝的說「這幾年澤裡見得著綠」，那句話是她找到這裡的線索。

| 層 | 內容 |
| :--- | :--- |
| **表** | 死地。鹽殼、白、風。寸草不生，鳥都不落。邊地人知道這地方，但不來。 |
| **裡** | 一道**痕**橫貫全澤。沿著痕，鹽殼底下壓著的草是**綠的**，不合時令。痕的中段有一具**殼**：那東西蛻下來的一層。**幽冥禁地所守之物沒有被人搬走——是自己走的**，在這裡蛻了一層，繼續往北。 |
| **深（本曲不揭）** | 那東西是什麼、為什麼走、往北是哪——**不揭，二部。** 全場沒有任何角色說出「它自己走了」；殼、蛻、痕擺在那裡，玩家自己拼。 |

> **⚠ 「空」不是硬設定（作者 2026-09-06 更正）。** 卷二寫的是**她爹當年**看到的樣子；**他來過已經是多年前**，中間誰住進來都有可能——別的勢力、外來的怪、避風的邊人皆可。**要放什麼、放多少，由地城設計端定。**

## 四、結構（三段，直線）

**三段直線，不分岔、不迷路**（迷路是幽冥禁地的活）。**下面寫的是敘事骨架**——沿路要不要有怪、有多少、有沒有別的勢力占著，**由地城設計端定**（見〈五〉）。

### 1. 澤面（入口 → 痕）

- 白到晃眼。四面一樣，沒有地標——**唯一的路標就是那道痕**。
- 風大。**來回都是自己的腳印被吹平**（走過的路看不出來，只有痕還在）。
- 玩家要做的事：找到痕、沿痕走。
- ⚠ 這一段負責**把痕交到玩家手上**——不論路上放了什麼，玩家離開這一段時要知道「跟著那道痕走」。

### 2. 殼（痕的中段）

- 半透、**比屋還大**、掐不碎；**裡面是空的**。
- **殼本身不是敵人**——它是空的、不動、掐不碎。（周圍要不要有東西，作者定；但**動手的不會是殼**。）
- ~~她爹的字刻在殼邊的鹽殼上，剩「……非死物……」~~——⛔ 2026-09-11 作者裁示拿掉，對話裡不提、她不讀（見〈五〉物件表第 4 條）。現行殼的對話 `#8`–`#14` 只摸、只問「那牠現在該有多大？」。
- 玩家要做的事：繞過去（或繞一圈看完）。**繞不繞得完由玩家決定，不強制**——但動線要讓「繞得完」這件事是可能的，玩家才意識得到它是空的。

### 3. 澤心・舊營（痕出澤的地方）

- 一個**舊營地**：石頭壓著的火塘、一口埋了半截的鍋、鹽殼上刻著一個記號——**天機盤的樣子**。**是她爹的最後一個營。**
- **末卷壓在那個記號旁邊**（撿卷戲的互動點）。
- 營再往北，痕出了澤沿。**戲在這裡斷**：不追、追不上、也沒有下一句。（2026-09-11 第二輪：北緣**維持無對話**；她把角給他看那一場改在**洞窟**——撿完末卷黃牆壓來，她喊「往那邊跑！前頭有個洞——快！」，對話直接轉場進洞，頭巾丟在風裡。）
- ⚠ 她在營地的反應：照她的規矩演（**不哭給人看**）；旁白不下判語。現行撿卷戲已定稿，見 `白鹵澤.md`。

## 五、給地城設計者

> 這一節講**樣式、風格、敵人、一定要有的物件**四件事。除此之外怎麼配，設計端自由。

### 樣式

- **地形：** 鹽澤。平、開闊、沒有遮蔽物，四面看起來都一樣。**⚠ 例外（2026-09-11，16 稿；2026-09-15 作者拿掉「崖」——實際地圖上沒有崖）：營地那一頭有一個剛夠兩人蹲的洞**——風沙起時兩人躲進去（作者補進地圖）。**洞窟不是獨立觸發點**：營地對話演完直接轉場進洞（`#24` → `#112` 黑幕 → `#113` 換 `Cave` 背景 → `#25`），出洞也是轉場（`#97` → `#116` → `#114`）。⚠ **那個洞長在什麼上頭（未定）**：作者未寫，AI 不得發明，台詞裡也不指地形。
- **動線：三段直線**——澤面 → 殼 → 澤心舊營，走到底是澤北緣。**不分岔、不迷路**（迷路是幽冥禁地的活）。
- **導航：** 玩家不靠地標，靠**那道痕**。四面一片白，只有痕是方向。
- **規模：** 中小。走完一趟多久由設計端定。

### 風格

- **顏色：** 白（鹽殼）＋灰（天）＋**一線綠**（痕底下壓著的草）。舊營那幾樣是土黃與鏽——在一片白裡特別跳。
- **光：** 晃眼的白，沒有陰影可躲。
- **聲：** 風為主。腳踩鹽殼有脆聲。**現行 JSON 已掛**：黃牆壓來 `#20` 起持續音效 `Others_Cave_1`（低沉的風、災難要來）；進洞首格 `#25` 換 `Others_HeavyColdWind`（洞外風勢正猛）；`#27` 停音效、進 `BGM_42`（情緒沉澱、謎題揭開），管整段洞窟到 `#97` 才停。
- **三座地城的調子分工：** 幽冥禁地＝石與機關（暗、封閉）；妖林＝墨綠與土（濕、下沉）；**白鹵澤＝白與風（乾、開闊）**。

### 敵人

- **有沒有、放多少、多強，由設計端定。** 她爹來過已是多年前，這片澤後來住進什麼都合理。
- 身分有三個現成方向，**都不必新造設定**：
  1. **邊地的人**——盜匪、逃人、避風的行旅。出塞荒地本來就有。
  2. **逆流河漏來的**——狗頭人、蜥人（世界觀已定：牠們已在人間定居營生）。
  3. **本土凶戾類**——用本名，不新造名字（世界觀第三節）。
- **牠們屬於「現在」這一層。** 痕、殼、舊營是很多年前那一層的東西，兩層各自獨立、不必互相解釋——**住進來的跟那道痕沒有關係**。
