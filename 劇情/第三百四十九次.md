# 支線：第三百四十九次（呂信）

> **全新場次。** 材料出自支線7 結尾那一拍——子羽：「你是來殺那第三百五十次的嗎？」（現為 `劇情/雙世冥劍.md` §12）——與 `@角色設定/呂信.md` 性格特質 1「天賦異稟與高處不勝寒的寂寞」——**後者至今全案沒有用過。**
> **⚠ 編號是刻意的。** 本支是**第三百四十九次**；支線7 結尾那場拼酒維持**第三百五十次**，**一個字都不必改**。玩家先玩過這一支，再看到子羽那句，才會發現那個數字是真的有人在數。
> **⚠ 支線7 目前凍結**（材料來歷與九黎新定義牴觸，見 `給AI看的指南/世界觀.md` 第十節）。**本支不依賴支線7，可獨立成立**；支線7 日後解凍與否都不影響本檔。
> **⚠ 沒有「指派」系統。** 本檔掛好感度門檻＋地點。

## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關的特殊處：〈仗義疏財〉問「他為什麼給錢」，這一關問「他為什麼打」。**

`劇情/仗義疏財.md` 那一關主角**站在旁邊看他伸手**。這一關反過來——**主角自己下場**，而且他很清楚自己不夠格。

| | 內容 |
| :--- | :--- |
| **場面** | 呂信在演武場外等子羽。等了半天，人沒來。**於是他轉頭看你。** |
| **主角的處境** | 你不是他要的那個對手。**他找你，不是因為看得起你，是因為沒有別人。** |
| **俠的做法** | 正面打。你會輸，而且輸得很快 |
| **管用的做法** | 你贏不了他的力，所以你用別的——詐、拖、借場地、賴。**話本裡的大俠不這樣切磋** |
| **⚠ 而真正讓他高興的是後者** | 因為他要的從來不是贏。**他要的是意外。** |

### 這一關扣在他那本帳上

依 `給AI看的指南/文本創作指南.md` 0.2.2：

| 呂信 | 正 | 反 |
| :--- | :--- | :--- |
| **同樣打了三百四十九次** | 因為子羽是唯一陪他打的人——**那不是戰績，是他攢下來的東西** | 因為他需要證明自己最強——**三百四十九次就是三百四十九個證明** |

**⚠ 兩種都對，而且他自己也分不清。** 這與 `劇情/仗義疏財.md` 的紅線一致：**呂信不得自陳。** 玩家要嘛從洞悉看出來，要嘛看不出來。**看不出來是允許的結果。**

**⚠ 本關只讓玩家「看見他為什麼打」，不做結算。** 每個人的結算點在哪些關卡、門檻多高＝**未定，AI 不得發明**。本檔只留樁。

**⚠ 寫法紅線：**
1. **他不承認自己寂寞。** 依 `@角色設定/呂信.md`：他「絕不表現出這種文人式的無病呻吟，總是用爽朗、沒心沒肺的大笑和對戰鬥的狂熱來掩蓋」。**全關他最接近承認的一句，也必須包在豪語裡。**
2. **那個數字不許他自己強調。** 他要說得像順口——**是主角（和玩家）自己發現「一個沒心沒肺的人不會記得數字」。**
3. **子羽不出場，只在最後露一面，兩句話。** 他不評論、不解釋。

## 附錄二：設計筆記

1. **這一關必須讓主角下場，這是它跟〈仗義疏財〉唯一的分工。** 那一支的設計筆記明寫「這一關不是主角自己伸手，是他站在旁邊看別人伸手」——**如果這一支也是站著看，兩支就重複了。** 所以子羽必須不在，呂信必須轉頭看你。
2. **「那就你吧」四個字是這一關的痛點，也是它的溫柔。** 他不是看得起你——他只是沒有別人。**而主角當場就明白了**（旁白直接寫出來），這一點不藏。藏起來的是後面那個數字。
3. **謀略那條比正面那條「好玩」，這是刻意的。** 他要的不是贏，是意外。**所以對他丟沙子比堂堂正正挨打更能讓他高興**——這就是高概念在這一關的樣子：**不俠的那一手，才碰得到這個人。**
4. **那個笑的寫法是全關最要緊的一筆。** 「先笑出來，他才想起來要笑大聲」——依 `@角色設定/呂信.md`，他的大笑是**用來掩蓋的工具**；這一次工具慢了半拍。**全關只有這一次他來不及包裝，不要再給第二次。**
5. **洞悉問的是一個誰都會問的問題（誰贏得多），看的卻是他放碗那一下。** 這與〈仗義疏財〉同一套手法：**問題是幌子，檢定看的是動作。**
6. **「就是這個滋味」＋倒過來的空碗**，是他全案最接近自陳寂寞的一次，而他立刻用「我是說酒沒了」蓋掉。**紅線：不得讓他講完，也不得讓主角替他講完。**
7. **子羽那句「第三百四十九次，算你的」有兩層。** 表面是記帳；底下是——**他把主角放進了他跟呂信之間那個只有兩個人的數字裡。** 他當然不會解釋。
8. **⚠ 待填：** 無。本支無戰鬥場次 ID、無小遊戲、無貴重品、無數值門檻，**可直接進 JSON**。
