## 二、用一句話說

**這條線演的是他的規矩是誰給的。** 高概念「關羽的骨，傅紅雪的病」（`@角色設定/子羽.md`）：關羽是他將來要成為的人，傅紅雪是他十八歲現在的樣子。傅紅雪的規矩是別人給的，關羽的規矩是自己立的；六支就是從前者走到後者的路。

六支各是一條規矩：

| 支 | 那條規矩 | 誰給的 |
| :-- | :-- | :-- |
| 羽之演武 | 不斬手無寸鐵的人 | 他自己的。**而主角第一次見面就拿它來用**（丟開兵器賭他不砍） |
| 慕惡而來 | 「惡刀」這個名 | 江湖給的。他不糾正 |
| 雙世冥劍 | 這把刀「是殺，亦是止殺」 | 莫雪給的 |
| 戴天 | 父之讎，不共戴天 | 書上的。**兩條規矩第一次打架**（書上說該報；那被殺的那個，他兒子呢） |
| 陽曲塢 | 刃出鞘就得有人死，所以他讓它重 | 他以為是自己想的，其實是莫雪的 |
| 歸姓 | 我姓關 | **第一條真正自己立的** |

**母題：每一支都有人拿他的規矩來用。** 主角拿「不斬」賭他，少年拿錢買他的「惡刀」，少年又拿他的話回他。跟呂信線的石墩三次一樣，這是全線的骨。

**結局的正反**（`給AI看的指南/文本創作指南.md` 0.2.2）：正＝殺心找到了要護的東西／反＝殺心只是找到了新的藉口。三條結局他都取回「關」姓、都拿著刀；改的是理由，以及別人後來怎麼叫他。
