> **全新場次。** 子羽線第五支，**直接延續 `劇情/戴天.md`**。
> **線路圖：**〈羽之演武〉→〈慕惡而來〉→〈雙世冥劍〉→〈戴天〉→ **〈陽曲塢〉** → 人物結局。

> **⚠ 這一支是「尋找答案」。** 而它的結論是：**答案不在別人身上。** 寫的時候要守住這一條——三個對照都給了，**但沒有一個是解答**。
> **⚠ 地點只做一座塢，不做陽曲城。** 陽曲是太原郡屬縣，與晉陽相鄰；**本檔不建城鎮**，只在大地圖上開一個點，玩家實際進入的是一座**豪強塢堡**（形狀比照趙王洞、水濂洞、五原障）。地點檔 `@地點/陽曲塢.md` **待建**。

## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關的特殊處：那個少年辦成了。而子羽是來看他辦成了什麼樣子的。**

| | 內容 |
| :--- | :--- |
| **他來找什麼** | 〈戴天〉那個問題的答案：**那被殺的那個，他兒子呢** |
| **他會遇到誰** | **那個少年。** 他報完仇，沒有走——他坐在常氏的正堂上，手底下已經有二十幾個人 |
| **那就是答案** | **他不是變成了壞人。他是變成了「那個位子」。** 而常氏那個十一歲的兒子，現在躲在柴房裡 |
| **為什麼這一刀最痛** | **因為子羽拒絕過他。** 那條「不斬女流老幼」的規矩護住了這個少年不被他所傷——**卻沒有護住他不變成他** |

### ⚠ 這一支真正的結構：答案是一個字

**子羽在 §9 會自己說出答案，而他不知道那是答案**（同 `劇情/五原障.md` 呂信那句「五原沒有江」）。

**他讀了很多年《春秋》。這一趟回來，他第一次看見那個「讎」字裡有兩個人。**

**⚠ 全關不得有人把這句話講出來，也不得有人解釋那個字。**

### 〈戴天〉三顆種子的回收

**主角當初給的答案，會變成子羽現在的立場——而他不知道那是主角教他的。**

| 承〈戴天〉哪一條 | 子羽在 §7 的立場 | 而現場撞到什麼 |
| :-- | :-- | :-- |
| **7-1 該報**（書上沒寫錯） | 主張**這事辦完了**——「他報了，就是報了」 | **那少年沒有停。他手底下有二十幾個人，而且他在找一個十一歲的。** 你的答案被打臉 |
| **7-2 總得有一個人先不報** | 主張**去勸他停**（**他把主角那句話搬出來用**） | **那少年一字不差地回了子羽當初的反問。** 你的答案被打臉 |
| **7-3 書不管後面的事** | **不表態**，把決定丟回給主角 | 兩樣都看見了，而你還是不知道——**因為那個答案本來就沒說什麼** |

> **⚠ 唯一沒被打臉的，是那個什麼都沒回答的答案。** 這就是「尋找答案」的結果。**收尾不得點破，只演。**

**⚠ 子羽在 0.2.2 帳上，但本關不做結算。** 結算點是 `劇情/歸姓.md`（人物結局）——**而它的分岔完全由本關 4-3 與 §7-1 決定**（見附錄一）。

**⚠ 寫法紅線：**

1. **那少年不是壞人，也不是反派。** 他冷靜、務實、不辯解，**而且他做的每一件事都說得出理由**。他甚至覺得自己還在做對的事。
2. **常氏是真的該死。** §4-2 那疊契會證明這件事。**不得為了讓玩家好過，把常氏寫得沒那麼壞。**
3. **那個十一歲的孩子不得說話超過三句，也不得寫得可憐。** 他躲著，他怕，他不懂發生了什麼事。**就這樣。**
4. **子羽全關話比平常更少。** 他不解釋自己為什麼要來、不提〈戴天〉那個晚上——**那要由那少年說破。**
5. **不得讓任何人指出「這少年變成了另一個常氏」。** 讓玩家自己撞。
6. **⚠ 不得碰「好紅的臉」。** 那三個字全劇只發作過一次（`劇情/羽之演武.md` 5-3），**用掉就沒了。**
7. **不得發明子羽的故鄉、妹妹、或那樁舊仇。** `@角色設定/子羽.md`「未定（AI 不得發明）」第 1 項。**本關的共鳴要全部靠場上的事撐起來。**

## 附錄二：設計筆記

1. **一座塢就夠了，不必做陽曲城。** 陽曲是太原郡屬縣，緊鄰晉陽（子羽的武館就在晉陽）——**大地圖開一個點、進去是一座地城**，這是趙王洞、水濂洞、五原障已經在用的形狀，而且比五原近，成本更低。
2. **「答案」由三個東西合起來給，而且沒有一個是解答：**
   * **地磚上的血**——砍了很久（那少年真的辦成了，而且辦得很難看）
   * **四十七張契**——常氏真的該死，而且不只欠他一條命（**殺得沒有錯**）
   * **那少年本人**——他報完仇沒有走，而且他在找一個十一歲的（**活體**）
   **三樣都是真的，互相不能調解。** 這正是「尋找答案」該有的結果（同 `劇情/五原障.md` 設計筆記 2）。
3. **那少年不可憐、不辯解、不後悔。** 他講他怎麼爬回去三次的時候要**很順**——那個順比任何台詞都說明問題。而他說「多謝」的時候要**誠懇**。
4. **⚠ 這一關把〈戴天〉那條規矩翻了一面。** 子羽不斬女流老幼，所以他沒有傷那個少年，也沒有攔他。**那條規矩護住了他不被子羽所傷，卻沒有護住他不變成子羽。** 而現在他在找一個十一歲的——**那個十一歲的，正好也在那條規矩裡。**
5. **§4-3 必須先聽才找得到，這一點不能改。** 直接推門一定找不到——**那孩子聽見腳步就不動了。** 這不是懲罰，是這一格唯一誠實的做法：**你得先站住、先安靜，才聽得見有人在。**
6. **§7-B 是全案最狠的一次回收。** 〈戴天〉7-2 主角說「總得有一個人先不報」，子羽當場反問「那一個，憑什麼是他」，主角答不上來；現在**子羽把主角的話搬出來用，而那少年一字不差地回了子羽當初的反問。** 三個人繞了一圈，站回原地。**不得有人指出。**
7. **§8 他不知道自己在複述莫雪。** 「重了，拔得慢。慢一分，想得起來」＝「是受限，亦是保護」。**他以為那是他自己想出來的**——而某種意義上也確實是：他花了整整一趟路才把那句話變成自己的。**不得點破。**
8. **「讎」字兩邊都是人。** 全支最後一句，也是他自己給的答案。他問的是「那被殺的那個，他兒子呢」；在陽曲他看見了那個兒子，也看見了報仇的那個已經變成被報的那個。**他不知道自己剛剛回答了自己。** 留給結局兌現。
   **⚠ 主角看不出那個字有什麼兩邊——這是刻意的。** 玩家看不看得出來，是玩家的事。
9. **⚠ 待填：**
