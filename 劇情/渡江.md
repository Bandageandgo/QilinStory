# 支線：渡江（呂信）

> **全新場次。** 這是呂信線的第四支，**直接延續 `劇情/英布.md`**。
> **⚠ 本支的職責只有一個：把問題提出來，而且不給答案。** 依既定路線圖——
> **呂之門路 →〈仗義疏財〉→〈英布〉→〈渡江〉（質疑／反思，無答案）→ 尋找答案（箱庭探索．大事件）→ 人物結局。**
> **⚠ 前置：** 完成 `劇情/英布.md`（任一分支皆可）。
> **⚠ 沒有「指派」系統。** 本檔掛好感度門檻＋前置旗標。

---

## ⚠ 最重要的一條紅線：這一支不准有答案

**本支結束時，呂信的疑問必須仍然懸著。**

- **他不得想通任何事。**
- **主角說什麼都不改變他。** 三個回答的差別**只在他用哪種方式把話推開**，以及留下哪一顆樁——**那三顆樁要留給後兩支用。**
- **旁白不得下任何判語**，不得暗示哪個答案是對的。

**如果這一支給了答案，後面那支「尋找答案」就沒有東西可找了。**

## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關的特殊處：這一關真正在選的人不是主角，是呂信——而他選完了才發現自己猶豫過。**

| | 內容 |
| :--- | :--- |
| **發生什麼** | 赤龍幫幫主褚人飛親自到英豪府談投資，順道**開價要呂信**。錢、地盤、兵，樣樣是英豪府給不起的 |
| **呂信怎麼做** | 拒絕。乾脆、大聲、很他 |
| **問題在哪** | **他拒絕之前停了一下。** 而那一下，只有站得夠近的人看得見 |
| **主角的位置** | 他是唯一站得夠近的人。**而當晚呂信來找他喝酒，問了一個沒有答案的問題** |

### ⚠ 這一關的暗對位（不得說破）

| | |
| :--- | :--- |
| **呂信崇拜** | 項羽 |
| **褚人飛崇拜** | 劉邦——「劉邦當年也不過是個亭長，老夫為何不能成皇？」（`@角色設定/褚人飛.md` 代表性對白） |
| **而英布** | 正是從項羽那邊，跳到劉邦那邊的人 |

**⚠ 全關不得有任何角色點破這個對位。** 褚人飛不知道賈詡說過那句話；呂信不會把兩件事連起來說；主角也不准在心裡把它講明。**玩過 `劇情/英布.md` 的玩家自己會撞到——那一撞就是這一關全部的效果。**

### 這一關扣在他那本帳上

| 呂信 | 正 | 反 |
| :--- | :--- | :--- |
| — | 不擇手段是為了重建英豪府（**重感情還在**） | 為了出人頭地、倚仗武力，**變質** |

**他拒絕了，這是「正」。而他猶豫了，這是「反」第一次真的動了一下。** 兩件事同時發生，**本關不裁決哪一件比較真。**

**⚠ 結算點不在這裡**（呂信的結算點在哪一關、門檻多高＝**未定，AI 不得發明**）。

**⚠ 寫法紅線：**
1. **褚人飛不是壞人，也不是誘惑者。** 他是真心欣賞，開的價是真的，講的話是真的。**他甚至沒有要挖英豪府的牆角的自覺**——在他的世界裡，好漢就該去有肉吃的地方。
2. **呂信拒絕得很漂亮，不得寫成勉強。** 他的拒絕是真心的。
3. **那一下猶豫不得被任何人指出來**，包括主角。洞悉成功只讓玩家看見，**主角不得說出口。**
4. **他不提英布，不提賈詡那句話。** 他問的是項羽。

## 附錄二：設計筆記

1. **這一支的主體是呂信，不是主角。** 前三支都是「主角看見／主角決定」；這一支是**呂信自己撞上一件事，然後自己問出一個問題**。主角只是那個在場的人——**而他最重要的動作是把話嚥回去**（§7）。
2. **褚人飛必須真誠。** 他不是誘惑者、不是反派、不用陰的。他開的價是真的，他笑得是真的，他那句「老夫這扇門，不關」也是真的。**一個好的挖角，靠的是對方真的很好。**
3. **賈詡不留人，這一點不能軟。** 他喝茶、他不加價、最後只說「今年的餉，還是發不出來」。**那句話比任何挽留都重**——他在提醒呂信，你剛剛推掉的東西，這裡真的沒有。**而他把判斷完全交給呂信自己。**
4. **「三息」是這一關的機關。** 呂信全案的人設是「聽到重點便足矣」「我這人最受不了等了」（`劇情/仗義疏財.md`）——**他從來不用三息。** 所以那三息是全案第一次，他的「反」那一極真的動了。**而洞悉沒過的玩家永遠不會知道。**
5. **「霸王要是渡了那條江，他還是霸王嗎？」** 這句直接扣 `劇情/英布.md` §1 那一幕（「烏江邊上有一條船，項羽沒有上」），而**呂信自己不知道這兩件事有關**。它同時是：一個沒有答案的問題、一個他不敢問自己的問題、以及一個玩家早就知道答案的問題。
6. **三個回答刻意都不改變任何事。** 依本檔開頭紅線：這一支不准有答案。**但三個回答不是白選的**——它們是後兩支的輸入。這是全案第一次，一個選擇的意義**完全延後**。
7. **⚠ 對位不得說破。** 呂信崇拜項羽，褚人飛崇拜劉邦，而英布是從項羽跳到劉邦的人。**三個角色沒有一個知道這件事，只有玩家知道。** 一旦有人說破，這一關就從「你看著他站在岔路口」變成「有人告訴他這是岔路口」——**完全不同的兩件事。**
8. **⚠ 待填：** 無。本支無戰鬥、無小遊戲、無貴重品、無數值門檻，**可直接進 JSON**。
