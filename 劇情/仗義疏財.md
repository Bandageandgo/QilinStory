# 支線：仗義疏財（呂信）

> **出處：** 概念與台詞取自 `劇情/第二章劇本.md` 支線6（1355–1415 行），改寫為現行劇本格式。
> **⚠ 命名統一：** 原檔標題作「仗義**散**財」，但 `支線7 雙世冥劍` 的解鎖前置寫的是「仗義**疏**財」。**本檔統一用「仗義疏財」**，舊檔那兩處請一併對齊。
> **⚠ 觸發改掛：** 原文寫「呂信好感度達 Lv1 後，雲中客棧觸發」——此條件現行系統支援，**維持不動**。沒有「指派」系統，本檔不使用。

## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關的特殊處：這一關不是主角自己伸手，是他站在旁邊看別人伸手。**

| | 內容 |
| :--- | :--- |
| **這一手是誰的** | 呂信的。不聽完就去砍、提著人頭回桌、拿錢把人打發走 |
| **哪裡管用** | 一炷香就結案。土匪死了、父女拿了盤纏、同夥當晚一次清乾淨。主角想了半天沒想出的辦法，他做完了 |
| **哪裡不是俠** | 沒審、沒證、沒問過那父女要不要；牆上留名是為了引人來殺。**話本裡這叫替天行道，手法不是** |
| **主角的位置** | 全程只能接話、只能跟上。**他這一關學到的是「原來還能這樣辦」——這正是高概念那句「每一手都管用」** |

**對應 0.2.2「累積的是人・各自結算」：**

| 呂信 | 正 | 反 |
| :--- | :--- | :--- |
| 同樣散財殺人 | 不擇手段是為了重建英豪府（**重感情還在**） | 為了出人頭地、倚仗武力，**變質** |

**⚠ 本關只負責讓玩家「看見他的理由」，不做結算。** 依指南 0.2.2，**每個人的結算點在哪些關卡、門檻多高＝未定，AI 不得發明**。本檔只留 `SetFlag` 樁（見附錄一），數值與門檻等你拍板。

**⚠ 不給數字（指南「症狀：不給數字」）：** 不做聲望條、不做恐懼值、不在 UI 顯示。玩家看不看得見他的理由，只反映在**別人怎麼叫他、怎麼看他**——本關落在「散財義士」這個稱呼上。

**⚠ 寫法紅線：** 呂信**不得自陳**「我這麼做是為了英豪府」。他的迷惘用豪語包住（`@角色設定/呂信.md` 性格特質 2、3）；玩家要嘛從洞悉檢定看出來，要嘛看不出來。**看不出來是允許的結果，不是懲罰。**
