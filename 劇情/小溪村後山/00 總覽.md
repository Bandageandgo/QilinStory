# 小溪村後山（箱庭文案總覽）

> **本檔由 `Json/` 回讀產生，不是創作稿；遊戲內文案的唯一事實來源是各章節對應的 JSON。**
> 改字請指名錨點（例：「`小溪村後山/赫連娜娜、張寧.json` #741 這句改成…」）→ AI 改 JSON → Unity 同步 → 重新回讀本檔對應章節。直接編輯本檔的文字**不會進遊戲**。
> 規則：`給AI看的指南/Unity對話同步流程.md`〈文案總覽稿〉；本檔各章節在其他總覽稿的收錄關係見 `劇情/索引.md`。

> **怎麼讀本檔**
> - 一份 JSON ＝ 一個 Unity 對話，**依箱庭區塊分檔**：同一塊區域裡的互動點寫在同一檔。因此一檔裡通常有好幾段互不相連的戲，每段的第一個節點即該互動點的進入處，本檔用 `### N-k　入口 #X` 分段，一段一段走完；這些段落之間沒有連線是正常的，不是斷線。
> - 每段從入口往下讀，遇到分岔就往下縮排（`▶`＝第一層、`▶▶`＝第二層…）；不同路線又走回同一句時，只寫「→ 接 `#N`」，不重複貼一次。
> - 「**◆ 玩家選擇**」是玩家點選項的地方；「`- 分流：…`」是遊戲自己依條件挑路走，標籤（「檢定成功」「戰鬥勝利」）是把 JSON 的 Conditions 翻成白話，原始寫法仍照抄在該節點的 `Conditions:` 行。
> - 「**孤兒節點**」＝ 沒有任何節點連到它、它也不連去別處的節點，遊戲中播不到（多半是廢稿），照抄保留。
> - 文案中的 `<br>` 是原始 JSON 裡就有的換行，不是新加的。

## 場景與人物（供讀劇情用）

**地點：** 後山林間空地（狗頭人吊著籠子處）、張寧採藥歇腳的屋子、通往後山的山路（§2 兩場遭遇）、荒郊野嶺的一間破屋與其下的地底墓室（§3）。村長口中「萬萬去不得」的那片林子、雍仔說藏著前朝古墓的地方，都是這裡。
**登場人物：** 燕不凡（MC1）、赫連娜娜（MC22）、張寧（MC6）、狗頭人三隻、林中怪物；§2 另有攔路匪（role12）與紅楓樹下的神秘刀客（role85）；§3 是燕不凡與雍仔（MC20）兩人。
**接續關係：** 由 `劇情/小溪村/12 赫連娜娜.md`（娜娜算命，叮囑近日往後山）引來；娜娜在本章入隊，張寧在本章初識並留下金創藥。
**§2 的定位：** 兩場與主線無涉的山路遭遇，各自獨立觸發。刀客那場留了鉤子——答對謎底他說「我們會再碰面的」，且檔名帶「1」，續篇尚未進 `Json/`。
