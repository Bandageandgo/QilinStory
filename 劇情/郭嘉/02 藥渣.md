## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關的特殊處：這一關管用的那隻手，是「守信」。**

| | 內容 |
| :--- | :--- |
| **這一手是什麼** | 答應替他瞞。**而且他會用一個人情來付帳** |
| **哪裡管用** | 郭嘉的人情，是這座府裡最值錢的東西之一。他跟得上隊伍、你隊上有腦子、你多一個欠你的人 |
| **哪裡不是俠** | 你答應瞞的那件事，正在殺他。**而現場站著全并州最懂藥的人** |
| **哪裡最難** | **守信與救命撞在一起。** 話本裡這兩樣從來不會互相為難，這一關讓它們互相為難 |
| **主角的位置** | 他先私下答應一次，然後當著張寧的面，決定要不要守那個承諾。**兩次選擇之間隔了不到十句話** |

**⚠ 這一關沒有「兩全」的選項，也不得補一個。** 說了就是背信，不說就是看著。**兩邊都要有失去**（AI 原則第 8 條）。

**⚠ 郭嘉的寫法紅線（`@角色設定/郭嘉.md`）：**
1. **詼諧綁酒。** 清醒的郭嘉話短、偏冷；促狹嘴賤那一面**只在他沾過酒之後**。**本關要把「切換」演出來給玩家看**——他被撞見時是冷的，張寧一到，他先灌一口殘酒，才開始貧嘴。**這是本場最重要的一拍。**
2. **他不解釋自己為什麼要撐。** 不得讓他自陳「我要報仇所以得跟上」。他的仇清醒時藏在沉默裡。
3. **不得寫成酗酒。** 那是「就著送藥／壓惊」的殘酒，一小口，不是爛醉。
4. **他不求人。** 「別告訴別人，行不行？」已經是他能做到的最低姿態，再低就走味了。

**⚠ 張寧的寫法（`@角色設定/張寧.md`）：** 對病人進入絕對專業狀態，用嚴厲甚至恐嚇的語氣是她的「小心機」，**下手卻極輕**。她罵得越狠，手上越穩——這個反差要寫出來。

## 附錄二：設計筆記

1. **「切換」那一拍是這一場的心臟。** 角色檔把「詼諧綁酒」寫成硬規則，但那條規則在玩家眼裡一直只是台詞風格。**這一場讓玩家親眼看見他伸手、灌酒、換臉**——從此以後，郭嘉每一次貧嘴，玩家都會多想一秒。**一個設定要變成體驗，就得有一場戲把它演出來，這就是那一場。**
2. **兩次選擇之間刻意不留緩衝。** 主角在 §3 剛答應，§4 張寧就到了。**如果中間隔了一天，守不守約就會變成一個從容的道德題**；隔十句話，它才是一個逼人的題。
3. **守信是這一關的「管用的手」，這是刻意的錯位。** 高概念說「每一手都管用，沒有一手是俠該用的」——多數關卡裡不俠的那手是騙、是殺、是行賄；**這一關把守信排在不俠那一邊**。因為守的是一個正在殺人的承諾。**這是全案唯一一次讓「信」跟「仁」互相為難的機會，別浪費。**
4. **張寧不是來破案的。** 她進場時就已經知道了（她在角色檔裡「很早就看出他在偷偷服藥」）。她問主角「你剛才在這裡多久了」——**問的不是郭嘉，是主角**。§6-3 張寧那句「不用你說。這種事我看得出來。」把這件事點破一次，其餘兩條不點。（✏ 2026-09-27：原寫「§6-3 的收尾」；6-3 的黑幕改稿後（N0894）不再點破，改指這句台詞）
5. **郭嘉全場沒有求救，也沒有道謝。** 他最軟的一句是「行不行？」，最重的一句是把命算進債裡。**兩句都不是求人，是報價。**
6. **失敗不懲罰。** 洞悉失敗＝沒看清楚，事情照樣發生；醫術失敗＝看不懂那是什麼藥，戲照走。依 0.2.3，**擲骰失敗只是「這條路沒開」**，這一關不得因為骰子不好而讓任何人出事。
7. **可延伸（未定，供拍板參考，不是提案）：** 若日後要接住這條線，最自然的兩個接口是——**張寧那邊**（她開了藥、他吃不吃，需要一支她的個人任務去接，而她目前只有一支任務）與**賈詡那邊**（張寧在 6-2 威脅「直接去問賈詡」，而賈詡對郭嘉「另有安排」）。**兩條都需要你先拍板延壽條件，AI 不動。**
