# 支線：其所不見（郭嘉・信任線之二）

> **全新場次。** 概念出自 `@角色設定/郭嘉.md`「從史料讀他的人格」第 7 點——他評袁紹那句：
> **「紹見人饑寒，恤念之形於顏色，其所不見，慮或不及也，所謂婦人之仁耳。」**
> **他鄙視的不是心軟，是「只對眼前看得見的人有感情」。** 這一關讓主角做一次他自己會做的事。**⚠ 2026-08-29 改口：不是他在量主角，是主角為他付了一次**（見 `劇情/郭嘉/郭嘉.md` 第二節）。
> **⚠ 檔名是作者層的。** 「其所不見」四個字**不得出現在遊戲內文本**（十勝十敗出自裴注引《傅子》，本曲不得引用條目原文）。若嫌隱晦，可改名〈**無人知**〉，內容不必動。

## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關的特殊處：這是全案唯一一次，俠的做法「完全沒有用」——而它才是對的。**

| | 內容 |
| :--- | :--- |
| **場面** | 回程路上，山道塌了一段。**你們已經過來了。** 受影響的全是後面的人 |
| **管用的做法** | 走。天要黑了、差事在身，**而且真的不會有人知道** |
| **俠的做法** | 停下來。花時間、費力氣、**零回報、零見證** |
| **哪裡「沒有用」** | 沒有報酬、沒有經驗、沒有人道謝、**連你救到的是誰都不會知道**。以任何一種算法算，它都是虧的 |
| **主角的位置** | **他以為沒有人在看。** 這一點是本關的樞紐——**一旦他知道有人看，這場戲就變成表演了，而表演正是郭嘉鄙視的那個東西** |

**⚠ 這一關與 `劇情/郭嘉/03 欠條.md` 是一組，方向相反（**2026-08-29 改口：兩支都是「你為他付了一次」，不是他在量你**）：**

- **〈欠條〉：** 你為了他，**坑了一個不在場的人**——而那人後來怎麼樣，你永遠不會知道。
- **〈其所不見〉：** 你在沒人看的時候，**顧了一個不在場的人**——而你救到的是誰，你也永遠不會知道。

**⚠ 兩支都收在「你永遠不會知道」。不要在任何一支裡點破這個對稱。** 走過兩支的玩家自己會感覺到。

**⚠ 郭嘉在 0.2.2 帳上，但本關不做結算。** 只留樁；延壽條件與結算點**未定，AI 不得發明**。

## 附錄二：設計筆記

1. **這一關的樞紐是「主角以為沒人在看」。** 一旦玩家事先知道郭嘉在看，這場戲就變成表演——**而表演正是郭嘉鄙視的那個東西**（他罵袁紹「恤念之形於顏色」）。所以 §4-2 當下**絕對不能**有任何暗示：他不問、不看、不停頓。**要到幾天後才翻牌。**
2. **「我回頭了。你沒有。」** 這七個字是整支的核心。**它同時說了兩件事**：他確實看見了；而他之所以看見，是因為**他自己回頭確認過那條路**——他也是會想到後面那些人的人。**兩個人在同一件事上對上了，而誰都沒有說破。**
3. **刻意沒有檢定。** 洞悉那一道只決定**你知不知道有多嚴重**，不決定你辦不辦得到。搬石頭不需要骰子——**這一關要問的是「你選不選」。** 加檢定會把一個道德選擇變成技能門檻。
4. **「走」那條寫得很寬容，這是刻意的。** 天黑、差事在身、洞悉沒過的話他甚至不確定那條路有問題。**任何一個正常人都會走。** 如果讓玩家覺得自己被設計成壞人，這一關就失效了——**它要的是「我當時真的可以走，但我沒有」，而那需要「走」是一個體面的選項。**
5. **兩支中段的對稱不點破。** 〈欠條〉的收尾是「那個人後來怎麼樣，你這輩子也不會知道」，本關兩條收尾都是「你這輩子也不會知道」。**同一句話，一次是債，一次是給。** 玩家自己會撞到。
6. **他為什麼挑「藥的來歷」來交換。** 因為那是他全身上下唯一一件**只要說出口就會被人拿去用**的事。他把它給你，等於把把柄給你——**對一個「不把名聲放進計算式」卻死死藏著這件事的人，這是他能給的最重的東西。**
7. **⚠ 待填：** 開頭那件小差事（野貓）可替換成任何一件反高潮的雜務，**但必須是虛驚一場**——這一關的重量全在回程，前面越無聊越好。
