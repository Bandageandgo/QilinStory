## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關的特殊處：俠的做法真的把事情辦成了——只是在這個人身上沒有用。**

| | 內容 |
| :--- | :--- |
| **他做了什麼** | 為了換一條線索，**以英豪府的名義**擔保了一筆他付不出的數。**他算得出來自己虧了，他還是換了** |
| **俠的做法** | 去找賈詡。府裡出面，三兩下擺平，沒人受傷，**賈詡還欠你一次** |
| **它的代價** | 他知道是你去說的。**他不生氣——他只是從此對你客氣。客氣就是遠** |
| **管用的做法** | 自己去找那個掮客談。字據銷了，**而他不知道是你** |
| **它的代價** | 你騙了他；而且掮客要的不是錢，**是你替他供出一個躲債人的下落——那人後來怎麼樣，你永遠不會知道** |
| **信任落在哪** | **管用那條。** 因為那正是他自己對人的方式 |

**⚠ 為什麼信任落在不俠的那一條——這一關的全部重量在這裡。**

`@角色設定/郭嘉.md` 性格特質 6：

> 「實際在意之人若真出事，他會用自己的方式默默補位——**通常是讓對方根本不知道是他出的手。**」

**所以取得他信任的唯一方式，是用他的方式對他。** 對他好沒有用，他只會歸類成「這人有用」。**你得在他失手的時候替他把事辦完，而且不讓他知道。**

**⚠ 但求援那條不是錯誤選項，寫的時候不准把它寫成錯。** 它真的把事情辦乾淨了、沒有人被賣掉、還多一個賈詡的人情。**它只是在這個人身上不管用。** 這正是高概念要的那句話——**每一手都管用，只是沒有一手是俠該用的**：這一次連順序都反過來了，**俠的那手管用，卻換不到你要的東西。**

**⚠ 這一關與 `劇情/郭嘉/04 其所不見.md` 是一組（**2026-08-29 改口：兩支都是「你為他付了一次」，不是他在量你**）：**

- **〈欠條〉：** 你為了他，**坑了一個不在場的人**。
- **〈其所不見〉：** 你在沒人看的時候，**顧了一個不在場的人**。

**兩支的方向相反，而量的是同一件事。** 兩支都做過的玩家，會自己感覺到那個對稱——**不要在任何一支裡點破它。**

**⚠ 郭嘉在 0.2.2 帳上，但本關不做結算。** 只留樁；延壽條件與結算點**未定，AI 不得發明**（`給AI看的指南/文本創作指南.md` 0.2.2）。

## 附錄二：設計筆記

1. **這一關把高概念倒過來演了一次。** 別關是「不俠的手比較管用」；這一關**兩隻手都管用**——找賈詡甚至辦得更漂亮。差別在於**你要的那樣東西（他的信任）只有一隻手拿得到**，而那隻手是髒的。**寫的時候絕不能把求援那條寫成錯。**
2. **五千錢刻意設在「玩家掏不出來」的高度。** 如果玩家能自己付錢解決，這一關就變成一道消費題。**掮客要的不是錢，這一點是這關的樞紐**——它逼出「你願意拿別人去換嗎」。
3. **掮客沒有立繪、沒有名字，這是刻意的。** 他不是反派，他只是個做生意的人。**他甚至很客氣。**
4. **那個躲債的人從頭到尾沒有出場。** 他只是主角記憶裡「城西糧行後門一個縮著肩膀走得很快的人」。**整關最重的一筆落在一個從未露臉的人身上**——這正是袁紹那條「其所不見，慮或不及也」量的東西。
5. **郭嘉全關清醒，所以全關沒有一句玩笑。** 他最長的一句話是 4-2a 那段推理（「五千錢，三日，沒人來收……剩下的就只有你」）——**那不是感謝，是他在你面前算了一次帳給你看。對他來說那就是最高的敬意。**
6. **「我沒問你付了什麼。你也別說。」** 這兩句是他的道謝。**不得改成任何更明白的說法。**
7. **⚠ 待填：** 五千錢的數值是否合理（要對照現行物價與玩家財力曲線）；`JiaXu_OwedYou` 這個人情日後兌不兌現。
