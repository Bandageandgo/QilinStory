## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關的特殊處：俠的堅持擺在最前面，然後它逼出了一整串不俠的手。**

| | 內容 |
| :--- | :--- |
| **最管用的做法** | **一舉焚之。** 蝹種築巢在亂葬崗，一把火下去，輕而易舉——郭嘉自己說的 |
| **為什麼不用** | 那是逝者的地方。**郭嘉否決了它**（「即便無名，逝者也有應得的尊敬」），**雍仔也否決了它**（「死者為大，入土為安」） |
| **於是他們做了什麼** | 去**偷**賈詡的解剖屍體、去**騙**徐榮下廚，把兩位師父的東西混成一份「超越死亡的氣息」當誘餌 |
| **哪裡不是俠** | 偷師父的、騙師父的、把難吃的飯推給同門。**每一手都不大，加起來卻是一整串** |
| **主角的位置** | **這一關是他出的主意。** 從頭到尾都是他在安排誰去坑誰 |

**⚠ 這是全案把引擎演得最完整的一關，因為它的因果是反過來的：**

> **不是「他選了不俠的做法」，是「他堅持了俠的那一條，結果被迫用了五種不俠的手」。**

**守住一件對的事，代價是別的地方全歪掉——這比單純的「要不要作惡」難看得多，也真實得多。** 寫這一關不要把任何一手寫成壞事，它們全都是為了不燒那片亂葬崗。

### 三個人各自的一格

| 人 | 這一關給他什麼 | 紅線 |

## 附錄二：設計筆記

1. **這一關的引擎是反過來的，這是它最值錢的地方。** 別關是「主角選了管用的做法」；這一關是**他們先守住了一件對的事，然後為了守住它，被迫用了一整串不俠的手**。寫的時候不要替任何一手道歉——偷、騙、坑同門，全都是為了不燒那片亂葬崗。**收尾那兩句黑幕旁白負責把這件事講一次，其餘地方一個字都不要提。**
2. **郭嘉全關滴酒未沾，所以他全關沒有一句玩笑。** 這是 `@角色設定/郭嘉.md` 的硬規則。**與 `劇情/郭嘉/02 藥渣.md` 並看**：那一關玩家會親眼看見他灌酒換臉，這一關他從頭冷到尾——**兩關擺在一起，玩家才知道哪一個是他。**
3. **「逝者應得的尊敬」與「那就好，我就怕你們不會感到疼痛」是同一個人，同一天，隔不到一個時辰。** 這一關不解釋這件事，也不讓主角評論它。**主角只問了一句「你很習慣這些事？」，然後他就把家仇講了**——那句問話是全關唯一的處理方式，夠了。
4. **賈詡那一段逼近紅線，所以我把洞悉放在那裡當閘門。** 讓玩家用一個檢定去「看見」，比讓旁白直接宣布「你看見一絲期盼」好——**因為那樣它就變成劇情告訴你的事實，而不是你自己抓到的東西**。骰輸的玩家看到的就只是罰錢三千，這是允許的結果。
5. **戰鬥失敗不再是死亡。** 原文那句「往後歷史皆與你無關，不勝唏噓」是舊時代的寫法，一支支線不該有 game over；而且依 0.2.3 的精神，**代價越重的判定越不該交給運氣**。改寫後輸掉反而多看到一樣東西——這符合 `劇情/呂信/01 仗義疏財.md` 設計筆記 3 已經定下的原則。
6. **§3 那個選擇沒有好壞，只有誰去受罪。** 標籤標成機略／仁心是為了讓玩家意識到自己在選什麼，**但兩條路的產出完全一樣**（都拿到誘餌、都推進劇情）。差別只在你玩到誰的戲——這是這一關唯一的重玩理由。
7. **⚠ 待你拍板：賈詡線與徐榮線互斥，這樣好不好。** 現況忠於原文：一輪只玩得到一段，另一段用一兩句交代（郭嘉的臉色）。**代價是這兩段各自是那兩人全案最好的個人文本之一，而玩家一輪只看得到一半。** 若要改成兩段都跑，流程要重排（誘餌需要兩樣東西，本來就有兩個人去拿）。**我沒有自己改，因為那會動到原設計的重玩結構。**
8. **⚠ 待填：** 戰鬥場次 ID、釣魚小遊戲的呼叫指令、450 錢的扣除方式。另 §5 雍仔那句是新加的（原文此處只有旁白），**若嫌多可刪**。
