## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關的引擎在最後：牠死了，線索指向更遠——他要追下去。你拉不拉他。**

| | 內容 |
| :--- | :--- |
| **管用的做法** | 陪他追。他有用、他自己要去、而且追下去說不定真能討到那筆債。**你多一個欠你的人，他多一個幫手** |
| **俠的做法** | 拉住他。府裡有人等、他的身子撐不了下一程。**代價：他的仇就停在這個村子** |
| **哪裡難** | 拉住他，是在替他決定那筆債不討了——**而那筆債本來就不是你的** |

**對位呂信的〈五原障〉：** 他來這裡找答案，這裡給他三樣互相矛盾的東西（告示／四副碗／牠），**沒有一樣是解答**。他離開時說一句他自己不知道是答案的話。

**⚠ 郭嘉的寫法紅線：**
1. **全關清醒。** 一句玩笑都沒有。話比〈其所不見〉還少。
2. **他到了村口就認出這是他家那件事的翻版，而他一個字不說。** 旁白只寫他停了、看了、走了，**不寫他想什麼**。
3. **他走得比山道那次更硬。** 這一關要讓玩家看見「跟得上」是什麼樣子——他停的次數更多，每次更短。
4. **不得讓他在牠面前失控。** 他攪蝹種傷口那種冷，這裡再來一次，**但更慢**。

## 附錄二：設計筆記

1. **三樣東西（告示／四副碗／牠）沒有一樣是答案。** 牠打得死，可是告示還是寫瘟疫，碗還是四副。**他來這裡討債，發現債討不完**——這是他自己說「不止這一處」的重量。
2. **他從頭到尾沒講一句自己家的事。** 「四副」是全關最接近的一次。**這一關是演給玩家看的，不是講給主角聽的。**
3. **7-2 必須真的管用。** 陪他追，他們真的多走了一程。如果陪他只有壞處，引擎就變回道德分了。代價全部收在停的次數上——五、九、十四——**旁白只給數字。**
4. **7-3 是〈逝者無聲〉那句的回聲，刻意的。** 那次他說「也肯陪著蹲」，這次「也肯扛」。**他認人的方式從來就是這一種。**
5. **戰鬥失敗兩條都不是死亡。** 第一場退回村口，第二場牠走了。依 0.2.3，運氣不好只是這條路沒開。
6. **⚠ 待填：** 兩個戰鬥場次 ID；情報網條目編號（暫記 #19）；「更遠是哪裡」定了之後 §5 與承 7-2 要回填；那東西的本名定了之後要不要補外形。
