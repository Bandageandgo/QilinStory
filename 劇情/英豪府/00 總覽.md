# 英豪府（箱庭文案總覽）

> **本檔由 `Json/` 回讀產生，不是創作稿；遊戲內文案的唯一事實來源是各章節對應的 JSON。**
> 改字請指名錨點（例：「`英豪府遴選/大廳.json` #541 這句改成…」）→ AI 改 JSON → Unity 同步 → 重新回讀本檔對應章節。直接編輯本檔的文字**不會進遊戲**。
> 規則：`給AI看的指南/Unity對話同步流程.md`〈文案總覽稿〉；本檔各章節在其他總覽稿的收錄關係見 `劇情/索引.md`。

> **怎麼讀本檔**
> - 一份 JSON ＝ 一個 Unity 對話。本檔收 `Json/英豪府遴選/`（遴選當日的會場）與 `Json/英豪府遴選(後)/`（大廳說明之後、各考官的個別考驗）**兩個子層**，共 9 檔；另收 §10 `主線事件/180年/2月.json`（遴選結束那場戲的**主線那條路**，作者 2026-08-27 裁示本檔也要收）；**箱庭那條路是第 10 檔 `英豪府遴選(後)/遴選結束.json`**，內容與 §10 逐句相同、錨點另成一套，見 §10-2。JSON 的兩層子資料夾不動，總覽稿合成一份。
> - 每段從入口往下讀，遇到分岔就往下縮排（`▶`＝第一層、`▶▶`＝第二層…）；不同路線又走回同一句時，只寫「→ 接 `#N`」，不重複貼一次。
> - 「**◆ 玩家選擇**」是玩家點選項的地方；「`- 分流：…`」是遊戲自己依條件挑路走，標籤（「檢定成功」「任務 CF16 ＝ 已觸發」）是把 JSON 的 Conditions 翻成白話，原始寫法仍照抄在該節點的 `Conditions:` 行。
> - 「**孤兒節點**」＝ 沒有任何節點連到它、它也不連去別處的節點，遊戲中播不到（多半是廢稿或場景氣泡），照抄保留。
> - **本檔文案中的 `<br>` 是原始 JSON 裡就有的換行**（英豪府這批 JSON 幾乎每句都在句中斷行），不是新加的；比照 `劇情/小溪村/` 的慣例標示。
> - 引號、旁白格式與立繪 ID 的客觀錯誤已於 2026-08-26 依作者裁示修進 JSON，見下方〈修正紀錄〉。
> - 本檔範圍＝英豪府會場與府內。雲中城本體見 `劇情/雲中/`；遴選結束、正式報到那場戲收在 §10（`主線事件/180年/2月.json`），**與 `劇情/180年事件/02月(主)遴選結束.md` 主線 §1 是同一份 JSON 的同一份回讀，JSON 一改兩邊都要重讀**；同一場戲另有箱庭版 `英豪府遴選(後)/遴選結束.json`，**改文案時兩個 JSON 都要改**（§10-2 有錨點對照）。設定檔見 `劇情/英豪府/@設定_英豪府.md`。
