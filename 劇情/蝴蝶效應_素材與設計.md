## 一、規矩（設計與編劇都要守）

### 1-1 形狀（✅ 作者 2026-09-25，從屍丹案一路打回來的結論）

1. **一個選擇、一場戲、讀一次。** 序章的一票，在下一章找**一場**既有的戲讀它，讀完就完。不要一路帶著讀好幾場。
2. **在那個人自己的場用掉。** 選擇把一件東西交到誰手上，那件東西就在**那個人**的大場裡發作；別人的場不讀它。誰拿著，誰的場。
3. **不接鏈。** 不要「先看有沒有給 A、再看有沒有給 B、最後才到 C」。作者 2026-09-25 打回的那版就是這樣：每條路最後都流進賈詡，等於沒有分支，而且邏輯鏈太長。
4. **序章那一票就是選擇。** 到了下一章那場戲，不再問玩家第二次。角色自己就做了（作者：「她就會用」）。要加的是那場戲的另一個版本，不是另一個選項。
5. **出口合流。** 那場戲的出口不變、主線不分岔：入府那關過了就過了，趙王洞結尾昏迷一個月不變。差別留在人身上（誰變了），不留在流程上。
6. **每條路都要看得見差別，但差別可以是「沒有捷徑」。** 毀了屍丹＝照現行走，別人有的捷徑他沒有，這本身就是仁心的代價。不必硬給每條路一段新戲。
7. **先給動機再給機制。** 每個版本先寫清楚「這個人為什麼會這樣做」，再寫怎麼做。「主角當工具」那種太方便的動機不要。

### 1-2 引擎與狀態（硬紅線，出處 `CLAUDE.md`、`劇情/轉成json指南.md`〈注意事項〉）

- **不新建變數、不新建任務、不自取名字。** 蝴蝶效應一律**讀既有的**變數與任務 entry（第二節有清單）。真的需要新的，稿內留 `＿＿`（`Variable["＿＿"]`、`SetQuestEntryState("＿＿", …)`）等作者在 Unity 建。同伴的天賦樹也是作者用變數或任務狀態開的，**編劇不寫、不管**（作者 2026-09-25）。
- **`SetFlag`／`GetFlag` 禁用。** 記「玩家做過什麼」只有變數（`Script` 欄）與任務狀態兩條路。
- **能用純樹狀分岔解決的就不記狀態。** 讀一次既有變數、分兩三條、合流，是本檔所有案子的預設形狀。
- **已進 Unity 的 JSON 不改號、不改 `title`、不改註記；新分岔節點續號。** 未進 Unity 的可以直接加。哪些已進、哪些沒進，各箱庭 `00 總覽.md` 的收錄表與 `劇情/索引.md` 有記。
- **`Description` 只准詞表標籤**（`劇情/轉成json指南.md` §1）；設定出處、待辦、給作者的話不進這欄。

### 1-3 人（出處 `給AI看的指南/文本創作指南.md` 0.2.2）

- **累積的是人，各自結算，沒有總分。** 蝴蝶效應的差別要長在人身上：誰變了、誰記得、誰從此不一樣。不做隱藏分數，不做聲望條，不在 UI 顯示。
- **症狀不給數字。** 一個人變了，寫他怎麼說話、別人怎麼叫他，不寫「邪氣＋1」。
- **四軸只在結局讀一次。** `DnDAlignment` 可以寫（照指南第一層第 3 條的對照表），**過程中不得讀**。所以蝴蝶效應不能靠信義／機略的高低分岔。
- **饕餮三條紅線**（`@角色設定/饕餮.md` 第五、六節）：她不當眾開口要東西；醒了（骰子燙）不等於吃得到；她要吃到，只有他親手遞出去那一條路。凡是牽到她的版本，先過這三條。

### 1-4 交件前（出處 `CLAUDE.md`）

1. 寫任何已有台詞的角色之前，跑 `python 給AI看的指南/既有台詞.py <角色名或actorID>`，把他說過的話全讀一遍。
2. 劇本或 JSON 寫完，跑 `python 給AI看的指南/文風節奏檢查.py <檔>`，處理碎句與縮寫名詞。
3. 新轉出的 JSON 再跑 `python 給AI看的指南/json順序檢查.py <檔>`。
4. 逐詞查表用 `給AI看的指南/武俠文風審校清單.md`。
5. 改了 `text` 就重翻 `zh_CN`。

## 九、回音清單（作者 2026-09-27 立案；範圍是全部，不只蝴蝶）

**什麼叫回音：** 一句話的回頭。遊戲已經記下來的一件事（變數、任務狀態、貴重品、在不在隊、命盤旗標），後面某一場由某個人提一句。**不是換路**：換路歸本檔第一到第八節的蝴蝶；回音只加一格、掛一個既有條件。

**規矩：**
1. 只讀既有的名字：`Variable`、`CurrentQuestState`／`CurrentQuestEntryState`、`IsValuablesObtained`、`IsInTeam`、命盤旗標。**不建新變數、不建新任務號**（`CLAUDE.md` 硬紅線）。
2. 一列一個回音：素材、記在哪、可以在哪被提、由誰講、一句話的方向。方向不是台詞，台詞在執筆時寫。
3. 講的人要合他的位置：在場、認得這件事、有理由提。旁白不替主角下判斷（文風指南旁白卡第 3 條）。
4. 回音不改結果，不給獎勵，不開選項；要開選項就是蝴蝶，回第四節。
5. 高難度檢定十六場各留一個回音的位置，用既有任務狀態或 `IsHiddenN`。
6. 一個人物一場最多一句回音，免得像在點名。
7. 寫法（作者 2026-09-28 定）：回音新加的每一格（台詞格，以及為了讓「你」那格播得到而墊的無字條件空格）`Description` 都寫「回音」（已加進 `劇情/轉成json指南.md` §1 詞表，`json順序檢查.py` 放行沒有指令的回音格）；台詞裡**不掛** `[em3]` 前情標籤。上一格 `links` 最前面加新格的號、原連結不刪不換序，作者准。
