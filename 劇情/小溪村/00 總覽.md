# 小溪村（箱庭文案總覽）

> **本檔由 `Json/` 回讀產生，不是創作稿；遊戲內文案的唯一事實來源是各章節對應的 JSON。**
> 改字請指名錨點（例：「`小溪村/主線起始.json` #77 這句改成…」）→ AI 改 JSON → Unity 同步 → 重新回讀本檔對應章節。直接編輯本檔的文字**不會進遊戲**。
> 規則：`給AI看的指南/Unity對話同步流程.md`〈文案總覽稿〉；本檔各章節在其他總覽稿的收錄關係見 `劇情/索引.md`。

> **怎麼讀本檔**
> - 一份 JSON ＝ 一個 Unity 對話，**依箱庭區塊分檔**：同一塊區域裡的互動點寫在同一檔（例如 §5 收了茶攤的茶博士與村外山坡的牧羊人）。因此一檔裡通常有好幾段互不相連的戲，每段的第一個節點即該互動點的進入處，本檔用 `### N-k　入口 #X` 分段，一段一段走完；這些段落之間沒有連線是正常的，不是斷線。
> - 每段從入口往下讀，遇到分岔就往下縮排（`▶`＝第一層、`▶▶`＝第二層…）；不同路線又走回同一句時，只寫「→ 接 `#N`」，不重複貼一次。
> - 「**◆ 玩家選擇**」是玩家點選項的地方；「`- 分流：…`」是遊戲自己依條件挑路走，標籤（「檢定成功」「任務 C0F1 ＝ 未接」）是把 JSON 的 Conditions 翻成白話，原始寫法仍照抄在該節點的 `Conditions:` 行。
> - 「**孤兒節點**」＝ 沒有任何節點連到它、它也不連去別處的節點，遊戲中播不到（多半是廢稿），照抄保留。
> - 文案中的 `<br>` 是原始 JSON 裡就有的換行，不是新加的。
> - **本檔範圍＝箱庭模式下的小溪村村內**；後山見 `劇情/小溪村後山/`，大地圖上的小溪村節點見 `劇情/舊創作稿/大地圖的小溪村.md`，古墓見 `劇情/後山古墓/後山古墓.md`。

## 事件大綱：初出茅廬（自舊創作稿 `初出茅廬之一.md` 搬入，供讀劇情用）

**核心衝突：** 說書裡的英雄浪漫 vs. 沒錢吃飯的骨感現實，並意外捲入潛藏的危機。
**遊戲機制：** 初始階段籌措資金，達成目標後開啟小溪村根據地模式，自由探索並觸發關鍵劇情，最終面對因探索而引發的危機事件。

- **第一幕：盤纏！盤纏！** 燕不凡與蕭靈犀抵達小溪村，為三百錢住宿費發愁，與狗頭人茶博士互動；探索村中，與華陀、老學究等 NPC 互動、接任務籌錢；茶博士提及「有間客棧」老闆娘「一枝花」。籌到盤纏後前往有間客棧。
- **第二幕：客棧奇遇，林中故人，根據地開啟。** 一枝花竟也是狗頭人；付房錢後小溪村開啟根據地模式，等一個月馬車；村外森林遇自稱茅山弟子的胖道士雍仔，結伴往古墓。
- **第三幕：古墓驚變，黑山禍村。** 古墓探險喚醒黑山老妖；老妖赴村吸食陽氣；回村示警／迎戰。

**登場人物：** 燕不凡（MC1）、蕭靈犀（MC8）、茶攤茶博士（狗頭人）、村長、年輕郎中（華陀）、老學究、雍仔（MC20）、小花、阿婆、牧羊人、車夫、黑山老妖、一枝花（狗頭人）、童淵。
**主要地點：** 村口茶攤、村長家、村中空地（華陀曬藥）、村東小屋（老學究）、田埂邊（雍仔）、大樹下石桌（棋局殘譜）、河邊柳樹下／廢棄小屋後（小花）、河邊小路／小廟前（阿婆）、村外山坡（牧羊人）、村邊河岸（釣魚）、村後林子（古墓群）、有間客棧（根據地）。
