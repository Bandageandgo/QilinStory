## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關的特殊處：這是四支考題裡唯一一支「題目本身就是不俠」的。**

徐榮的原話是「行走江湖，交際人和不可免」。**而所謂交際，攤開來就是這兩件事：**

| | 赤龍幫 | 甄家 |
| :--- | :--- | :--- |
| **你要做什麼** | 對著一個剛當著你的面捏碎人腦袋的老頭，陪笑、送酒、乾杯 | 對著一個剛演完馭下之術的女人，說她愛聽的話 |
| **哪裡管用** | 酒喝到底，信物就給你 | 三句答對，信物就給你 |
| **哪裡不是俠** | 那人剛殺了人。**你什麼都沒說** | **正解是承認自己「大奸也是大盜」，然後把她捧成天。**誠實的那兩個答案，一律送客 |
| **主角的位置** | **兩邊都是他自己動手、自己開口。** 沒有師兄替他去砍，也沒有人替他遞袋子 |

**⚠ 甄家那三問，是全案把高概念講得最白的一次：**

> **「在下想與甄家交朋友，一片赤誠，天地可鑑。」→ 「人心隔肚皮，天地豈能見。來人，送客。」**

**說真話會被趕出去。說管用的話才進得去。而主角學會了，還用了三次。**

**⚠ 這句「一片赤誠」他在〈賈之嗜好〉也說過一次，也被趕出去過一次。** 兩支考題不必互相知道，但**玩家會記得**——那正是要的效果。

**⚠ 徐榮不在 0.2.2 帳上，本關不做結算。** 只留記錄用的樁，見附錄一。

**⚠ 寫法紅線：**
1. **徐榮不自陳「懷才不遇」。** 依 `@角色設定/徐榮.md`：「不把困難掛嘴上，多半以低調與實績回應」。他最多在收尾露一句，然後自己收掉（「那又是另一段故事了」——這是他在支線4〈逝者無聲〉已經定調的收句方式）。
2. **褚人飛殺毒販那一段不加評語。** 不寫「主角覺得他殘忍」，也不寫「主角覺得他豪爽」。**只寫他看見了什麼。**
3. **甄筠不是反派。** 她的馭下之術寫成本事，不寫成惡；她趕人也趕得有道理。

## 附錄二：設計筆記

1. **這一關的高概念不在選項裡，在正解裡。** 甄家三問，玩家**沒有**「用俠的做法過關」這個選項——誠實的答案全部送客。這不是懲罰玩家，是**把「說真話沒用」直接做成規則**。玩家答對三題會有解謎的爽感，而爽完之後才發現自己剛才說了什麼。**那個時間差就是這一關的全部。**
2. **「一片赤誠」要留著。** 這句話在〈賈之嗜好〉§1 被兩個字打發，在這裡被一句「天地豈能見」打發。**兩支考題各出現一次，都不要改字**——玩家第二次看到它時的反應，比任何旁白都有效。
3. **褚人飛那一段不給主角反應。** 舊稿寫「主角被眼前駭人一幕嚇到」，本檔改成只寫他看見的東西＋一句「他一個字都沒問那個人是誰」。**評語交給玩家**，這是指南「不給數字」的同一條原則的敘事版。
4. **徐榮的洞悉放在最後、而且可以不點。** 他是四位考官裡唯一一個**主動對主角好**的人（請吃飯、送馬、還道歉說題目太難）。所以他的裡層不能用逼的，得玩家自己想問。問了、又骰贏了，才拿得到那半句。**沒問也完全說得通**——他本來就不打算講。
5. **老馬是喜劇，也是他的全部。** 收尾那句「能拿得出來當賀禮的東西，大概也就這麼一匹」只在 `XuRong_ReasonSeen` 亮的時候出現。**沒看見的玩家就只是拿到一匹老馬，這是允許的結果。**
6. **兩件信物刻意用完全不同的手。** 赤龍幫靠身體（酒量檢定，硬功夫），甄家靠嘴（三問三答，沒有骰子、純選擇）。**一個玩家過不了的關，通常另一個過得了**——這讓「交際」這個詞在機制上也成立：交際不是一種本事，是好幾種。
7. **可延伸：** `@角色設定/徐榮.md` 有一條伏筆——他將見到主角父親董卓，並因欣賞其鎮守邊塞的作風而成為日後追隨的伏筆。**本關那句「刀比完了還得有人肯替你說一句話」是同一條線的第一節**：他缺的從來不是本事，是有人替他說話。**日後董卓那條線要接，接口就在這裡。**
