## 這場跟高概念怎麼接

**0.1：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。

**而「俠」是：重然諾、守信義、重情義、輕生死。** 所以管用與俠在結構上互斥——**管用＝那一份代價他沒付；俠＝那一份必須由他自己付。**

這箱庭裡他會拿到的手：

| 傢伙 | 哪一場 | 他躲掉的那一份 |
| :--- | :--- | :--- |
| 伸手拿銅鼎（雍仔慫恿） | 第一次入墓 | 該不碰的東西，他碰了——想空手而回的那份忍 |
| 郎中的煙、長生經 | 戰敗之後 | 該由他自己補起來的那段命 |
| 骰子擋那一擊 | 第一次瀕死 | 該由他拿命去換的那一次（**他沒選，而且他不知道那不是擋，是吃**） |
| 期限到了上車走 | 第二次之前 | 該由他了結的那樁禍 |
| **讓她吃屍丹** | 第二次打贏後 | 該由他自己扛的那口邪——**而且他這次是自己伸的手** |

## 原文哪裡已經對、哪裡空轉

**已經對（不要重寫整場）：**

- 話本腔、表妹拆穿、肚子叫——這就是「想當大俠」的人。
- 取鼎：不管誰拿，封印破、必戰、必傷。俠的做法（別碰）**推不動場面**——這句本身就是 0.1。
- 張仲景：「像是藏了什麼寶貝在自行護主。」他當誇獎。玩家可以比他早一步覺得不對勁。
- 第二次再探：張大叔囑了「為民除害」，他用話本腔去斬妖。動機是大俠，不是去餵骰子。

**已解決（不再列為缺口）：**

- ~~她擋完沒有夢~~ → **已完成**，見 `黑血屍_旅店夢.md`。
- ~~夢裡沒把好處講完~~ → **已解決，而且是用不講的方式**：她只丟一句「好處你也有。你自己沒覺得？」，不說是什麼；玩家要等張仲景嫌任督開得太順，才把兩句對上。

**仍空轉／仍缺（本檔要改的）：**

1. **取鼎是魅力檢定，不是玩家選。** 檢定過兩次，雍仔自己拿，結局一樣。玩家感覺不到「這次用了哪一種手」。
2. **第二次去不去打，原文沒有抉擇場。** 去打是強制劇情（L979）；不去只是逾時掉進 `@結局/序章失敗結局.md`【被遺忘的災厄】。
3. **屍丹是四軸標籤。** `[信義][通達][仁心][機略]` 像考卷。**骰子沒燙**——而屍丹在 `@角色設定/饕餮.md` 第四節「叫得醒」清單上，**它一定會燙。**
4. **拒絕幾乎沒代價。** 銷毀屍丹只得「浩然正氣」；自己吞沒有當下的怪。
5. **`AddItem(...)` 是廢棄指令**（見 `給AI看的指南/貴重品指令轉換規則.md`），本場四處要換掉。

**第一次若打贏（既有支線：奪石骨大劍）：** 沒有瀕死，骰子不必擋，夢不出現，**她沒出手，那一筆也不記**。本檔主線仍以**戰敗**為準。打贏線本文不寫。
