# 雲中（箱庭文案總覽）

> **本檔由 `Json/` 回讀產生，不是創作稿；遊戲內文案的唯一事實來源是各章節對應的 JSON。**
> 改字請指名錨點（例：「`大地圖/雲中/街道.json` #111 這句改成…」）→ AI 改 JSON → Unity 同步 → 重新回讀本檔對應章節。直接編輯本檔的文字**不會進遊戲**。
> 規則：`給AI看的指南/Unity對話同步流程.md`〈文案總覽稿〉；本檔各章節在其他總覽稿的收錄關係見 `劇情/索引.md`。
> 舊創作稿已於 2026-08-26 依拍板歸檔：`劇情/舊創作稿/雲中.md`（§1 的出處）、`劇情/舊創作稿/吉祥賭場.md`（§2 的出處）——**歷史版本，不可引用為現行文案**。

> **怎麼讀本檔**
> - 一份 JSON ＝ 一個 Unity 對話，**依箱庭區塊分檔**：同一塊區域裡的互動點寫在同一檔。因此一檔裡通常有好幾段互不相連的戲，每段的第一個節點即該互動點的進入處，本檔用 `### N-k　入口 #X` 分段，一段一段走完；這些段落之間沒有連線是正常的，不是斷線。
> - 每段從入口往下讀，遇到分岔就往下讀（`▶` 標示該條路線的條件或選項分支）；不同路線又走回同一句時，只寫「→ 接 `#N`」，不重複貼一次。
> - 「**◆ 玩家選擇**」是玩家點選項的地方；「`- 分流：…`」是遊戲自己依條件挑路走，標籤（「檢定成功」「戰鬥勝利」「任務 CF22 第 1 項未完成」）是把 JSON 的 Conditions 翻成白話，原始寫法仍照抄在該節點的 `Conditions:` 行。
> - 空文案的功能節點用 `> ⚙`（緩衝、過場、給獎勵）、`> 🎲`（擲骰檢定）、`> ⚔`（進入戰鬥）、`> 🎮`（小遊戲）標示。
> - 「**孤兒節點**」＝ 沒有任何節點連到它、它也不連去別處的節點，遊戲中播不到（多半是廢稿），照抄保留。
