## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關的特殊處：兩條路都拿得到那卷書。差別在你有沒有替他守住嘴。**

| | 內容 |
| :--- | :--- |
| **他要什麼** | 蔡邕手上那卷異邦殘卷 |
| **他為什麼不自己去** | **表（戲裡給的）：他那名聲借不到書**——嗜錢如命、屋裡剖屍，蔡邕那樣愛書的人不會把書交到他手上。**裡（作者層，他不說）：一開口就等於告訴對方「我在查什麼」**——那一脈不留名、不對外承認（`世界觀.md` §三），問一句暴露一寸 |
| **俠的做法** | 老實告訴蔡邕要來做什麼。**他就給你** |
| **它的代價** | **你保住了自己的誠實，卻把先生賣了一寸。** 蔡邕從此知道英豪府在查這個 |
| **管用的做法** | **什麼都不說。** 而蔡邕肯不肯給，看的是**你以前跟這家人存下來的交情** |
| **哪裡不是俠** | 你替一個不肯露面的人跑腿，而且不告訴對方為什麼。**你用的是人情，不是道理** |

> **⭐ 這一關真正的引擎：不說理由那條，正是賈詡自己會做的選擇。**
> **主角走了先生的路，先生就高興；主角走了自己的路，先生的好感就掉。**
> **——你越像他，他越喜歡你。**
> **⚠ 這一層不得由任何人說破，旁白也不行。** 玩家從那個數字自己感覺到。

**⚠ 賈詡不在 0.2.2 的帳上**（明確不開）。**本關不做結算、不用變數、不留旗標**，只寫任務 entry。
