## 場景與人物（供讀劇情用；自舊創作稿 `不知名野外.md` 搬入）

**區域描述：** 位於山路盡頭的一處隱秘所在，看似死路，實則別有洞天。包含隱士小屋、池塘與一處神祕的墓碑。
**主要機制：** 探索檢定（武藝）、機關木人戰鬥、挖掘、釣魚戰鬥。

**登場人物：** 燕不凡（MC1）、河童三弟（role121）。
**互動點（本檔 7 個入口）：** 斷崖 → 谷底 → 隱士小屋 → 木人樁 → 屋內暗牆 → 古樹下無字墓碑 → 池塘。
