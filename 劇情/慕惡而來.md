## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關的特殊處：這一關要動的手，動在別人的名字上。**

| | 內容 |
| :--- | :--- |
| **場上發生什麼** | 五山劍盟找上門要「斬奸除惡」。子羽把幾十個人打趴，**一個都沒殺** |
| **那個名字** | 「惡刀子羽」。**這名字不是他掙的，是別人給的——而他從來沒有糾正過** |
| **管用的做法** | **讓它傳，甚至幫它傳。** 一個名聲在外的惡人擋在門口，英豪府省下多少麻煩 |
| **俠的做法** | 去把話講清楚：是他們先動的手，而且他一個人都沒殺 |
| **哪裡不是俠** | 拿師兄的惡名當自家的招牌。**他替你擋掉的那些麻煩，是他自己的名字在付帳** |

**⚠ 這一關是〈仗義疏財〉的鏡子。**

- 〈仗義疏財〉：**「散財義士」是別人怎麼叫呂信**，主角只能站著看。
- 〈慕惡而來〉：**「惡刀」是別人怎麼叫子羽**，而這一次**主角可以動它**。

**這正是 0.2.2「症狀：不給數字」講的那件事——名單活在別人怎麼叫他、怎麼看他。這一關把那個機制交到玩家手上一次。**

**⚠ 子羽在 0.2.2 帳上（2026-08-25 補開，正＝殺心找到了要護的東西／反＝殺心只是找到了新的藉口），但本關不做結算。** 只留記錄用的樁，見附錄一。**他的結算點在 `劇情/歸姓.md`（人物結局），不在這裡。**

**⚠ 寫法紅線：**
1. **子羽不澄清自己。** 全關他一個字都不解釋那個名字。他甚至沒有表示在意。
2. **不得寫成「他其實是好人被誤會了」。** 他是真的把幾十個人打趴、真的說「羽要打十個百個不成問題」。**沒殺人不等於溫柔**——那是規矩，不是心軟。
3. **不得碰「好紅的臉」。** 主角在 §5 說的是「師兄的臉太像壞人了」——那是**長相**，不是那三個字（`@角色設定/子羽.md` 性格特質 2 的逆鱗是「好紅的臉」＝殺心反噬的具象化）。**兩者不同，這一關的玩笑安全，不要把它寫成踩雷。**
4. **五山劍盟不是壞人。** 他們是名門正道，他們也真的以為自己在除惡。原文那句「即便出手也要講個說法」**一字不改**——這一關的諷刺全在那一句上。

## 附錄二：設計筆記

1. **加厚只加了兩處，而且都在「名聲」上。** 原文 26 行的骨架很好——堵門、打趴、喜劇收尾——缺的不是長度，是**玩家有事可做**。所以加的是「你要不要看清楚那滿地的人」（§4）與「那個名字你要不要動」（§6），兩者都不動原有節奏。
2. **§4 那個洞悉是這一關的心臟。** 「惡刀」這個名字之所以荒謬，不是因為他人好，而是因為**他打趴幾十個人用的是刀背，而沒有人去數**。玩家骰贏了會自己去數——**那個「自己去數」的動作，就是這一關全部的重量。** 骰輸了只看見滿地的人，這是允許的結果。
3. **6-1 刻意不成功。** 這是全案少見的「做了對的事，結果沒有用」。它不是懲罰（沒有扣任何東西），也不是嘲笑主角——**它只是誠實**：名聲這東西不是靠講道理能動的。而且它的失敗方式最漂亮：**你替他說話，於是你也被寫進那個名字裡。**
4. **6-2 要真的好用，這一點不能軟。** 依高概念，管用的做法必須真的管用；如果讓玩家選了以後只有壞處，這台引擎就變成道德分了。所以那個月門口真的清靜、麻煩真的少了——**代價只寫在「付帳的人從頭到尾沒說過一句話」那一句上。**
5. **這一支跟〈仗義疏財〉是一對。** 那一支的收尾是「後來雲中的人都叫他散財義士」，這一支的收尾是「你於道上再聞羽威名」。**兩支都收在別人怎麼叫他，而這一支多了一格：這次是你決定他被怎麼叫的。**
6. **五山劍盟不能寫成蠢貨。** 他們排練說詞、他們要先講個說法才肯圍毆——**那是人的樣子，不是笑話的樣子。** 原文那句旁白已經把分寸定好了，照著走就好。
7. **⚠ 待填：** 無。本支線**沒有戰鬥、沒有小遊戲、沒有貴重品、沒有場次 ID**——是四支新稿裡唯一可以直接進 JSON 的一支。
