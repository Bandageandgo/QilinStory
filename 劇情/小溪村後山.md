> 改字請指名錨點（例：「`小溪村後山_赫連娜娜、張寧.json` #741 這句改成…」）→ AI 改 JSON → Unity 同步 → 重新回讀本檔對應章節。直接編輯本檔的文字**不會進遊戲**。

> **怎麼讀本檔**
> - 一份 JSON ＝ 一個 Unity 對話，**依箱庭區塊分檔**：同一塊區域裡的互動點寫在同一檔。因此一檔裡通常有好幾段互不相連的戲，每段的第一個節點即該互動點的進入處，本檔用 `### N-k　入口 #X` 分段，一段一段走完；這些段落之間沒有連線是正常的，不是斷線。
> - 每段從入口往下讀，遇到分岔就往下縮排（`▶`＝第一層、`▶▶`＝第二層…）；不同路線又走回同一句時，只寫「→ 接 `#N`」，不重複貼一次。
> - 「**◆ 玩家選擇**」是玩家點選項的地方；「`- 分流：…`」是遊戲自己依條件挑路走，標籤（「檢定成功」「戰鬥勝利」）是把 JSON 的 Conditions 翻成白話，原始寫法仍照抄在該節點的 `Conditions:` 行。
> - 「**孤兒節點**」＝ 沒有任何節點連到它、它也不連去別處的節點，遊戲中播不到（多半是廢稿），照抄保留。
> - 文案中的 `<br>` 是原始 JSON 裡就有的換行，不是新加的。
