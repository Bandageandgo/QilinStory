# 支線7：雙世冥劍（呂信・子羽）

> **出處：** 概念與台詞取自 `劇情/舊創作稿/第二章劇本.md` 支線7（1468–1793 行，全案最長的一段，326 行），改寫為現行劇本格式。**本檔為定稿，原檔對應段落作廢。**
>
> **⚠⚠ 解凍（2026-08-25 拍板）。** 本支線自 V1.24 起整條凍結，理由是 `給AI看的指南/世界觀.md` 第十節：「L1435 雍仔驗劍說它『揉合了九黎怪物的血肉與怨魂』——但九黎是未來式，179 年沒有成規模的九黎屍體可煉。」
> **凍的是那一句，不是那個故事。** 故事自己早就給了答案——廖莊主親口說**甘夫把妻子投進了爐子**。**那不是九黎，那是人祭。**
> 依 `給AI看的指南/世界觀.md` 第三節「人祭與凶戾（已定）」：**凶戾＝怨、煞、邪凝成一團的實體**，定樁是「白虎道妖＝殷商人祭的失敗品，屬本土軸」。**莫雪與白虎道妖同軸。**
>
> **⚠ 兩把劍不同級，不得寫成一樣：**
> * **莫雪＝人祭級的凶戾**（一個活人被投進爐子，怨凝了幾十年沒散）。
> * **甘陽＝甘夫自己的怨**（一個殘廢的人抱著它恨了半輩子，臨死前在兒子背上刻「斷　劍」二字）。**是執念，不是人祭。**
> * **兩劍相激，才凝得出一隻實體。** 單獨哪一把都不會變成怪物。
>
> **⚠ 觸發改掛：** 原文 L1425–1426「在戰略圖接取」作廢（**沒有「指派」系統**）。改為前置旗標＋情報網條目，見下。

## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關的特殊處：這一關要動的手，動在一個人肯不肯拔刀上。**

| | 內容 |
| :--- | :--- |
| **場上發生什麼** | 兩把劍凝成的東西砍不穿。**全場只有子羽那一刀劈得開，而他握著刀柄不動**——因為那把刀是死在爐子裡的那個女人給他的 |
| **管用的做法** | 給他一個該殺的理由。**「那東西殺了多少人，你數過嗎？」**——一句話，他就出刀，而且出得比誰都快 |
| **俠的做法** | 把那個女人的話還給他：**「她給你這把刀，是要你止殺。」** 他也會出刀，只是要慢一拍 |
| **哪裡不是俠** | 前者管用是因為**它餵的是他的病**。他那把刀本來叫「偃武」——止戈的意思；你把它變回一把殺人的刀，而且你成功了 |
| **代價在哪** | **在那慢的一拍上。** 毒煙不會等你講完道理，那一拍有人要付 |

**⚠ 這一關是全案唯一一次，兩本帳同時攤在同一個場子上。**

**⚠ 寫法紅線：**

1. **兩套說詞都不揭穿。** 廖莊主說甘夫把妻子投進爐子；鑄師之子說廖莊主殺了他母親、奪了劍。**本作不告訴玩家哪一套是真的**，呂信那段第三種假設也只是假設。原文 L1613「所謂事實，不過都是個人角度罷了」**一字不改**——這一關的表裡真實全在那句上。
2. **子羽不解釋自己。** 全關他不提殺心、不提亡命、不提妹妹、不提偃刀是誰給的。**那段回憶是演給玩家看的，不是他說出來的**——他當場的反應只有「……」與一句「羽沒興趣聽無緊要的故事」。
3. **不得碰「好紅的臉」。** 那三個字全劇只在 `劇情/舊創作稿/羽之演武.md` 5-3 發作過一次，**用掉就沒了**。本關即使他握刀不動、即使他手在抖，**任何人都不得說那句話**。
4. **呂信不是壞人，也不許被寫成壞人。** 他答應了一個殘廢的孤兒替他父親了願，他就做到底；他斬那一刀是因為他一眼看出那人已經回不來了。**他的判斷可能是對的——這正是難受的地方。**
5. **五山劍盟那條規矩在這裡也適用：子羽不斬女流老幼。** 本關沒有這種人在場，**不要為了演他的義而硬塞一個**。
6. **不得出現「九黎」二字。** 世界觀已定為未來式。怪物用本名 `刀勞鬼種`。
7. **不得出現「反噬」「命盤」「鬆一分」「秤」「退格」「贖」。** 全是 `@角色設定/饕餮.md` 第十節的停用術語。

## 附錄二：設計筆記

1. **解凍只動了兩句話。** 世界觀第十節凍它的理由寫得很精確——問題出在雍仔驗劍那一句與呂信那一句「怪物血肉」。而故事自己早就給了答案：**一個活人被投進爐子。那不是九黎，那是人祭。** 兩句改成凶戾的講法，其餘 326 行的骨架一個字都不必動。**這一支從來不是壞稿，它只是背了一句別人的錯。**
