## ⚠ 最重要的一條紅線：這一支不准有答案

**本支結束時，子羽的疑問必須仍然懸著。**

- **他不得想通任何事。**
- **主角說什麼都不改變他。** 三個回答的差別**只在他用哪種方式把話推開**，以及留下哪一顆樁——**那三顆樁要留給後兩支用。**
- **旁白不得下任何判語**，不得暗示哪個答案是對的。

**如果這一支給了答案，後面那支「尋找答案」就沒有東西可找了。**

## 高概念對照（寫這一關之前先看）

> **高概念：** 一個想當大俠的少年，他學到的每一手都管用——只是沒有一手，是俠該用的。
> **引擎：** 這次，用俠的做法，還是用管用的做法？

**本關的特殊處：這一次上門的人不是要殺他，是要用他。而他拒絕之前，先問了那個人的名字。**

| | 內容 |
| :--- | :--- |
| **發生什麼** | 一個十六歲的少年抱著錢找上雲中練武場，**指名要「惡刀子羽」**。他要買一條命：他父親被人打死了，官府不辦 |
| **子羽怎麼做** | 拒絕。乾脆、很短、很他 |
| **問題在哪** | **他拒絕之前，先問了那個仇人的名字。** 而問名字這件事，只有一種解釋——**他把「該不該殺」在心裡過了一遍** |
| **主角的位置** | 他是唯一站得夠近的人。**而當晚子羽在練武場擦刀，問了一個沒有答案的問題** |

### ⚠ 這一關是〈慕惡而來〉的第二次帳單

**同一個門口。上一次來的人要殺他，這一次來的人要用他。**

**兩次都是因為那個名字。**

- 〈慕惡而來〉：五山劍盟為了「斬奸除惡」而來——**因為他們相信那個名字。**
- 〈戴天〉：一個少年為了買一條命而來——**因為他也相信那個名字。**

**⚠ 若玩家在〈慕惡而來〉走的是 6-2「讓它傳」那條，這個少年是主角自己招來的。** 本關**不得由任何人指出這一點**，只在 §2 讓少年說出他是從哪裡聽來的——**玩家自己會撞到。**

### 這一關扣在他那本帳上

| 子羽 | 正 | 反 |
| :--- | :--- | :--- |
| — | 殺心找到了要護的東西 | 殺心只是找到了新的藉口 |

**他拒絕了，這是「正」。而他問了名字，這是「反」第一次真的動了一下。** 兩件事同時發生，**本關不裁決哪一件比較真。**

**⚠ 結算點不在這裡，本關也不帶任何東西到結局。** 結算點是 `劇情/歸姓.md`，而它的分岔只認 `劇情/陽曲塢.md` 4-3／§7-1。**本關 §7 三條的去處是〈陽曲塢〉§7，在 §7-1 匯合。**

**⚠ 寫法紅線：**

1. **那個少年不是壞人，也不是誘惑者。** 他不哭鬧、不威脅、不編故事。**他帶了錢，他講得很清楚，而且他講的都是真的。** 他甚至不覺得自己在做壞事——在他的世界裡，這種事本來就是這樣辦的。
2. **子羽拒絕得很乾脆，不得寫成勉強或掙扎。** 他的拒絕是真心的。
3. **那一下不得被任何人指出來**，包括主角。洞悉成功只讓玩家看見，**主角不得說出口。**
4. **子羽不提自己。** 全關他不提殺心、不提亡命、不提妹妹、不提為什麼問名字。他問的是書。
5. **⚠ 不得碰「好紅的臉」。** 那三個字全劇只在 `劇情/舊創作稿/羽之演武.md` 5-3 發作過一次，**用掉就沒了**。本關即使他握著刀、即使他停了一下，**任何人都不得說那句話。**
6. **⚠ 不得讓子羽被寫成「其實心軟」。** 他不是不忍心殺那個仇人。他是**不受雇**——那是規矩，不是心軟（同 `劇情/慕惡而來.md` 紅線 2）。

## 附錄二：設計筆記

1. **這一支的主體是子羽，不是主角**（同 `劇情/呂信/04 渡江.md`）。前三支都是「主角看見／主角決定」；這一支是**子羽自己撞上一件事，然後自己問出一個問題**。主角最重要的動作是 §8 把話嚥回去。
