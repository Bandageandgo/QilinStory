# 子羽

> **⚠ 稱謂（2026-08-29 作者拍板）：主角喚「羽兄」，不是「師兄」**（原文誤寫成「不是『羽兄』」，2026-09-05 訂正）。呂信喚「子羽兄」「羽兄」。**英豪府不是門派，不互稱師兄弟**；全表見 `給AI看的指南/武俠文風創作指南.md` 第四節之二。 (未來的關羽)

## 高概念（**已定．2026-09-05 作者拍板**）

> **關羽的骨，傅紅雪的病。**
> 關羽是他將來要成為的人，傅紅雪是他十八歲現在的樣子。這條線，是從傅紅雪走到關羽的路。

兩個原型各管一半，不混：

| 關羽給他的（骨） | 傅紅雪給他的（病） |
| :--- | :--- |
| 義；讀《春秋》 | 那把刀是他跟世界唯一的關係：偃刀從不離手、拔得慢、出鞘就得有人死 |
| 認罰不認錯 | 殺心不是他選的，是別人一刀一刀餵出來的（每殺一人，便有一人尋仇） |
| 不斬婦孺 | 名是別人給的（「惡刀」），他從不糾正 |
| 善待卒伍而驕於士大夫 | 不解釋自己 |
| 紅臉（殺心翻湧的具象） | 傲是護著病的殼；「好紅的臉」踩到的是殼被掀開，不只是被虧 |
| 將來取回的姓（關）；面如重棗那句吹牛 | 唯一一個看穿他還不怕他的人，已經死了（莫雪） |

**線的形狀（六支怎麼落）：**〈羽之演武〉他是傅紅雪（刀、傲、殼）→〈慕惡而來〉名是別人給的→〈雙世冥劍〉刀的來歷、莫雪→〈戴天〉〈陽曲塢〉**在別人的仇裡看見自己**（傅紅雪是報仇的人；子羽是看著別人報仇、被問到自己的人。這一層是不改背景就能裝進傅紅雪的入口）→〈歸姓〉取回關姓，**刀還在手上**（三條結局都拿著刀，正是傅紅雪停手之後刀仍在的形狀）。

**⚠ 不取的（紅線）：**
- **「仇是假的、他不是那家的兒子」。** 動到已定背景，也讓〈歸姓〉取回「關」姓塌掉。他殺的那個人是真的該殺，這條不鬆。
- **癲癇、跛足、黑衣蒼白。** 新病就是新機制，世界觀沒寫的不發明；他的病是紅臉，而且已定全劇只發作一次。外貌撞面如重棗。
- **第二個翠濃。** 莫雪已經填了那個位子。
- **古龍的句法。** 傅紅雪只借性格與意象，古龍的碎句一寸都不進旁白，**子羽自己也不碎句**（見〈說話風格〉）。
- **公子羽。** 《天涯明月刀》的反派叫公子羽、執念是天下第一。撞名知道就好，不去踩。

## 性格特質與行為邏輯
1. **眼底容不下「輕浮」與「兒戲」**
   他用生命在戰鬥與對抗殺心，因此極度討厭別人把英豪府或戰鬥當成兒戲。
2. **觸碰「逆鱗」（紅臉）**
   被指出「好紅的臉」不僅是外貌特徵，更是他**殺心翻湧上來、壓不住**的具象化表現。這句話會踩中他無法控制殺心的痛點，導致瞬間暴走。
   > **⚠ 用詞：本條原寫「殺心反噬」，2026-08-25 改為「翻湧、壓不住」。** 「反噬」是 `@角色設定/饕餮.md` 已停用的術語（那邊指的是刪掉的計數器），兩者無關，避免讀成同一套機制。
   > **⚠ 與「臉太像壞人」不可混寫。** `劇情/慕惡而來.md` §5 主角說的是**長相**，他的反應是**被虧了**（`pic=2` ＋ `Anger`）；逆鱗是**那三個字**，反應是**被踩了**（`Anger_2`／`Anger_3`，暴走級）。該檔紅線 3 已註明。
3. **武者的底線：不斬女流與老幼**
   雖然被殺心籠罩，但潛意識裡的「義」讓他絕對不對手無寸鐵或沒有威脅的婦孺拔刀。當娜娜或靈犀惹怒他時，他的殺氣會瞬間鎖定全場「最具威脅性、且是個男人/戰士」的主角。
   *(潛台詞：你們是一起的，既然女人管不住嘴，那作為拿武器的男人，你就得替她們接下這一刀！)*
   > **⚠ 這條規矩是可以被人拿來用的武器。** `劇情/舊創作稿/羽之演武.md` 5-2：主角丟開兵器賭他不斬手無寸鐵之人——**而且賭贏了**。他事後只說一句「下次別再用這一手……用得上的，不會只有你一個」。
4. **守規矩的狂犬（認罰但不認錯）**
   對師父說：「羽願受責罰，你罰吧，師父。」
   精髓在於「我尊重英豪府的規矩和師父的權威，所以我認罰，但我心裡不覺得砍他有錯」。受罰時背脊挺得筆直，眼神依舊桀驁不馴。
5. **只尊敬他認可的人（善待卒伍而驕於士大夫）**
   他看不起才能平庸或只會紙上談兵的人。對於沒有真本事卻身居高位者，他會毫不掩飾自己的鄙視與傲慢；但對於他認可的人（無論是武藝高強，還是品德高尚、有骨氣），他會展現出極度的忠義與友善。同時，他非常護短，對底層的戰士或平民十分照顧。
6. **文武雙全的硬漢（喜讀《春秋》與極高忍痛力）**
   即使在狂躁期，他閒暇時仍可能拿著一本破舊的《春秋》研讀，這是他內心渴望「大義」的證明。此外，他擁有極其恐怖的忍痛能力，即使受了重傷也能面不改色（呼應未來的刮骨療毒），展現出極致的硬漢作風。
   > **寫法：用道具演，不用嘴說。** `劇情/舊創作稿/羽之演武.md` 全關《春秋》出現三次（開場他在讀、通達尾他攤著書半天沒翻一頁、5-3 他走後風把書翻過兩頁），**一次都沒有解釋。**

## 說話風格（**已定．2026-09-05 依高概念重寫，同日作者拍板**）

> **語料底稿：`@角色設定/子羽_演義關羽語料表.md`**（2026-09-05）——演義十八回關羽台詞 210 句，按對誰說分類，每句標句骨、取不取、子羽版；前面兩節是抓出來的規則與關羽→子羽的改造法。寫他的台詞找不到句形時去翻那張表。

**一句話：他說話像在說規矩，而且是他自己的規矩。** 每一句都是一條規矩、規矩的理由，或規矩套在眼前這件事上：「水底下看不見，我不下」是規矩，「重了，拔得慢。慢一分，想得起來」是規矩的理由，「大丈夫意氣相許，何須多言。乾」是規矩套在敬酒上。所以他沒有心情句，只有道理句（不說「我不想下」，說「看不見，我不下」）；理由只給一層，底下那層不說（這就是「不解釋自己」的實際操作：**講理由，不講來歷**）；講完就做，句尾常接動作（乾／打敗我／回去罷）。冷是因為平說，不是因為短。**關羽在規矩的內容**（義、大丈夫、堂堂正正、不斬婦孺、不受雇）與句子的骨（演義的斷語、對舉、條件）；**傅紅雪在說法**（平說、無語氣、只給一層、刀當表情）。**話少是靠格少，不是靠字少**：他不接的話就沒有他那一格，接了就是整句。

**跟府裡其他人怎麼分：** 徐榮的規矩管別人（軍令：「回來一個都不許少」），子羽的規矩管自己，他很少命令人，「夜深了，回去罷」是說天色，不是下令。郭嘉話裡有話，子羽話裡沒有第二層，字面就是全部。呂信揶揄、反問，子羽不揶揄、不反問。賈詡引經、四字成句，子羽引書一場一次、引完不解釋。〈上巳〉第一段到第三段河，五個人講同一件事（下不下水），是現成的對照。

### 口吻怎麼聽（2026-09-05 作者追問「口吻是相同的，還是只是相同邏輯」後補．已定）

**「規矩」是邏輯層，不是口吻層。** 上面那六句邏輯相同，口吻其實不齊：「水底下看不見，我不下」是白話，「大丈夫意氣相許，何須多言」是演義文言，「無端逢迎，不是小人，就是奸逆」半文半白。口吻要齊，得再定三層：

1. **句形（六句本來就齊）：兩截句。** 前半是事實或條件，後半是他的行動或判語，中間一個逗號，動詞收尾。「水底下看不見，我不下」「站久了，腳會麻」「刃出鞘，就得有人死」「重了，拔得慢」全是這個形。一格一到兩句，不寫三截以上的長句。
2. **語域（09-05 第三輪改成三層）：白話有兩種，重場用傅紅雪那一種；義才用書上的話。**
   - **輕場、眼前的小事：家常白話。** 具體的東西、身體的事，用全案的金庸白話底子平說（〈上巳〉「水底下看不見，我不下」「站久了，腳會麻」「這杯是茶」）。
   - **重場（生死、規矩、認罰、拒人、饒人）：傅紅雪的話＝決斷、江湖、帶一點黑暗（作者 09-05 第四輪定的三個字眼）。** 還是白話的字，句子完整，取的是傅紅雪的**分量**，不是他的短。
     - **決斷：句子收在自己身上。** 後半永遠是「我＋要做的事」，說成已定（「不勝，我不回來」「是我放的。我來領死」「城破，我不出城」「船備好，我過河」）。**不收在別人身上**：「換馬」「備船」「你動手」「你自己問」這種令，是第二版被退回的主因。
     - **江湖：規矩用道上的話講。** 命、帳、頭、路、還清、該領的、取你的頭、挨過的刀。不用官話（公事、賞將士），不用書生話。
     - **黑暗：死、殺、血、刀不迴避，說得平，像說天氣。** 「閒久了，刀會找人」「換了馬，我再來取你的頭」。但不誇口、不放狠話、不嚇人，黑是事實，不是姿態。
     - **句子完整：有主語、有動詞，一格一到兩句。** 六個字也行，只要是「我＋動詞」的整句（「不勝，我不回來」）；兩三個字的令不行。**動作前不停頓**（作者 09-05 第五輪）：逗號後面只掛兩三個字的肯定動作是碎句，「船備好，我過河」要寫成「船備好我就過河」，「這一趟，我去」要寫成「這一趟我自己去」，條件接行動用「就／便」連成一氣。否定的決斷可以停（「水底下看不見，我不下」「不勝，我不回來」）。`文風節奏檢查.py` 會抓「逗號後短尾」。
     - **不要古龍的巧。** 「不是Ａ，是Ｂ」的翻轉、「痛是我的事」「刀不能閒」那種格言式的小聰明，讀起來是刻意。傅紅雪的黑是沉的，不是巧的。
     **你點頭的句子全在這一層**：「刃出鞘，就得有人死」「殺得越多，才越明白這話有多輕」「不勝，我不回來」「是我放的。我來領死」「金子我不收。留給該領的人」「玉可碎，不可改其白。城破，我不出城」。
   - **義：書上的話。** 文言引語，**不翻白**（「玉可碎，不可改其白」，不是「玉碎了還是白的」），而且是他在引，不是他在說：「大丈夫意氣相許，何須多言」「不以一眚掩大德」「父之讎，不共戴天」都是格言。**書上一句，自己一句**是招牌形：引完接一句傅紅雪的話或一個動詞（「……何須多言。乾。」／「玉可碎，不可改其白。城破，我不出城。」）。一場至多一兩句，沒有義的場合一句都不出現。
   > **⚠ 前兩版錯在哪（09-05 作者兩次退回）：** 第一版把「白話」寫成「家常」——「先前給的還沒用完，這金子賞你的兵」「換一匹，再來」，是鄉土，不是冷；書上的話又被翻白（「玉碎了還是白的」）。第二版學傅紅雪學到他的**短和巧**——「倒的是馬，不是你。換馬」「痛是我的事」「刀不能閒」——短的成了碎句（兩三字的令），巧的成了刻意。作者裁示：**傅紅雪要取的是決斷、江湖、帶一點黑暗，不是短。** 家常的給輕場，決斷的給重場，文言的只給義。`@角色設定/子羽_演義關羽語料表.md` §二末有三版對照。
3. **用詞：跟著場的重量走。** 輕場用具體與身體（水、鞋、腿、茶）；重場只剩硬名詞（命、人、刀、死、頭、路）。任何場都沒有形容詞、沒有語氣詞（啊、嗎、呢不用；「罷」「便」是全案白話底子，可用），不揶揄、不反問。抽象詞（義、大德、讎）只在書上的話裡出現。

| 台詞 | 語域 | 照這三層看 |
| :--- | :--- | :--- |
| 「水底下看不見，我不下。」 | 自己的話 | 標準形 |
| 「站久了，腳會麻。」（〈上巳〉上游分支） | 自己的話 | 標準形 |
| 「刃出鞘，就得有人死。」 | 自己的規矩，講成格言的樣子 | 可以，一場一句；這是他自己的規矩借了書的形，正好是高概念 |
| 「重了，拔得慢。慢一分，想得起來。」 | 自己的話 | 可以，但頂真是修辭，貼近「刻意」的邊，一場一次 |
| 「大丈夫意氣相許，何須多言。乾。」 | 書上一句＋自己一個字 | 招牌形 |
| 「無端逢迎，不是小人，就是奸逆。」 | 書上的話（下判語） | 可以；後面若接一句自己的白話更像他 |
| 「書上說，父之讎，不共戴天。」→「那被殺的那個，他兒子呢？」 | 書上一句＋自己一句 | 招牌形，兩層撞在一起 |

**這三層跟高概念對得上：** 白話那一層是他自己（傅紅雪），書上那一層是他借來的規矩（關羽、《春秋》）。〈戴天〉那一對就是兩層撞在一起，書上的話說完，他自己的話把它問垮。〈歸姓〉「我姓關」是他第一次用自己的白話說出一條以前只在書上的規矩。

**跟高概念怎麼接：** 這條線問的是**他的規矩是誰給的**。殺心、「惡刀」之名是別人給的規矩（傅紅雪），義與關姓是自己立的（關羽）。〈戴天〉是他第一次發現兩條規矩打架（書上說不共戴天，那被殺的那個他兒子呢），〈歸姓〉「我姓關」是他把藏姓那條規矩收回。

> **⚠ 不是碎句（2026-09-05 作者裁示：「不要再走回碎句」）。** 「說。」「回去。」「多小。」「上馬。」「拿著。」那種一格一令是 08-25 那批稿（〈戴天〉〈陽曲塢〉〈歸姓〉）的寫法，**已廢**。生氣、拔刀、殺心上來的時候句子也還是整的，只是更短更冷。單字喝斥（「囉嗦！」）一場至多一聲，算驚呼不算句子。
> **⚠ 也不是舊的那三副嗓子。** 熱血少年（「你小子是把我當傻子耍嗎！」「……我說笑的。」）、溫厚大哥（「逞強無益。先喝口茶緩緩。」「錢是死物。」）、招式喊名（「偃武────開斬！！！」）都不是他。反例與改法見本節末表。

### 六條規矩

1. **一格一句整話，有頭有尾。** 一句八到二十字上下，一格至多兩句。要下令就把令說完：「回去」寫成「夜深了，回去罷」；「說」寫成「有話便說，我聽著」。
2. **只講事，不講心。** 他的句子說的是事怎樣、規矩怎樣、他會怎麼做。「我覺得」「我想」「我怕」「我懂」不出口，情緒進立繪與刀，不進字面。**他也不勸人、不評人**：說理（「逞強無益」）、褒貶（「比那筆銀子貴重得多」）是舊嗓子。要認可一個人，一句斷語帶過（「你今日那一讓，我記著」）；要否定一個人，講事實不講形容詞（「腿都軟了，還打什麼」）。
3. **演義的三種句骨。** 斷語（「哄鬧而已」「何須多言」「無端逢迎，不是小人，就是奸逆」）、對舉（「殺得越多，才越明白這話有多輕」「重了，拔得慢。慢一分，想得起來」）、條件（「你若只想博名討彩，趁早退下。若當真想一決短長，便堂堂正正打」）。引書可以（「書上說，父之讎，不共戴天」「不以一眚掩大德」），一場至多一次，引完不解釋。
4. **照字面答，只答被問的那一件。** 問名字答名字，問刀答刀，問人數答人數。不用反問頂回去（反問一場至多一次），不用「沒什麼」「不必多問」搪塞。**不想答就沒有他的格**，讓別人接下去。
5. **自稱「我」，稱名「羽」只留給禮數。** ⚠ 作者 2026-09-05：自稱「羽」做作、刻意。**平常一律「我」，能省主語就省**（〈上巳〉「水底下看不見，我不下」）。「羽」只在**對師父認罰**（「羽願受責罰」，漢代對尊長稱名是實禮）與**立誓**兩種場合可用，一場至多一次；**連這兩處也拿掉與否，待作者定**。已進遊戲帶「羽」自稱的有五格：遴選開場 `#3982`／`#518`（認罰，可留）、羽之演武 `#4061`／`#4071`、武道大會 `#18`（後三格照新規要改）。認可的人給稱謂（奉孝兄、莊主、師父、賈先生），看不起的人不給稱謂，直接「你」；「爾等」只對成群的匪類。「你小子」「兔崽子」「老大」不進他的嘴。
6. **文言虛詞跟著書上的話走。** 自己的話（白話平說）裡只用全案白話底子有的「罷」「便」「不過」；「而已」「何須」「乃」「豈」只出現在他引書、下判語那一兩句裡。不用：也、矣、耳、哉、吾、汝、某。「吧」一律寫「罷」。「乎」只用在反問，一場至多一次。語域怎麼分見下方〈口吻怎麼聽〉。

### 「……」與沉默

「……」是他想過才開口的記號，**一場至多兩格帶它，不單獨成格**。他不答的時候，寫法是**沒有他的格**：別人問完，下一格是別人繼續講，旁白不替他補、不寫「他沒有回答」。現有稿裡「…………」單獨成格的（〈雙世冥劍〉三處、遴選開場 `#535`）改成別人接話，或改 `[em7]` 動作（依文風指南 7.1a 省著用）。

### 殺心上來時怎麼寫

**不是句子變碎，是話變少、句變冷。** 稱謂去掉，只剩事實與他要做的事，這個狀態一場至多兩三格。標竿是〈陽曲塢〉「刃出鞘，就得有人死。」刀是他的表情：怎麼握、拔不拔、拔多慢，寫進 `[em7]` 或旁白，每十格至多一個（7.1a）。

### 講怪物、講武學

書面語（「吞食劍中怨念滋生」「怨念是生者與亡者之間的聯繫」）。這是他唯一可以講長一點的題目，但仍然是講事，一格至多兩句。
