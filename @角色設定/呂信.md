## 基本設定
* **姓名**：呂信（英豪府時期用名）
* **籍貫**：并州五原人（與史載呂布故里呼應）
* **身分**：英豪府門人／學長，比主角早入門
* **性格**：有些臭屁、愛顯擺，但極重情義；遇事總衝在先頭，是隊伍裡那種「有難先上的大哥」。
* **武道偶像**：極度崇拜西楚霸王項羽——那種「以一人之武勇，戰盡天下」的氣概。口頭禪與自我期許常繞著「霸王」「匹夫敵萬」之類的意象打轉。
* **他人評語（賈詡）**：賈詡曾半開玩笑、半認真地說：他若真要拿古人比，與其說像項羽，**更像英布**——同樣驍勇絕倫、敢打敢衝，卻少了幾分項羽那種悲劇英雄式的「純粹」，多了一點現實與野心，也更懂得在亂世裡為自己找位置。（此評語可成為呂信內心的一根刺，也可成為他日後自我辯解的伏筆。）

## 背景與在英豪府的定位
* 來自邊地，自幼見慣紛亂與廝殺，相信「拳頭與膽氣」最能說話。
* 早於主角入英豪府，對後進會擺一點學長架子，嘴上有時不饒人；但一旦認定是「自己人」，便會護短到底，任務與危局裡習慣扛第一線。
* 與「崇拜項羽」並行的是他對「名聲與天下」的隱約渴望——此時多半還包裝在「兄弟一起打出名堂」的豪語裡，尚未完全攤開成政治野心。

## 性格特質與行為邏輯
1. **天賦異稟與高處不勝寒的寂寞**
   天生神力，武道之路上難逢敵手。因為太強，其實內心極度寂寞，渴望能有並肩或真正匹敵的對手。但他絕不表現出這種「文人式的無病呻吟」，總是用爽朗、沒心沒肺的大笑和對戰鬥的狂熱來掩蓋。
2. **大智若愚：粗獷外殼與人情世故**
   外表看起來是不拘小節、只懂打殺的樂天武夫，實則對人情世故、利益糾葛看得很透（英布式的務實）。他深知亂世中「單純的武人」最容易生存也最容易被利用，因此刻意用這層「簡單」的外殼來保護、包裝自己。
3. **用「簡單」包裝「迷惘與尋道」**
   因為太強，反而不知道這身武力最終該用在哪裡。他在英豪府，其實一直都在摸索屬於自己的志向與道路（這也完美銜接了他未來想要「匡扶漢室」卻眼力不足的悲劇）。他不會輕易向人吐露這份迷惘，只會用「追求武道巔峰」當作對外的標準答案。
4. **愛馬、懂馬、馬痴（2026-08-29 作者加）**
   **他對馬的講究，遠遠超過他對任何東西的講究。** 五原出身，從小在馬背上長大——看一眼就知道口齒幾歲、腿是不是傷過、能走幾天不喝水。他的騎術不是「學來的技術」，是**他跟馬本來就是一件東西**。
   - **表現在動作，不在台詞。** 他不會宣稱自己愛馬；他只是**會停下來拍那匹馬的脖子**、會替一匹不是自己的馬鬆一鬆肚帶、會在別人面前忽然講起某匹馬的來歷講很久。
   - **⚠ 這是他唯一會「囉嗦」的題目。** 平常他「聽到重點便足矣」、最受不了等；**只有講馬的時候他會多話**，而且不覺得自己在多話。這一點是他難得的可愛，也是**旁人最容易看見他不是只會打殺**的地方。
   - **⚠ 傷馬這件事他過不去。** 殺人他不眨眼；**當著他的面把馬弄殘、弄死，他會不高興**——他不會罵，但那一刻他的話會變少、變短。**不得寫成他為馬跟人翻臉**（那太輕了），只寫他忽然不說話。
   - **⚠ 不得寫成他把馬看得比人重。** 他救人仍然先於救馬；差別只在**事後他會回頭去看那匹馬。**
   - **⚠ 赤兔：只准出現在結局後日談那一句，其餘一律不得提（2026-08-29 作者裁示）。** `劇情/呂信/07 改名.md` §3-共用 有「人中呂布，馬中赤兔」——**那是後人的俗諺，講的是他一生的名聲，不是本劇的情節**。**那匹馬在遊戲裡出不出現、怎麼來、什麼時候，仍然未定，AI 不得發明**；各支正文只寫他懂馬，**不得提赤兔、不得暗示他在等一匹馬**。

5. **臭屁與大哥氣並存**
   喜歡被叫一聲「呂大哥」「信哥」（日常稱呼見上方〈稱呼〉，**不得改叫師兄**），戰前愛放兩句狠話或自誇；真打起來卻不會讓同伴頂在自己前面。可以為了兄弟丟臉、認栽，對他認定的小團體忠誠度極高。

## 正史走向（伏筆）
* 英豪府解散之後，為**紀念這段歲月與誓言**，他**改名「呂布」**，並立下**取天下**之志。
* 改名可解釋為：對「信」之一字（承諾、兄弟之信）的執念與決裂並存——或象徵拋卻舊我、只認強權與功業（依你劇本基調二選一或折衷）。
* 若採用下方**隱藏設定**，「取天下」亦可解讀為：在他自己心中，武力與地盤終究是為了**匡扶漢室、清君側**而爭；與世人眼中「背主無信」的標籤形成悲劇性落差。

## 隱藏設定（劇透／主線後期，預設不向玩家揭露）
* **對漢室的真心**：呂信骨子裡對**漢朝十分忠誠**，一心想**匡扶漢室**；這層動機平時不掛在嘴上，與他「項羽式豪氣、英布式務實」的外殼疊在一起，外人更難看透。
* **眼高手低之憾**：可惜**眼力與實力（含政治判斷、局勢拿捏）不足**，屢次在亂世中做錯選擇、跟錯人、或被人利用；行為在史觀與流言裡被拼成「反覆無常」。
* **污名與實情**：背後評價常是**無信義之人**；但就「對漢室是否心懷不軌、是否存心篡弒」而論，敘事上可以堅持：**他對漢朝並沒有什麼真正的虧欠**——虧欠的是具體的人與具體的盟誓，與「漢」這面大旗在他心中的位置，不必混成一談。
* **轉機起點**：上述矛盾與轉折，可從他**遇見漢獻帝**之後開始鋪陳——面對「名義上的天下共主」，他壓在心底的忠誠、委屈與不服，才有機會被照亮或被迫攤牌（依你主線選擇：覺醒、悲劇、或扭曲成更危險的執念皆可）。
* **邊地出身的階序意識（潛在）**：呂信非常清楚漢地社會裡對「邊地人」的隱性鄙視鏈。雖然并州本就屬邊地，但他出身五原，離中原更遠、在主流文士眼中更「粗野」，地位常被再壓一層。他對此並不天真，知道自己在仕途與升遷上往往起步更慢、被信任更難。
* **「知道處境，但暫不反抗」的心理**：此時的呂信尚無強烈「非要出人頭地不可」的執念。英豪府給了他近乎家的歸屬與兄弟感，暫時沖淡了他對階序不公的憤懣。因此他多半選擇把這份清醒藏在心底，表面仍以豪氣與武人氣度示人——不是不懂，而是暫時不在乎。

#### 分岔就發生在「選單上有幾個選項」

| 結局選項 | 出現在 | 落點 |
| :--- | :--- | :--- |
| **「那個『信』字，你留給誰？」** | **只有 `2-B ＋（3-B 或 3-C）`** | **正**：不擇手段是為了重建英豪府，重感情還在 |
| **「呂布。好名字。」** | 全部路徑 | **反・甲**：拋卻舊我，只認強權與功業 |
| **「……師兄保重。」** | 全部路徑 | **反・乙**：什麼都沒說，你也沒問 |

**⚠「……師兄保重。」是全案唯一允許主角當面喚他「師兄」的地方。** 日常叫信哥，這裡退回師兄＝見外、沒問、沒說——不是敬禮。見上方〈稱呼〉。

**⚠ 判準一句話：沒說過「改變不減損你是誰」、又沒做給他看的人，講不出那句話。**

* **2-B**：你給過他一個「渡了江還能是自己」的可能。**而改名正是那件事的字面版。**
* **3-B／3-C**：你放過（或想帶走）一個「只是活下來的人」——**你把那句話做了一次給他看。**
* **3-A**：你說一套做一套。**說過 2-B 也沒有用。**

**⚠ 這仍然不是道德分。** 3-B 放過那個老兵，**而雇主要的「乾淨」你沒給**；3-C 想帶他走，**而他拒絕了，你什麼也沒改變**。**兩條都有代價，沒有一條是當好人拿到的**——依 0.2.2「這不是道德分」。

**⚠ 大勢不改，改的是理由。** 三條結局裡英豪府**都會散**、他**都會改名呂布**、**都會立取天下之志**（本檔「正史走向」）。差別只在**為什麼**，以及**別人後來怎麼叫他**。

#### ⚠ 「布」這個字（改名的設計核心）

他丟掉的是「**信**」——承諾、兄弟之信；接下的是「**布**」——**而賈詡評他「與其說像項羽，更像英布」**（`劇情/呂信/03 英布.md` §2-1）。

| | |
| :--- | :--- |
| **正** | 他把「信」**留在**英豪府了。丟掉那個字不是因為不在乎，**是因為他覺得自己不配再叫它** |
