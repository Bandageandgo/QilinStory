## 一、從關羽嘴裡抓出來的規則

### 1. 自稱有三檔，而且是照對象換的
- **「某」「關某」**：對上位者、對嫂嫂、認罪、立誓（「如不勝，請斬**某**頭」「使二嫂受驚，**某**之罪也」「關**某**特來請死」）。
- **「吾」「我」**：對平輩、對敵、對下屬，佔絕大多數。
- **「漢壽亭侯關某」**：報名號，過關時用。

→ **子羽：** 全案「我」。「羽」只留在關羽用「某」的那兩種場合（認罰、立誓），一場至多一次；連這兩處要不要留，待作者定。名號那一檔子羽沒有，也不該有（他的名是別人給的）。

### 2. 稱人分兩檔：認的人給稱謂，不認的人給字眼
- 認的人稱字（文遠、子敬、公明）、稱謂（丞相、嫂嫂、先生、壯士、太守），連對追殺他的徐晃也叫「公明」。
- 不認的人：「汝」「匹夫」「鼠賊」「犬子」「孺子」「狗彘」。

→ **子羽取前半、不取後半。** 給稱謂＝認可，這一套照搬（奉孝兄、莊主、師父、賈先生）；罵人的字眼一個不取，他平說，不揶揄、不辱人。

### 3. 六種句式，四種能用
| 演義句式 | 例 | 子羽 |
| :--- | :--- | :--- |
| **條件＋自任／自罰** | 「如不勝，請斬某頭」「若彼不退，吾先斬之」「三者缺一，斷不肯降」 | ★ 兩截句的原型。前半條件，後半自己認 |
| **斷語「…耳」「…而已」「何足道哉」** | 「插標賣首耳」「土雞瓦犬耳」「有死而已」 | ★ 判語，歸「書上的話」，一場一次 |
| **對舉** | 「玉可碎而不可改其白，竹可焚而不可毀其節」「來時明白，去時不可不明白」 | ★ 一場一次，太多就刻意 |
| **照字面答／問** | 「未也」「便是」「不知去向」「將及二十年矣」「用何物治之」「公何人也」 | ★ 核心。傅紅雪也是這樣答 |
| **講完就做** | 「酒且斟下，某去便來」「速備船隻，送我渡河」 | ★ 句尾接動作 |
| **反問「安肯…乎」「豈…耶」「何…哉」** | 「吾豈懼汝耶」「安敢就坐」「何以雪恨」 | ✗ 關羽用得最多（四十句上下），**子羽一句不取，全改平述**。這是最大的一刀 |

### 4. 他什麼時候話多、什麼時候話少
- **話多三處：** 說理（對張遼三約、對諸葛瑾、對魯肅）、部署（烽火臺、古城分兵）、罵人。
- **話少三處：** 認罰（「關某特來請死」「皆不曾拏」）、答問、對嫂嫂與卒伍。

→ **子羽只留話少的三塊。** 所以「關羽一段話，子羽只留最後一句」成立：第 48、150、163、212 句的尾句就是子羽版。

### 6. 關羽有、子羽沒有的（不取清單）
- **自誇**：「吾於千槍萬刀之中……如入無人之境」（66 回）、「量一老卒，何足道哉」（53 回）。傅紅雪不會說。
- **驕於老卒**：「大丈夫終不與老卒為伍」（73 回）。⚠ 與設定第五條「善待卒伍」相反。
- **辱人**：「虎女安肯嫁犬子」（73 回）、「猶殺狗彘耳」（74 回）。
- **報名號爵位**：「漢壽亭侯關某」。他的名是別人給的，他不報。
- **兄弟情**：所有對劉備、講桃園的句子。本作沒有這個人，不發明。
- **復仇誓**：「吾誓報此一箭之讎」（74 回）。⚠ 〈戴天〉〈陽曲塢〉是拿「讎」這個字去問的，他自己不立這種誓。
- **內心話**：「吾非欲沿途殺人，奈事不得已也」（27 回馬上自歎）。⚠ 這句正是子羽線的底，**只能演，不能說**。

## 二、改造規則：關羽 → 子羽

1. **反問改平述。** 「安敢就坐」→「嫂嫂站著，我不坐」；「吾豈懼汝耶」→ 刪，或「我不怕你」也不必說。
2. **「某」「吾」→「我」。** 認罰、立誓那兩處的「某」→「羽」（待定）。
3. **一段話只留最後一句。** 說理與部署整段不取，尾句常常就是規矩本身。
4. **罵人的字全刪；判語只留書上那一句。** 「土雞瓦犬」可以，「碧眼小兒紫髯鼠輩」不行。
5. **「耳／哉／乎／也」落地。** 「…耳」→「…而已」或不加；「何足道哉」→「不算什麼」。
6. **名號、爵位、兄弟關係換成子羽有的。** 丞相→賈先生／英豪府的規矩；兄長→（無，不寫）；張飛→呂信；嫂嫂→娜娜、靈犀那種「手無寸鐵的人」。
7. **講義的句子留文言，講事的句子全白話。** 「玉可碎而不可改其白」是書上的話，可以引；「我人重，馬馱不動」是自己的話，全白。
8. **凡是解釋自己的，刪，改成道具或動作演。** 舊袍穿在外面（25 回）、拜馬不拜金（25 回）、馬上自歎（27 回）：他做，不說。
9. **關羽話多的那一格，子羽沒有那一格。**

### 改法示範：三版對照（第三版才是現行標準）

> **⚠ 2026-09-05 作者兩次退回。** 第一版「太過於白話」：白話寫成家常（「還沒用完」「馱不動」「賞你的兵」「再來」），書上的話翻白（「玉碎了還是白的」）。第二版學傅紅雪學到**短和巧**：「倒的是馬，不是你。換馬。」是碎句，「痛是我的事」「刀不能閒」是刻意。作者裁示：**加傅紅雪，取的是決斷、江湖、帶一點黑暗，不是短。** 第三版照 `@角色設定/子羽.md`〈口吻怎麼聽〉語域第二層：句子完整、收在自己身上（後半是「我＋要做的事」）、規矩用道上的話講、死殺刀不迴避但不誇口、不要古龍的翻轉。第二版過關的四句原樣留。**§三 語料表「子羽版」欄已於同日照第三版全欄重寫。**

**第三版作者再退兩句（「船備好，我過河」「這一趟，我去」），毛病是動作前停頓：** 逗號後面只掛兩三個字的肯定動作，就是碎句；條件接行動要用「就／便」連成一氣（「船備好我就過河」）。否定的決斷可以停一下（「不勝，我不回來」「水底下看不見，我不下」都過了）。`文風節奏檢查.py` 2026-09-05 起會抓這個形（「逗號後短尾」）。

**第二版被退的六句，毛病都是同一個：收在別人身上。** 「換馬」「備船」「讓我去」「你自己問」「你動手」是令，「不是恩」「痛是我的事」是巧。過關的四句全收在自己身上：我不回來、我來領死、我不收、我不出城。**傅紅雪不命令人，他宣告自己要做什麼。** 輕場（〈上巳〉）才用家常白話。

**先驗條件對照（哪些演義情境能借）：** 對曹操＝對英豪府／賈詡（恩不是主）；土山三約＝進英豪府時的條件（若寫）；過五關＝〈慕惡而來〉被攔；古城會＝與呂信被誤會時；華容道請死＝認罰場；刮骨＝忍痛場；單刀會＝對士大夫劃界。**桃園、荊州、麥城沒有對應。**
